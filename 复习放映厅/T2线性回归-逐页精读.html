P.04Why Predict a Number?

Why Predict a Number? 为什么要预测一个数字

核心一句话：很多真实问题要预测的是一个连续量（continuous quantity），而不是一个类别。

课件给了四个例子：

  • Housing prices — 从面积、位置、房龄预测售价
  • Stock trends — 从历史信号估计未来价值
  • Weather — 预测明天的气温
  • Student outcomes — 从学习时长预测考试分数

这一页最重要的是那张散点图（house size vs. price），它是本主题的贯穿例子：

看两件事：

  1. 有明显的上升趋势 — 面积越大价格越高，所以「用直线拟合」是合理的。
  2. 点不会完全落在任何一条直线上 — 这就是整门课存在的理由。真实数据有噪声和没测到的因素，目标是抓住趋势，而不是追逐每一个点。
⚠ 初学易错

完美穿过所有点不是目标，那叫过拟合（overfitting）。

◇ 小八卦

"regression" 这个词来自 Galton 19 世纪研究身高的工作——高个父母的孩子会「回归」到平均值。这个名字纯属历史遗留，跟方法本身在做什么没关系。

Study check从照片预测一个人的年龄——回归还是分类？▸

回归。年龄是连续数值（23.5 岁是有意义的）。但注意：如果任务是分成「儿童 / 青年 / 中年 / 老年」四档，那就变成分类了。任务类型取决于输出的形式，不取决于输入。

P.05Regression in the ML Landscape

Regression vs Classification 回归在机器学习版图中的位置

核心一句话：监督学习分成两大家族，分界线只有一条——你要预测的 y 是什么类型。

Regression 回归Classification 分类
预测什么连续值 continuous离散类别 discrete
输出一个实数 real number一个标签 / 类 label
例子房价（$）、气温（°C）、分数垃圾邮件、猫/狗/鸟、及格与否

1两者都是监督学习

共同点是：训练时我们已经握有正确答案。整条流水线也完全一样——

数据 → 带参数的模型 → 代价函数 → 优化器 → 评估

变的只是代价函数和输出的形式，底层哲学没变。所以你学会线性回归这套流程，下一个主题学分类时只是换零件，不用重学思路。

2「看起来是数字，其实是类别」的陷阱

⚠ 数据处理坑

邮编 5005 存成数字，但它是个标签。5006 并不是「比 5005 多一」，把邮编拿去求平均是没有意义的。同样的坑：学号、电话号码、球衣号码。

判断方法：问自己「这两个数相减 / 求平均有意义吗？」没有意义 → 它是类别，不是连续量。

↺ 回到 P4 复习
  • 回归预测连续量，不是类别。
  • 散点图有上升趋势，但点不精确落在直线上 → 抓趋势，不追点。
  • "regression" 的名字来自 Galton 身高研究，是历史遗留。
P.06Setting Up the Problem · 记号

Setting Up the Problem 问题的建立与记号

★ 全学期地基

备注明说：这套记号会用一整个学期，现在马虎，之后每个主题都会混乱。

我们从一个训练集（training set）开始——一堆「输入 + 已知输出」的配对。

五个记号 Notation
记号含义
x输入特征 input feature，例如房屋面积
y目标 / 输出值 target，例如价格
(x⁽ⁱ⁾, y⁽ⁱ⁾)第 i 个训练样本 the i-th example
m训练样本的数量 number of examples
ŷ模型的预测值 predicted value（y-hat）

三个必须记牢的坑

⚠ 坑 1

上标是索引，不是指数。课件原话点名「头两周最常见的记号误读」，会悄无声息毁掉你后面的代数推导。

x⁽²⁾ = 数据集里的第二栋房子；  x² = x 的平方。写的时候上标加括号 x⁽²⁾，就是为了跟平方区分。

⚠ 坑 2

m 和 n 别搞反。 m = 样本数 = 表格行数（有几栋房子）；n = 特征数 = 输入列数（每栋看几个属性），到第 5 模块「多元回归」才登场。

✎ 记忆法

m 数 examples，n 数 features 的维度。互换是常见失分点。

⚠ 坑 3

y 和 ŷ 是两个东西。 y = 真实观测值；ŷ = 模型猜出来的值。整门课的全部工程，就是想办法让 ŷ 尽量接近 y——后面的残差、代价函数、梯度下降全围绕这句展开。

Study check课件原题：表里 x⁽³⁾ 和 y⁽³⁾ 分别是什么？▸

第 3 行：x⁽³⁾ = 1.5（千平方英尺），y⁽³⁾ = 190（千美元）。注意不是 1.0² 也不是第 0 行——索引从 1 开始数。

P.07The Simple Linear Regression Model

The Model 一元线性回归模型

fw,b(x) = wx + b   （也写作 ŷ = wx + b）

1先卸下心理负担

课件备注开门见山：这就是你中学学过的 y = mx + c，只是换了字母。

中学机器学习
m（斜率）w — weight / slope，权重 / 斜率
c（截距）b — bias / intercept，偏置 / 截距

没有任何新东西。真正新的是「怎么自动找到最好的 w 和 b」，那是后面几页的事。

2w 和 b 各自是什么

  • w — 斜率：y 每随 x 变化一个单位而改变多少。房价里回答：每多 1000 平方英尺，预测价格增加多少。
  • b — 截距：x = 0 时的预测值。
⚠ 重点

b 常常在物理上没有意义。面积为 0 的房子并不存在，也没有价格。但这完全没问题——b 只是一个垂直偏移量，让直线坐到正确的高度上，它本身不需要能被解释。很多学生在这里纠结，不必。

3关键术语：参数 vs 超参数

参数 Parameters超参数 Hyperparameters
例子w、b学习率 learning rate
谁定的从数据中学出来我们自己选
算法会调吗会不会，算法从不碰它

一句话：参数是学出来的，超参数是我们挑的。考试常考，别混。

§ 去神秘化

训练 = 在所有可能的 (w, b) 组合里搜索，找出最好的那一对。没有更玄的东西。整个第 3、4 模块（代价函数、梯度下降）只是在回答「什么叫最好」和「怎么高效地搜」。

✎ 好习惯

单位检查：x 是千平方英尺、y 是千美元，那么 w 的单位 = 千美元 / 千平方英尺。养成检查单位的习惯，能帮你抓出很多计算错误。

Study check增大 w 会让直线怎么变？增大 b 呢？▸

增大 w → 直线旋转变陡（steeper）；增大 b → 直线整体向上平移。课件说这 30 秒互动很值——到后面「代价曲面」那页，你才会明白我们是在调两个互相独立的东西。

自己验一下：x = 2.0 → 72×2.0 + 78 = 222 ✓

三个重点

  1. 直线在「没见过的面积」上也能预测。表里没有 2.5，但直线照样算：72×2.5 + 78 = 258。这叫泛化（generalisation）——模型有用的根本原因。
  2. 没有任何一条直线能穿过全部 10 个点。这条线是一个折中，同时靠近所有点。回想 P4：抓趋势，不追点。
  3. 大白话解释：每多 1000 平方英尺，关联着大约多 7.2 万美元，在 7.8 万美元的基准偏移之上。
§ 语言纪律

说 associated with（关联），不要说 causes（导致）。把房子扩建 1000 平方英尺，并不会可靠地给它加上 7.2 万美元的价值。模型学到的只是观测数据里的一个模式，其中混杂着大量未被区分的因素（好地段、房龄、装修）。这是相关 ≠ 因果在本课的第一次出现，写报告和答题都要注意用词。

★ 这页的真正作用

这条线看上去很好，于是逼出下一页的问题：「好」到底按什么精确定义来衡量？——这就是 P9 开始的 residuals 和 cost function。

Study check你会怎么去衡量这条线有多好？（先自己想 10 秒）▸

答案就是下一页：用每个点的残差（residual）= y − ŷ，再把所有残差的平方加起来，就是代价函数。越小 = 这条线越好。
