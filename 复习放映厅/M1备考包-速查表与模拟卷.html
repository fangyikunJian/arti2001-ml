T1 · 流程、划分与泄漏

T1ML pipeline

问题定义 → 数据收集 → 探索与准备 → 划分 → 选模型 → 训练 → 评估 → 部署 → 监控与再训练

  • AI ⊃ ML ⊃ DL。ML 从数据中学规律，而非把规则显式写死。
  • 监督（有标签）／无监督／强化；监督内分回归（连续）与分类（类别）。
  • 部署后性能下降 → 先调查输入分布变化，收集有代表性的新数据，必要时重训并重新评估。

T1三份数据的职责

Train拟合模型参数（w, b）
Validation比较候选模型、选超参（kernel, C, γ, 阈值）
Test设置全部锁定后，只用一次，给泛化性能的无偏估计

定完超参后，可在 train+validation 上重新拟合，再动测试集。

Data leakage 的两种形态 —— 考试高频
① 预处理泄漏：在切分前用全量数据 fit scaler／填缺失值 → 验证集与测试集的统计量参与了变换。正确做法：Pipeline([("scale",StandardScaler()),("svc",SVC())])，scaler 只在 train 上 fit。
② 选择泄漏：用测试集挑 kernel／C／γ／阈值 → 测试集变成第二个验证集，最终估计乐观偏高。
两者的后果都是同一句话：performance may look better than it really is。

T2 · 回归与线性回归

T2模型与解析解

ŷ = w₀ + w₁x ŷ = wᵀx + b 单变量最小二乘： w₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)² w₀ = ȳ − w₁x̄ 正规方程（多变量／多项式）： XᵀX β̂ = XᵀY β̂ = (XᵀX)⁻¹XᵀY 多项式 y = ax²+bx+c 的设计矩阵： X = [xᵢ² xᵢ 1] (n×3), β = [a b c]ᵀ

可逆的前提是 X 列满秩（各列线性无关）。实际软件用 QR/SVD/伪逆而不是直接求逆，更稳定也能处理秩亏。

T2MLE ↔ 最小二乘

假设 εᵢ ~ N(0, σ²) 独立同方差： log L = −(N/2)log(2πσ²) − (1/2σ²)·SSE └─ 与 w 无关 ─┘ └ 负系数 ┘ ⇒ argmax log L = argmin SSE

一句话答法：Under independent, equal-variance Gaussian noise, OLS is also the maximum-likelihood estimator; if the noise assumption changes, a different loss may be appropriate.

T2评价指标

MSE = (1/N)Σ(yᵢ−ŷᵢ)² 单位是 y 的平方 RMSE = √MSE 与 y 同单位，可直接说"平均差多少" MAE = (1/N)Σ|yᵢ−ŷᵢ| 对离群值不敏感 R² = 1 − SS_res/SS_tot 模型解释的目标方差比例
  • R² = 0.85 意思是"解释了约 85% 的方差"，不是"85% 的预测正确"。
  • R² 可以为负（比用均值预测还差）。
  • 解释预测误差用 RMSE/MAE（有单位），比较模型用 R²。

T3 · 分类、感知机与逻辑回归

T3感知机

s = wᵀx + b ŷ = sign(s) 对每个样本算 y·s： 若 y·s ≤ 0 → 更新 w ← w + η·y·x b ← b + η·y 否则不动 更新的效果：把该样本的得分朝正确一侧推 收敛保证：仅当数据线性可分时，有限步收敛 输出：硬类别，没有概率

注意是 ≤ 0，所以 s = 0（正好在边界上）也要更新。一次 pass 不保证全部分对。

T3逻辑回归

z = wᵀx + b p = σ(z) = 1/(1+e⁻ᶻ) 预测 1 当 p ≥ 阈值（默认 0.5） 边界：z = 0，因为 σ(0) = 0.5 2x₁ − x₂ − 3 = 0 → x₂ = 2x₁ − 3 z > 0 的一侧是 class 1 BCE（平均）： J = −(1/N)Σ[yᵢ ln pᵢ + (1−yᵢ)ln(1−pᵢ)] 梯度： ∂J/∂w = (1/N)Σ(pᵢ−yᵢ)xᵢ ∂J/∂b = (1/N)Σ(pᵢ−yᵢ)

(pᵢ − yᵢ) 是带符号的概率误差：预测概率高于标签为正，低于为负。沿负梯度走一小步是局部下坡，所以损失下降。

T3阈值与指标

precision = TP/(TP+FP) 预测为正里真的比例 recall = TP/(TP+FN) 真正例里被找出的比例 accuracy = (TP+TN)/全部 F1 = 2·P·R/(P+R) 阈值 ↑（0.5 → 0.8）：正例预测变少 → precision 通常 ↑，recall ↓ 阈值 ↓：正例变多 → recall ↑，precision ↓ （阈值改变不会重算概率，只是重新切分）
类别不平衡：若测试集只有 9% 是正类，91% 的 accuracy 可能等于"全predict 负类"。必须先报多数类基线再比较，并看 precision/recall 与混淆矩阵。

T3多分类与"伪概率"

  • One-vs-rest：每类学一个得分，预测时取最大得分的那类。
  • 行归一化混淆矩阵按行读：每行是一个真实类别的去向；行内最大的非对角元就是主要混淆方向。
  • 把 others 这类"其他"合并类当成一个同质类别去解释是错的——它内部很异质。
感知机得分 ≠ 概率：得分符号给出类别、大小是模型自己尺度上的置信度，不限于 0–1。对它套 sigmoid 只是把数值压到 0–1，并没有用概率损失训练过，不是校准概率。

陷阱清单 · 考前 10 分钟看这栏

SVM：f(x)=0 是 margin violation，不是"正确分类"。yf<1 才叫 violation，yf<0 才叫误分类，别混。全宽是 2/‖w‖，单侧才是 1/‖w‖。
感知机：更新条件是 y·s ≤ 0（含等号）。更新后要用新参数处理下一个样本。
逻辑回归：改阈值不会重算概率，只是重新切分。阈值 ↑ → 正例更少。
R²：是解释的方差比例，不是"正确率"，也不是 1−MSE。
系数：不同尺度下不能比大小。符号才是可靠信息。
正态：求"介于 a 与 b 之间"必须 Φ(z_b) − Φ(z_a)，不是直接查一个值。
C 与 γ：C 管"违反的惩罚"，γ 管"影响的范围"。两个都调大 → 边界又窄又局部 → 过拟合。
核技巧：省的是"构造特征"，不是"计算量"。大数据上仍可能很贵。
训练准确率 1.00：不是好消息的证据，先怀疑记忆训练数据。
选超参：任何用测试集做的选择都会污染最终估计。选完要在 train+val 上重拟合，再碰一次测试集。

Q22

Evaluating claims about a fitted model (10 marks)

A student fits a linear regression on the California housing data and a logistic regression on an imbalanced medical screening dataset, then writes the following four claims in their report. For each claim, state whether it is correct, explain why, and give a corrected version. (4 × 2.5 marks)

  1. "The test R² is 0.72, so 72% of our predictions are correct."
  2. "The coefficient of MedInc is 0.45 and the coefficient of AveRooms is −0.02, so median income is about 22 times more important than average rooms."
  3. "Our screening classifier reaches 96% accuracy on the test set, so it is ready for deployment." (4% of patients in the data have the condition.)
  4. "We applied a sigmoid to the perceptron's decision scores, so we now have the probability that each patient has the condition."
参考答案与采分点

Claim 1 — Incorrect

R² 是被模型解释的目标方差比例，不是预测正确的比例。目标是连续变量，"预测正确"本身没有定义（任何预测几乎必然不等于真值）。

Corrected: "The model explains about 72% of the variance in median house value on the test set. To describe typical prediction error we should also report RMSE or MAE, which are in the same units as the target."

Claim 2 — Incorrect

两个特征的量纲和尺度不同（收入以万美元计、房间数以间计），系数的原始大小反映的是"每单位该特征变化对应多少目标变化"，单位不同就不可比，更谈不上"22 倍"。系数的符号是可靠信息（方向），大小不是。

Corrected: "MedInc is positively associated with median house value and AveRooms is negatively associated with it. To compare their relative influence we would need to standardise the features before fitting, or use a scale-free measure such as permutation importance."

Claim 3 — Incorrect（或 misleading）

只有 4% 的患者有该病症，因此永远预测"无病"就能得到 96% 的准确率。96% 可能恰好等于多数类基线，没有证据表明模型学到了任何东西。而且筛查场景下漏诊（false negative）的代价远高于误报，准确率把两类错误当成等价。

Corrected: "The 96% accuracy must be compared with the 96% majority-class baseline. We should report recall and precision for the positive class and inspect the confusion matrix, because accuracy averages across groups and treats all mistakes as equally costly."

Claim 4 — Incorrect

sigmoid 只是把任意实数压缩到 (0,1)。感知机是用硬分类的更新规则训练的，没有优化任何概率损失（如交叉熵），所以这些数值不是校准过的概率——0.9 不代表"90% 的这类病人真的患病"。

Corrected: "The transformed scores lie between 0 and 1 but were not obtained by training a probabilistic loss, so they are not calibrated probabilities. To obtain estimated probabilities we should fit logistic regression, which optimises binary cross-entropy, and evaluate them with log loss."

采分点（每条）：明确判定（0.5）· 说明为什么（1）· 给出可支撑的正确表述或所需证据（1）。

Identifying problems in a machine-learning procedure (10 marks)

A team reports the following procedure for a two-class problem with 2,000 observations and two numerical features on very different scales.

1 Load all 2,000 observations. 2 Fit a StandardScaler on all 2,000 rows and transform them. 3 Split the scaled data 80/20 into training and test sets. 4 For every combination of C ∈ {0.1, 1, 10, 100} and γ ∈ {0.1, 1}, fit an RBF SVC on the training set and evaluate it on the test set. 5 Keep the combination with the highest test accuracy (C = 10, γ = 1, accuracy 0.971). 6 Report 0.971 as the expected accuracy of the model on new data.

(a) Identify four distinct problems with this procedure. For each, name the problem and explain its consequence. (6 marks)

(b) Write a corrected procedure as a numbered workflow. (4 marks)

参考答案与采分点

(a) 四个问题 6 marks

① 预处理泄漏（Step 2 在 Step 3 之前）。scaler 的均值与标准差是用包含测试集的全部 2000 行算出来的，测试集的统计量因此参与了变换。模型间接"见过"了留出数据，测试表现会偏乐观。

② 没有验证集（Step 3）。只切了训练/测试两份，没有任何一份数据可以合法地用来选超参。

③ 用测试集选超参（Step 4–5）。在 8 个候选设置上反复读取测试准确率并挑最大值，等于把测试集变成了第二个验证集。挑出来的最大值还包含了"选择偏差"——8 次评估里的最大值本身就系统性地偏高。

④ 把 0.971 当作对新数据的期望表现（Step 6）。这个数字已被用于模型选择，不再是无偏估计，会系统性高估未来性能。

（其他可接受的第四点：没有报告类别分布或多数类基线，无法判断准确率是否有意义；切分时没有 stratify；只报单一指标而未报 precision/recall；只有一次划分、没有交叉验证，2000 条数据下 20% 测试集的估计方差不小。）

(b) 修正流程 4 marks

1 先切分：train / validation / test（分类问题用 stratify 保持类别比例， 固定 random_state 保证可复现）。切分必须发生在任何预处理之前。 2 把 StandardScaler 和 SVC 装进一个 Pipeline， 使 scaler 只在训练折上 fit，验证/测试只被 transform。 3 在训练集上拟合每个 (C, γ) 候选，在验证集上比较； 记录验证准确率和支持向量数，准确率相同时取支持向量更少的。 4 锁定选中的 kernel、C、γ，不再改动。 5 用锁定的设置在 train + validation 上重新拟合。 6 在测试集上评估一次，报告该结果作为泛化估计。 7 同时报告多数类基线与 precision / recall，说明结论的局限： 单次划分、有限网格，只对这份数据成立。

"Because the scaler was fitted on all rows before splitting, information from the test data influenced the transformation — this is data leakage. Combined with selecting C and γ on the test set, the reported 0.971 is optimistically biased and should not be described as the expected accuracy on new data. A finite grid on a single split identifies only the best tested setting for that split."

采分点：(a) 每个问题"命名 + 后果"各 1.5 分，必须点出 leakage 与 test-set 选择两大项。(b) 切分先于预处理（1）· Pipeline / 只在 train 上 fit（1）· 用验证集选超参并锁定（1）· 重拟合后测试集只用一次（1）。

(a) 选 kernel 3 marks

(b) C 的趋势与选择 3 marks

趋势：C 从 0.1 增到 100，支持向量数单调下降 120 → 71 → 36；验证准确率则先升后降，在 C = 1 达到峰值 0.917（0.861 → 0.917 → 0.903）。

选择：C = 1，验证准确率最高。（若出现并列，tie-breaker 用更少的支持向量，即更简单的模型；绝不能用测试准确率来打破平局。）

L2 · Linear Regression & Gradient Descent 1:18 — 全看

主线四点

  1. 假设与代价：hθ(x) = θᵀx，J(θ) = ½Σ(hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²。Ng 明确说线性回归又叫 ordinary least squares。
  2. 梯度下降：θⱼ ← θⱼ − α·∂J/∂θⱼ，α 是 learning rate。批量（每步扫全量，稳但慢）vs 随机（每步一个样本，快但在最优点附近震荡）。
  3. 正规方程：θ = (XᵀX)⁻¹Xᵀy。一步到位，不用迭代、不用选 α——代价是要求矩阵可逆。
  4. 概率解释：假设误差 ε⁽ⁱ⁾ ~ N(0, σ²) 独立同分布 ⇒ 极大似然估计等价于最小化平方误差。这就是 T2 Tutorial Q1 的整道题。

L3 · Locally Weighted & Logistic Regression 1:19 — 只看约 30 分钟

L6 · Support Vector Machines 1:20 — 必看，跳过前 20 分钟

主线五点 · 本课 T4 的地基

  1. 记号切换：标签改用 y ∈ {−1,+1}，h(x) = g(wᵀx + b)，截距 b 单独写出来（不再吸收进 θ₀）。这和本课的写法一致。
  2. functional margin γ̂⁽ⁱ⁾ = y⁽ⁱ⁾(wᵀx⁽ⁱ⁾ + b)。这就是本课的 y·f(x)。Ng 的直觉说法：它衡量你分类得"多有把握、多正确"。
  3. geometric margin γ⁽ⁱ⁾ = γ̂⁽ⁱ⁾/‖w‖。这就是本课的 y·f(x)/‖w‖。
  4. 为什么需要规范化：把 (w,b) 同时放大 k 倍，functional margin 也放大 k 倍，但边界没动——所以单看 functional margin 没有意义。令它等于 1（canonical scaling），最大化间隔就变成 min ½‖w‖²，于是单侧间隔 = 1/‖w‖、全宽 = 2/‖w‖。
  5. 对偶与支持向量：解对偶问题后只有 αᵢ > 0 的样本参与决策函数，那些就是支持向量。

L7 · Kernels 1:20 — 必看

主线五点

  1. 先把算法改写成只依赖内积的形式。Ng 花了很长时间做这件事——这是核技巧的前提：特征向量只出现在内积里，才有机会替换掉。
  2. 核函数 K(x,z) = φ(x)ᵀφ(z)：直接算这个内积，永远不构造 φ(x)。
  3. 所以维度可以极高甚至无穷。Ng 反复强调这一点：十万维、百亿维、无穷维的特征空间都能操作，因为你从没真的写下过那个向量。
  4. 高斯核（RBF）K(x,z) = exp(−‖x−z‖²/2σ²)，是最常用的非线性核；线性核 K(x,z) = xᵀz 对应 φ(x) = x。注意换算：sklearn 的 gamma = 1/(2σ²)，所以 σ 小 ⟺ gamma 大 ⟺ 影响局部 ⟺ 易过拟合。
  5. 软间隔：min ½‖w‖² + C·Σξᵢ，对偶约束从 αᵢ ≥ 0 变成 0 ≤ αᵢ ≤ C——C 成了单个样本影响力的上限。
讲义 notes3：p1–6 特征映射与核技巧 · p6 核的性质（Mercer 条件）· p24 软间隔与 C（必读） 本课对应：T4 Tutorial Q3（φ 展开证明等于 (xᵀy)²）· T4 Tutorial extension（0 ≤ α ≤ C）· T4 Practical 的 kernel/C/gamma 比较 跳过：SMO 算法（notes3 p25–30，本课不考）

L8 · Data Splits, Models & Cross-Validation 1:23 — 必看，大题的出处

主线四点

  1. 偏差 / 方差：欠拟合 = 高偏差（模型太简单，线性函数拟合曲线数据）；过拟合 = 高方差（换一批样本，拟合结果会大不相同）。Ng 说这个概念"容易懂、难精通"。
  2. 三分数据：训练集定参数，dev（= 本课的 validation）集做选择，测试集报告。
  3. hold-out cross validation 就是本课用的单次验证划分；另有 k-fold 与 leave-one-out，数据少时用。
  4. 不能拿 dev 集的成绩当最终结果——因为算法已经针对 dev 集优化过了。
