T1 · PCA 与降维 速查

整条计算链（手算大题就考这个）

① 均值 μ = 每一列的平均 自检：算完两个数就停下核对 ② 中心化 Xc = X − μ（逐行减） 自检：Xc 每一列加起来 = 0 ③ 散布阵 S = Xcᵀ Xc 对称；对角线 = 各列平方和 协方差 Cov = S / (n−1) n = 观测个数 ④ 特征值 解 det(S − λI) = 0 自检：Σλ = 迹(S)　Πλ = det(S) ⑤ 特征向量 解 (S − λI)v = 0，再归一化 ‖v‖=1 ⑥ 排序 λ 从大到小；最大 λ 对应 PC1 ⑦ 投影 Z = Xc W（一维时 z = Xc·v₁） 自检：得分之和 = 0 ⑧ 重构 X̂ = Z Wᵀ + 1ₙ μᵀ ⚠ 别漏加 μ ⑨ 解释方差 rⱼ = λⱼ / Σλ 分母是全部特征值之和
本课约定（Tutorial 写死的，考试按这个）
  • S = Xcᵀ Xc 叫散布矩阵；Cov = S/(n−1) 才叫样本协方差。没除就叫协方差会被扣。
  • S 与 Cov 的特征向量完全相同，特征值差 (n−1) 倍，解释方差比完全一样。 ⇒ 手算直接用 S（整数好算）；只有问「方差是多少」或要对 sklearn 的 explained_variance_ 时才除 (n−1)。
  • CS229 用 (1/n)Σxxᵀ 且式子里没有 μ（它前一步已预处理）——三种写法主方向相同，别被绊倒。
  • 成分的符号是任意的：v 与 −v 张成同一条轴，得分整体变号，子空间与重构完全不变。

两个必须记住的算例

Tutorial 原题（退化 / 秩一）
X = (2,3) (3,5) (0,−1) (−1,−3) μ = (1, 1) Xc = (1,2) (2,4) (−1,−2) (−2,−4) ← 四点共线 S = [[10, 20], [20, 40]] Cov = S/3 λ² − 50λ = 0 ⇒ λ = 50, 0 （和 = 迹 50 ✓ 积 = 0 ✓） v₁ = (1, 2)/√5 得分 = √5, 2√5, −√5, −2√5 解释方差 = 50/50 = 100%，重构误差 0

⚠️ 这是刻意设计的退化例子（λ₂=0），一维就能完整重构。别把 100% 当常态。

by-hand 公开例（非退化 / 更常考）
X = (−3,0) (3,0) (0,−1) (0,1) μ = (0,0) ⇒ Xc = X S = [[18, 0], [0, 2]] 对角阵，λ 直接读 Cov = S/3 ⇒ 方差 6 与 0.667 解释方差比 = 18/20, 2/20 = 0.9 / 0.1 保留 PC1（水平）后：(0,±1) 都被重构到 (0,0) 总平方重构误差 = 1 + 1 = 2 = 被丢的 λ₂

用途：证明「保住 90% 方差 ≠ 保住 90% 信息」——第二个特征的差异完全消失了。

为什么是特征向量（大题问「为什么选最大的 λ」时照抄）

取单位方向 v，投影得分 z = Xc v 投影方差 = vᵀ Σ v 在 ‖v‖=1 下最大化 ⇒ 拉格朗日 L = vᵀΣv − λ(vᵀv − 1) ∂L/∂v = 2Σv − 2λv = 0 ⇒ Σv = λv 代回：vᵀΣv = vᵀ(λv) = λ·vᵀv = λ ⇒ 目标函数的值就等于特征值本身，所以挑最大的 λ
第二条等价推导（加分点）
x = (xᵀu)u + r ，且 r ⊥ u 勾股： ‖x‖² = (xᵀu)² + ‖r‖² 对所有点求和： Σ‖x‖²（常数，与 u 无关） = Σ(xᵀu)² + Σ‖r‖² ⇒ 最大化投影方差 ⟺ 最小化正交重构误差

被问「PCA 在优化什么」时，给出两种等价表述并说明为什么等价，明显高出一截。

保方差 ≠ 保意义

  • PCA 只用 X 拟合、不看 y。高方差方向可能是量纲、光照、批次效应；低方差方向可能才分得开类别。
  • ⇒ PCA 对下游可能提升、可能降低、也可能没影响，只能在验证集上比较。
  • PCA ≠ 线性回归：回归有 y、最小化目标方向（竖直）的预测误差；PCA 无 y、最小化正交（垂直）重构误差。
  • 缩放：某特征 ×c ⇒ 其方差 ×c² ⇒ 主方向可能整个翻转。标准化后两特征方差都为 1，若协方差为 0 会出现 0.5/0.5 的特征值平局（PC1 方向不唯一，不是「载荷均等」）。
  • 泄漏：预测流程里先划分，scaler 与 PCA 只在训练集 fit，验证/测试集只 transform。

T2 · 聚类：K-means 与 DBSCAN 速查

K-means

目标（inertia / WCSS） J = Σᵢ ‖xᵢ − μ_c(i)‖² ← 是求和不是平均 分配步 c(i) = argmin_j ‖xᵢ − μⱼ‖² 可只比平方距离，不开根号 更新步 μⱼ ← 该簇所有点的均值（逐维平均） 停止 分配不再变 / 质心稳定 / 到最大迭代次数
为什么一定收敛（必考问答）

分配步把每个点放到最近的质心 ⇒ J 不增；更新步用均值，而均值正是使簇内平方和最小的点 ⇒ J 不增。 两步都不增，而且把 n 个点分到 k 个簇的方式只有有限多种 ⇒ 必然收敛。 但 J 是非凸的，收敛到的只是局部极小 ⇒ 需要多次初始化。

  • k-means++：第一个质心随机取自数据，之后偏好离已选质心远的点 ⇒ 起点分散。
  • n_init=10 是重启 10 次完整拟合、保留 inertia 最低的那次，不是迭代 10 轮。
  • 比较稳定性要比「成员」不比「标签号」：标签 0/1 互换但分组相同 ⇒ 同一个解。
  • 怕什么：k 要预先给定 / 尺度 / 初始化 / 非球形 / 离群点（而且每个点必须有标签，没有「噪声」选项）。
算例（一维，一轮就收敛）
观测 {1, 2, 8, 9}，k=2，初始质心 1 和 8 分配：{1,2} → μ₁ ； {8,9} → μ₂ 更新：μ₁ = 1.5 ，μ₂ = 8.5 J = (1−1.5)² + (2−1.5)² + (8−8.5)² + (9−8.5)² = 1 再分配一次分组不变 ⇒ 已收敛

稳定性对照：A(0,0) B(0,2) C(4,0) D(4,2)，k=2 {A,B},{C,D} → 质心 (0,1) 与 (4,1) → inertia = 4 {A,C},{B,D} → 质心 (2,0) 与 (2,2) → inertia = 16 ← 更差的局部解

选 k 的证据

  • inertia：全局最优的 inertia 随 k 增大不会上升（k=n 时为 0）⇒ 不能用「最小」选 k，只能看肘部（判断，不是规则）。⚠️ 实际拟合的多次运行会落进不同局部极小，所以观测到的 inertia 未必单调。
  • silhouette s(i) = (b−a)/max(a,b)，范围 −1~1。a = 到同簇其他点的平均距离（排除自己）；b = 到最近的另一个簇的平均点对点距离。近 1 = 匹配好；近 0 = 边界；负 = 更该属于别的簇。
  • silhouette 偏爱紧凑凸形簇，对弯曲/密度型结构会给出误导排序。评 DBSCAN 时要先排除噪声点（−1）并报告排除比例。
  • 官方决策表的形状要记住：分最高但不稳定的候选会被否掉，最终选多路证据一致的那个。

DBSCAN

邻域 Nε(x) = { z : ‖z − x‖ ≤ ε } ⚠ 包含 x 自己；取等号也算在内 core |Nε(x)| ≥ MinPts border 自己不够 core，但落在某个 core 点的 ε 邻域内 noise 两者都不是（sklearn 标签 −1） 扩张 只有 core 点能扩张簇；border 点加入但不再往外传
算例（一维，直接背）
A=0, B=0.5, C=1.0, D=3.0, E=3.4 ，ε=0.6, MinPts=3 A:{A,B}=2 B:{A,B,C}=3 C:{B,C}=2 D:{D,E}=2 E:{D,E}=2 ⇒ B 是 core；A、C 是 border（挨着 core 点 B）；D、E 是 noise 最终：簇 = {A,B,C}，噪声 = {D,E}
▶ 短片③（53 秒）演的就是上面这个算例：ε 窗口逐点扫过去，边扫边把这张判定表填出来

为什么先标 noise 的点会变 border：噪声标签在遍历中只是临时的——当后来访问到的某点被认出是 core 并开始扩张时，落在它邻域里的非 core 点就被吸收为 border。

  • 参数怎么影响：ε 太小 ⇒ 稠密区碎裂、大量点未分配；ε 太大 ⇒ 不同稠密区合并。MinPts 太小 ⇒ 弱模式被当成簇；太大 ⇒ 小的/低密度的真实组被丢成噪声。
  • 密度差异大的数据用一组全局 (ε, MinPts) 描述不好——这是 DBSCAN 的主要局限。
  • 先缩放，再选 ε：ε 的数值含义完全取决于特征单位。
  • −1 不等于「异常」：它只表示「在当前设置下没被分进任何稠密区」，不是数据错误的证据。
  • border 点的归属可能取决于遍历顺序（若同时够得着两个簇）；core 点组成的连通块才是稳定的。

T3 · 高斯混合模型与 EM 速查

模型与责任度

一维高斯 N(x | μ, σ²) = 1/√(2πσ²) · exp( −(x−μ)² / (2σ²) ) 混合密度 p(x) = Σₖ πₖ N(x | μₖ, Σₖ) πₖ ≥ 0 ，Σₖ πₖ = 1 责任度 rᵢₖ = πₖ N(xᵢ|μₖ,Σₖ) ÷ Σⱼ πⱼ N(xᵢ|μⱼ,Σⱼ) 分母就是混合密度 p(xᵢ) ⇒ 自检：Σₖ rᵢₖ = 1
三个必须分清的量

密度＝曲线的高度（可以大于 1，p(x) ≠ P(X=x)，后者恒为 0）； 概率＝曲线下的面积；责任度＝概率（0~1 且对成分求和为 1）。混淆这三个是最常见失分。

EM 两步

E 步：参数固定 → 算责任度 rᵢₖ M 步：责任度固定 → 更新参数 有效计数 Nₖ = Σᵢ rᵢₖ （分数，可非整数；Σₖ Nₖ = n） 权重 πₖ ← Nₖ / n 均值 μₖ ← (Σᵢ rᵢₖ xᵢ) / Nₖ ⚠ 分母是 Nₖ，不是 n 方差 σ²ₖ ← (Σᵢ rᵢₖ (xᵢ − μₖ^new)²) / Nₖ ⚠ 用刚更新的新均值，但用同一轮的旧责任度；除 Nₖ 不是 Nₖ−1（极大似然）
  • EM 每轮不降低对数似然，但会停在局部最优 ⇒ 多次初始化。
  • 为什么要这样交替：直接 MLE 会得到 log Σₖ πₖN(...)——log 里套求和，没有闭式解。EM 用 Jensen 不等式造下界：E 步挑 Q 让下界在当前参数处取等，M 步最大化下界，所以真似然只能升不能降。（考纲：会用 E/M 步即可，收敛性证明不考）
  • 初始化必须打破对称：两个成分若初始化成完全相同的参数，责任度恒为 0.5、更新后仍然相同，永远分不开。
两个必背算例

模型选择

AIC = −2 log L + 2p BIC = −2 log L + p · log n 一维 K 成分（每成分一个方差）： p = (K−1) + K + K = 3K − 1 权重 K−1 个自由度（须和为 1）+ K 个均值 + K 个方差 越低越好；BIC 惩罚更重（含 log n），样本越大越偏向简单模型
  • AIC 只能和 AIC 比，BIC 只能和 BIC 比，而且必须同一份数据、同一套特征。不要把 AIC 值和 BIC 值直接比大小。
  • 训练对数似然随复杂度上升 ⇒ 不能单独用它选 K。
  • 标准表述：「在这些候选中 K=k 在拟合与复杂度间取得最好平衡；但这不证明总体存在 k 个自然分组，也不证明高斯成分有科学意义。」

大题答题模板 四类，各背一套

评分公式（四类通用）

① 报出结果（数字/方向/判定） → ② 解释它说明什么（在当前表示下代表什么） → ③ 用可见证据支撑（解释方差 / silhouette / BIC / 稳定性 / 图） → ④ 说出证据的局限（它不能证明什么）。 大多数人停在第一步，那最多拿一半分。

Style A · 计算并解释（PCA 全链路 / k-means 一轮 / GMM 责任度+M步）

  1. 写出约定与公式：例如「Use S = XcᵀXc and Cov = S/(n−1)」「比较平方距离即可」「MinPts 含点自身」。一行，免费的分。
  2. 逐步计算，每个中间量都标名字：μ → Xc → S → λ → v → Z → X̂。算错时能定位，阅卷也看得见过程。
  3. 写出自检：列和为 0 / Σλ=迹 / 责任度和为 1 / ΣNₖ=n。这本身就是采分点。
  4. 解释：这个数字在当前表示下意味着什么。
  5. 局限：一句「它不能证明什么」。

Style B · 评价或纠正一个说法

每条说法三句话：

  1. 这个说法哪一部分是对的（先承认对的部分，别一上来全盘否定）。
  2. 哪一部分不成立，为什么（指出它混淆了什么、或忽略了什么假设）。
  3. 要怎样才能支持这个结论（补什么证据、做什么检查）。

例：「我们跑了一次 k=3，silhouette 0.69，所以恰好有三类。」 → ① silhouette 0.69 确实说明在当前表示下簇内紧凑、簇间分离尚可； ② 但它只描述所选表示下的几何，而且只跑了一次、偏爱凸形簇，不能确立「唯一的自然分组」； ③ 需要补：多次初始化与重采样的稳定性、对 k 与缩放的敏感性、形状与离群点的检视、簇摘要在应用上是否讲得通。

Style C · 找出机器学习流程中的问题

每个问题三段：是什么问题 → 会造成什么后果 → 怎么改。按这个顺序扫一遍流程：

  1. 特征与尺度：量纲差很多却没缩放？缩放了但方差差异本身有意义？
  2. 划分与泄漏：在全量数据上 fit 了 scaler / PCA 再划分？测试集自己 fit 了一次？
  3. 算法假设：用 k-means 处理弯曲结构？用一组全局 (ε,MinPts) 处理密度差异大的数据？
  4. 初始化与稳定性：只跑了一次？没设 n_init / random_state？
  5. 证据与结论：只报了一个分数？把簇/成分当成真实类别？把噪声当成异常？

Style D · 用证据比较方案并论证决策

  1. 先说判据：我要用哪几类证据来比（内部指标 / 稳定性 / 假设 / 有用性）。
  2. 逐候选给出证据，做成小表：候选 → 内部证据 → 稳定性 → 应用意义。
  3. 给出选择并说明理由：不是「分最高」，而是多路证据一致。
  4. 说明这个决定的代价与还需要什么检查。
  5. 收尾一句：这是有依据的判断，不是证明（a reasoned judgement, not proof）。

Q22 · 评价聚类结论

(a) 尺度问题（3 分）

消费额量程 0–80,000，到访次数 0–60，相差三个数量级。k-means 用欧氏距离， 消费额会完全主导距离，等于只按消费额分组，到访次数几乎不起作用。 建议：当两个特征应当同等贡献时做标准化（StandardScaler），并比较标准化前后的结果； 若量程差异本身有业务含义，则需要论证为什么保留。

(b) silhouette 支持什么（3 分）

0.71 说明在所选特征与缩放下，簇内较紧凑、簇间较分离。 但它不能确立「恰好存在三种类型」：① 它只描述当前表示下的几何； ② 它偏爱紧凑凸形簇，对弯曲或密度型结构会误导； ③ 只跑了一次，没有任何稳定性证据；④ 它不涉及 k 是否是唯一合理的选择。

(c) 两项进一步检查（4 分，每项 2 分：做什么 + 揭示什么）
  • 稳定性：用 n_init=10 并换多个随机种子/重采样重拟合，比较成员（不是标签号）。 揭示：这个划分是稳定结构还是某次初始化的偶然产物。
  • 对 k 与缩放的敏感性：比较 k=2,3,4 与标准化/不标准化的组合。 揭示：结论是否只在某一个特定设置下成立。
  • （其它可接受）看散点图与簇摘要（形状、离群点）；检查三个簇在业务上是否可解释、可行动。
收尾必须有的一句

「即使这些检查都通过，也只能说这是一个有依据的判断（a reasoned judgement）， 不是『恰好存在三种自然类型』的证明。」

Q23 · GMM 责任度

(a) 加权贡献： 0.2 × 0.90 = 0.18　　0.8 × 0.15 = 0.12 混合密度： p(x) = 0.18 + 0.12 = 0.30 (b) r₁ = 0.18/0.30 = 0.6　　r₂ = 0.12/0.30 = 0.4 检查：r₁ + r₂ = 1 ✓
(c) 为什么权重大的没拿到更大责任度（2 分）

责任度 ∝ 先验权重 × 该点处的成分密度，是两个因素的乘积再归一化。 成分 2 的权重是成分 1 的 4 倍（0.8 vs 0.2），但成分 1 在这个 x 处的密度是它的 6 倍（0.90 vs 0.15）， 密度上的优势压过了先验上的劣势，所以 0.18 > 0.12，最终 r₁ = 0.6 > r₂ = 0.4。 结论：混合权重只是先验，归属还取决于该观测处每个成分解释得有多好。

(d) E 步与 M 步（2 分）

E 步：参数固定，用当前的 π、μ、Σ 计算每个观测对每个成分的后验责任度。 M 步：责任度固定，把它们当作分数计数更新参数—— Nₖ=Σᵢrᵢₖ，πₖ=Nₖ/n，μₖ=Σᵢrᵢₖxᵢ/Nₖ。两步交替直到对数似然改善可忽略。

常见扣分

把 0.45/0.15 直接当概率相加；忘记先乘权重；责任度不做和为 1 的检查； 只说「E 步算责任度、M 步更新参数」而没说各自固定了什么；忘了补一句密度不是点概率。

Q24 · 诊断流程

(a) 三处问题（6 分，每处 2 分：是什么 + 后果）
  1. 在全部数据上 fit Scaler 与 PCA ⇒ 数据泄漏。 后果：若后续要评估或接下游模型，评估结果会偏乐观，因为测试集信息已进入均值与主方向。 正确做法是先划分，只在训练集 fit。
  2. 对弯曲带状结构用 PCA 降到一维再跑 k-means ⇒ 方法与几何不匹配。 PCA 只保留线性高方差方向，把两条带子投到同一条轴上会把它们压叠在一起； k-means 又假设紧凑凸形簇，会横切弯曲结构。后果：得到的两个簇很可能只是沿主轴切了一刀，与真实结构无关。
  3. k-means 只跑一次（未设 n_init / random_state）⇒ 没有稳定性证据。 后果：J 非凸，结果可能是某个较差的局部极小，且不可复现。
  4. （其它可接受的第三点）把「silhouette=0.61」当成「识别出自然分组」的证明—— silhouette 偏爱凸形簇，在弯曲结构上反而会偏袒错误的划分； 另外 92% 解释方差只说明保住了输入方差，不代表保住了区分两条带子的信息。
(b) 更好的方案与判据（4 分）

方案（2 分）：在标准化后的原始二维特征上直接用 DBSCAN， 因为它基于密度连通、能跟随弯曲形状，并且允许把稀疏点标为噪声； ε 用 k-距离图的拐点作为起点再在邻近值上做敏感性测试。 若必须用 k-means，则应保留二维、增大 k 并接受「一个真实结构被切成多个簇」再后处理。

判据（2 分）：① 几何检视——把标签画回散点图，看是否跟随了带状结构； ② 噪声比例——DBSCAN 是否把大量有效点丢成 −1； ③ 稳定性——在邻近的 (ε, MinPts) 上结果是否一致； ④ 若有下游任务，在验证数据上比较。 ⚠️ 不要用 silhouette 在两个算法之间做唯一裁判（它偏袒凸形）， 也不要跨算法比较 inertia（DBSCAN 根本不优化它）。
