M2 和 M1 最大的不同：没有 ground truth。 监督学习可以report一个准确率就完事；无监督没有那个数字。 所以这门课把评分重心整个挪到了「你凭什么相信这个结果」上——这就是为什么每道大题都要求你给证据、并说出证据不能证明什么。 记住这一句，四道大题的写法就定了。

三个主题 · 各记 3–4 条 + 头号陷阱

T1 · PCA 换表示

造连续的新坐标轴 —— 不产生任何簇标签

  • 先中心化；量纲不可比时再考虑标准化（要论证，不是默认动作）
  • S = Xcᵀ Xc 与 Σ = S/(n−1) 特征向量相同、特征值差 (n−1) 倍 ⇒ 主方向与解释方差比都不变
  • 约束 ‖v‖=1 下最大化 vᵀΣv ⇒ 拉格朗日解出 Σv = λv，且 vᵀΣv = λ（特征值就是该方向的投影方差）
  • 解释方差比 λⱼ / Σλ；重构误差 = 被丢掉的特征值之和
  • 只在训练集上 fit 一次，特征向量从此固定；测试集只 transform
头号陷阱：PCA 只最大化输入方差、从不看 y。所以「解释方差 95% 但分类变差」完全正常——被丢掉的低方差方向可能正是判别关键。要判断降维伤没伤到任务，只能用验证数据比。

T2 · 聚类 给分组

K-means 认到质心的距离；DBSCAN 认密度连通

  • K-means 两步：分配（质心此刻不动）→ 更新（搬到该簇均值）。目标 J = Σ‖xᵢ − μ_c(i)‖²
  • 为什么收敛：①每步不增 ②分配方式有限 ⇒ J 取值有限。两句都要写，只写第一句是半句
  • J 非凸 ⇒ 局部极小 ⇒ k-means++ 加 n_init 多次重启（n_init 是重启次数不是迭代次数）
  • DBSCAN：ε 邻域含自身、距离取等也算；core ≥ MinPts；border 属于簇但不能扩张；noise 只是当前设置下的标签
  • 「直接密度可达」定义里那个 「且 p 是核心点」 是一切的源头；因为可达不对称才需要「密度连通」
头号陷阱：silhouette 偏爱紧凑凸形簇，在弯曲结构上可能反而偏袒 K-means。评估 DBSCAN 时必须先排除噪声点（−1）并报告排除比例。范围是 −1 到 1，不是 0 到 1。

T3 · GMM 与 EM 给密度

责任度 + 完整的 p(x) —— 分组只是副产品

  • 生成故事：掷骰子选成分 → 从那个高斯抽点，骰子结果 z 没被记下来
  • z 是真实归属（one-hot，看不到）；r 是观测后的后验（0~1，每行和为 1）。EM 从未「猜出」z，只算出它的分布
  • 不能直接 MLE：求和号困在 log 里面，log(a+b) 拆不开 ⇒ 无闭式解。若 z 可见就退化成 GDA
  • E 步四步：算每成分密度 → 乘权重 → 相加得分母 → 各自除。分母就是 p(x)，每行和必为 1
  • M 步三步：N_k = Σr → π=N_k/N 与 μ 加权平均 → 协方差用新均值，分母一律 N_k
头号陷阱：方差分母是 N_k，不是 N 也不是 N_k−1（EM 是极大似然，不是无偏样本方差）。本讲算例里误用 N_k−1 会把 1.93/2.88 变成 5.16/10.09，整题全毁。

贯穿三块 · 四类证据 M2 的主线

官方标为 Core and assessable，而 PPT 几乎没讲

  • ① 内部结构：解释方差 / inertia / silhouette / 似然 / AIC / BIC
  • ② 稳定性：换随机种子（探优化敏感性）· 重采样（探采样稳定性）—— 两者问的不是同一件事
  • ③ 几何与表示：把标签画回散点图看形状；检查缩放与特征选择
  • ④ 领域有用性：这些组讲不讲得通、下游用不用得上
用法：被问「该选哪个 k / K / 算法」「这个结论可信吗」，就逐条扫这四类，每条都能得分。只报一个 silhouette 就下结论，最多拿一半分。

★ 4 道大题的命根子：答题四步

① 报结果
→
② 解释它说明什么
→
③ 用可见证据支撑
→
④ 说出局限

大多数人停在第①步，那最多拿一半分。第④步的句子直接从下表挑一句抄上去：

你报了什么就补这一句局限
解释方差 / 重构误差只说明保住了多少输入方差；PCA 从不看 y，是否伤到任务要用验证数据比
某个主成分的含义单个特征向量数值上不稳定，可信的是前 k 个张成的子空间
silhouette 数值只描述所选表示下的内聚与分离，且偏爱凸形簇
一次 k-means 的分组单次运行；J 非凸，可能是局部极小
DBSCAN 的噪声点只表示当前 ε 与 MinPts 下未进任何稠密区，不是异常值判定
GMM 的责任度是当前拟合模型下的后验，不是真实类别归属的已验证概率
BIC/AIC 最小的 K是模型选择的证据，不是「确实存在这么多自然分组」的证明
选定了某个 k / K这是 a reasoned judgement, not proof

全 M2 高频陷阱清单（考前扫一眼）

✗ 「PCA 降到二维就得到了两个簇」 ✓ 那只是视觉印象，簇要另外用聚类算法算——PCA 不产生任何簇标签
✗ 跨缩放比较 inertia ✓ 它带量纲，标准化前后不在同一尺度，根本不可比
✗ 用「inertia 最小」选 k ✓ k 越大 J 越小（k=n 时 J=0），永远指向 k=n
✗ 用「似然最大」选 K ✓ 加成分不会降低最好的训练似然，要用 AIC/BIC
✗ 看到实际 inertia/似然不单调就以为算错 ✓ 那是局部最优造成的，提高 n_init 再比
✗ n_init 是迭代次数 ✓ 是独立重启次数；迭代上限是 max_iter（k-means 与 GMM 都一样）
✗ 用标签一致率衡量聚类稳定性 ✓ 簇编号是任意的，要比「哪些点被分在一起」（GMM 的成分编号同理）
✗ DBSCAN 的 ε 邻域不含自身 / 距离等于 ε 不算 ✓ 都要算，错一个角色判定全错
✗ 以为 border 点也能继续扩张簇 ✓ 只有 core 能扩张（「直接密度可达」定义里的那个「且」）
✗ 把 DBSCAN 的 −1 当成「这是异常值」 ✓ 只表示当前设置下没进任何稠密区
✗ 「DBSCAN 不用调参」 ✓ 簇数不用给，但 ε 与 MinPts 比 k 更难设；ε 必须在缩放之后选
✗ 把 DBSCAN 在密度差异大时的失败归咎于调参不够 ✓ 那是方法的内在限制：一组全局参数描述不了两种「稠密」
✗ silhouette 范围是 0 到 1 ✓ 是 −1 到 1；负值表示该点也许更该属于另一个簇
✗ b(i) 用最近的点或最近的质心 ✓ 用最近的簇的点对点平均距离；a(i) 要排除自己（分母 |C|−1）
✗ 把 p(x)=0.2 读成「20% 的概率」 ✓ 连续变量的 p(x) 是密度，可以大于 1；概率要对区间积分
✗ 成分数 = 峰数 ✓ 两个成分靠得近、方差大时叠出单峰；单峰推不出只有一个成分
✗ 混合方差 = 各成分方差的加权平均 ✓ 还要加上成分均值之间的差异那一项
✗ 有效计数 N_k 要凑整 / 是「责任度超过 0.5 的点数」 ✓ 是期望计数，0.9 就贡献 0.9；Σ N_k = N 是自检点
✗ M 步均值除以 N ✓ 除以 N_k——这是加权平均。x=0 的点对分子贡献 0，但责任度仍进分母
✗ 方差用旧均值 / 用四舍五入后的均值 ✓ 用刚算出的新均值，且全程保留完整精度
✗ 把 σ² 当成 σ ✓ 本课一维高斯的第二个参数是方差；NumPy 的 random.normal 用的是标准差
✗ 用 predict 汇报软归属 ✓ predict 丢掉不确定性，要用 predict_proba；score_samples 给的是对数密度
✗ 全量数据上 fit PCA 后再切分 ✓ 数据泄漏；测试集上重新 fit 则是坐标系不一致。正确：split → train 上 fit → 同一变换 transform 两边
✗ 认为收敛 = 找到最优解 ✓ k-means 与 EM 都只保证不变差，停在局部最优
