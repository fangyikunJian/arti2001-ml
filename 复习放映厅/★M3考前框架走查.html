睡醒后 ~50 分钟走一遍这张图，把 T1–T3 锁成一根主线。这是框架不是速查表——公式细节看备考包。Week 13（11 月 9–15 日），在你排定的 assessment / practical 时段。⚠ Canvas 的 due-date 字段是空的，页面写明「空的截止日期不代表考试没排」。

整个 M3 就一条链

前向：用当前参数算出预测
→
损失：和目标比，得一个数
→
反向：算每个参数的梯度
→
更新：优化器改参数
→
评估：用留出证据判断
三个 Topic 不是三个话题，是同一条链被切成三段。 T1 让一个神经元把这条链从头走到尾（所以 T1 的算例最完整）； T2 把链加宽——多了隐藏层、多种激活与损失、一次处理一批； T3 退后一步问：这条链产生的结果，凭什么可信。
⭐ 所以每道大题的套路都一样：先把数算对，再说这串数说明了什么、不说明什么。 官方评分口径原话：A correct final number alone may not demonstrate the required understanding.

三个主题 · 各记 4–5 条 + 头号陷阱

T1 · 神经网络基础 走完整条链

一个神经元 + sigmoid + BCE，所有公式都在这一课定型

  • 前向 z = Σwᵢxᵢ + b，p = σ(z)。此刻还没有学习发生——参数没变，目标 y 也还没被用到
  • 损失用概率不用阈值后的类别：y=1 ⇒ L = −log p。p=0.75 和 p=0.90 判类相同，但损失不同——这就是阈值之外多出来的信号
  • δ = ∂L/∂z = p − y（sigmoid+BCE 专属化简），再往回 ∂L/∂wᵢ = δ·xᵢ、∂L/∂b = δ
  • 更新 θ ← θ − η·∂L/∂θ。全部梯度用更新前的原参数算完，再一起更新
  • 计算图：一条路径内部相乘，多条路径汇合相加。官方小例 q→r=2q、q→t=3q、F=r+t ⇒ dF/dq = 5（只算一支得 2，漏了）
头号陷阱：「sigmoid 是非线性的，边界应该是曲线」——错。阈值 0.5 对应 z = 0，两个输入时那是一条直线。而且限制来自「仿射分数 + 单调激活 + 固定阈值」这个组合，不是单纯因为只有一个神经元——多个仿射层叠在 sigmoid 前面，直边界照旧。所以异或型数据再训练多久也分不开，「再 train 久一点」是错误选项。

T2 · 训练神经网络 把链加宽

激活怎么选、损失怎么配、隐藏层怎么拿到梯度

  • 输出值和导数是两件事：a 往前传，g′(z) 在反向乘在传回的梯度上。大的输出不代表大的梯度
  • 导数要会默写：σ′ = σ(1−σ)、tanh′ = 1 − tanh²、ReLU′ = 0/1。本课约定 ReLU′(0) = 0、Leaky′(0) = α = 0.01
  • 配对：回归→线性+MSE/MAE；二分类→sigmoid+BCE；互斥多类→softmax+CCE；多标签→每标签一个 sigmoid+BCE（和不必为 1）。整数标签用 sparse 版
  • 隐藏层梯度四步：(p−y) → ×输出权重 vⱼ → ×g′(zⱼ) → ×xᵢ。上层权重会出现在下层梯度里，因为影响必须穿过输出层
  • batch = 算一次更新用的那组观测；epoch = 过完一遍训练集。100 个 / 批 20 ⇒ 1 epoch = 5 次更新。平均损失的 1/N 只除一次
头号陷阱：某个隐藏 ReLU 对这个观测不激活时，它的输入权重梯度全是 0，这一步整个单元不动；同时 h=0 的那个输出权重梯度 = (p−y)·0 = 0，也不动。考场上漏掉这两处「没变」直接丢分。⚠ 但「这个样本上输出 0」≠「这个单元死了」——要在相关的那批输入上一直不激活才叫死亡 ReLU。

T3 · 模型评估 凭什么可信

划分 → 不泄漏 → 诊断 → 选阈值 → 只评估一次

  • 三角色：训练=拟合（含缩放与填补参数）、验证=一切选择（含阈值与停止点）、测试=评估冻结的流程，一次
  • 防泄漏五步：先划分 → 只在训练集上算预处理参数 → 原样应用 → 用验证选 → 测试评一次。⚠ 不用标签也会泄漏（[0,2] 均值 1，混入 100 就变 34）
  • 划分方式要复现「新数据怎么来」：不平衡→分层；同源记录→分组；预测未来→按时间。随机划分不是自动合适的
  • 指标：precision 分母 TP+FP，recall 分母 TP+FN，F1 = 2TP/(2TP+FP+FN)，不含 TN。先声明哪一类是正类
  • ROC：两个分母固定，加正例往上、加负例往右；AUC 两种算法（梯形 / 正负配对，平局半胜）互相验算
头号陷阱：正例稀少时 accuracy 和 AUC 都会骗人。1000 个里只有 10 个正例、TPR=0.8、FPR=0.1 ⇒ FP = 0.1×990 = 99 ⇒ recall 80% 但 precision 只有 8/107 ≈ 7.5%。原因是两者分母完全不同。⚠ 单独改变 prevalence 不一定改变 AUC，但 precision 可能天翻地覆——所以要同时看 precision–recall 和 prevalence。

贯穿三块 · 算完之后说什么 M3 的主线

这一栏是大题后半段的全部分数

  • ① 这个数说明了什么：概率朝目标移动 / 损失下降 / 某条路径梯度为零
  • ② 机制是什么：是哪个局部导数、哪条路径、哪个分母在起作用
  • ③ 它没有说明什么：单样本的改进不是泛化的证据；诊断模式不是证明；排序好不等于校准好
  • ④ 该怎么做才算规范：用验证证据选、冻结、在没碰过的测试集上评估一次
用法：任何一道大题，前半段把数算对拿基础分，后半段逐条扫这四项。⚠ 只写最终数字，官方明说「可能不足以体现所需的理解」。

★ 4 道大题的命根子：答题四步

① 报结果
→
② 解释机制
→
③ 给证据
→
④ 说出局限

大多数人停在第①步，那最多拿一半分。第④步的句子直接从下表挑一句抄上去：

你报了什么就补这一句局限
一次更新后损失下降只证明在这一个训练样本上有改进，不是泛化的证据；要再走一步必须重新跑前向、重新算梯度
某个参数的梯度更大只反映那个输入的数值更大，不构成「这个特征更重要」的排序
某个隐藏单元梯度为 0只说明它对这个观测不激活，不等于这个单元死了
训练损失一直在降只说明在拟合训练目标，不说明能预测没见过的数据
某个学习率一步后损失最低只是单步结果，一步走得远不等于长期收敛得好；也只属于这个批次和这个起点
平均损失下降了不代表每个样本都被正确分类——讲义算例里跑完 100 次更新，仍有一个正例停在 0.4859
训练强、验证差可能过拟合；在归因于方差之前还要检查分布差异、验证样本过小、以及泄漏
一个划分给出的分数是对未见数据表现的估计；不保证泛化，也不保证分布漂移下的稳健性
五折交叉验证的平均不是五次独立实验（训练集互相重叠），仍依赖抽样与划分假设
很高的 accuracy可能被大量负例主导；要和「全判多数类」的基线比，并说明两类错误的代价
一个 AUC 数值概括的是整条曲线的排序能力，不决定阈值、不衡量校准、不编码代价；AUC=1 只说明在这个样本上排序完美
选定了某个阈值依赖代价假设；代价一变结论可能翻转，不存在普适最优的阈值

全 M3 高频陷阱清单（考前扫一眼）

把激活输出 a 当成参数。参数只有权重和偏置；a、z 是每个样本现算的中间值。
以为前向传播里用到了 y。没有——y 是后面算损失时才用来评判这个预测的。
先把 p 四舍五入成类别再取对数。BCE 用概率本身，否则连续的学习信号就没了。
算一个参数就更新一个。全部梯度用同一个（更新前）状态算完，再一起更新。
把 1−g² 当成 sigmoid 的导数。1−g² 是 tanh；sigmoid 是 g(1−g)。
ReLU′(0) 填 1。本课约定 0；Leaky ReLU 在 0 处是 α = 0.01。
看到 Leaky ReLU 输出 −0.02 就以为导数是负的。导数是 +0.01——输出的符号和斜率的符号是两回事。
把梯度消失全归给激活函数。真实梯度还包含权重与多条路径的求和，激活斜率只是一个成因。
多标签任务用 softmax。多标签是每个标签一个 sigmoid，各自输出不必加起来等于 1。
用 from_logits 的损失时又套了一次激活。这类实现内部已经做了 sigmoid / softmax。
把 ∂ℓ/∂p 和 ∂ℓ/∂z 混用。p − y 是对 logit 的导数，已经含了 sigmoid 的链式因子。
平均损失在每一层又除一次 N。1/N 只除一次。
以为 tape.gradient 会更新参数。assign_sub 才更新；tape 只记录与求导。
以为自动微分能保证模型好。它不替你选目标、不修数据泄漏、不保证学习率合适。
划分之前对全部数据做缩放或 PCA。只在训练折内部拟合——不用标签一样会泄漏。
同一个人的记录分散进训练和测试。用分组划分，否则测得的不是「对新病人的表现」。
在测试集上挑阈值或挑模型。用验证集；测试集只评估一次冻结的流程。
看过测试结果后又继续开发。那个测试集已成为开发历史的一部分，新结论需要一次全新的独立评估。
「训练强验证差 ⇒ 方差高」一口咬定。先排除分布差异、验证集过小、泄漏。
照搬 sklearn 的混淆矩阵顺序。先读行列标签；本课是 [[TP,FN],[FP,TN]]，sklearn 是 [[TN,FP],[FN,TP]]。
把 F1 里的 P 当成概率。P 是 precision，R 是 recall。
以为降低阈值 precision 一定变好。recall 不会下降，precision 可升可降。
用 AUC 回答「该用哪个阈值」。AUC 不决定阈值、不衡量校准、不编码代价。
AUC < 0.5 就把预测反过来用。先检查分数方向、标签约定和抽样。
只写最终数字。官方：只给正确数字可能不足以体现所需的理解。
