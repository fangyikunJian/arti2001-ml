# ARTI2001 M1 复习放映厅 · 说明

这是为 Module 1（T1–T4）做的全部复习网页与源码的本地备份（从 Claude Code 的临时目录拷过来，防止过期）。

## ⚠️ 打开前必看
- **直接双击 `.html` 就能在浏览器打开**，不用装任何东西。
- **需要联网**：放映厅影片里的公式和图，是靠 CDN（cdnjs 的 MathJax、d3）实时渲染的。
  联网时一切正常；**断网时影片里的公式/图会显示不出来**（文字讲解仍在）。
  - `★考前框架走查` 和 `M1备考包` 这两个不依赖公式库，**断网也完整显示**（字体会退回系统默认）。
- 想打印带进考场：用 `★考前框架走查` 和 `M1备考包`，里面有打印按钮 / 直接 Ctrl+P。

## 源码/ ：怎么改 / 重新生成
- `eng.txt` = 放映厅引擎（所有 CSS + 放映机 + 绘图工具箱，暗色主题）。
- `build_*.py` = 各片子的生成脚本（Python，无需第三方库）。改内容改这些，重跑生成 `*-ppt.html`。
  - `build_hub.py` 把各片子合并成总入口 `hub.html`（读 `eng.txt` + 各 `*-ppt.html` + `cs_docs.json`）。
  - `build_t4deep.py` = 深度版 SVM；`build_t1/t2/t3/t4.py` = 官方课件版；`build_notes1/3.py` = CS229 讲义。
- `cs_docs.json` = CS229 讲座片的 base64（内嵌用）。
- `ppt_M1T*.txt` = 从官方 PPT 提取的文字（写讲解的素材）。
- 生成方法：在本文件夹的上一级放一份 `eng.txt` 同目录下运行，例如 `python build_t4deep.py`（脚本从当前目录读 `eng.txt`）。

## 2026-09-07 补的两处修复

这两个 bug 是做 COMP3011 那套放映厅时发现的，已经回补到本文件夹的全部 19 个 HTML
（含 hub 里以 base64 内嵌的 4 部 CS229 讲座片）和 `源码/eng.txt`。
**改之前的原文件整份备份在 `_备份-修复前/`**，要还原直接拷回来覆盖即可。

1. **本地打开中文乱码** —— 这些 HTML 都以 `<title>` 开头、没有 `<meta charset>`。
   在线 artifact 正常是因为外壳补了 charset；本地双击时浏览器按系统编码猜就会乱码。
   → 每个文件开头补了 `<meta charset="utf-8">` 和 viewport。

2. **切到后台再回来，上一镜的大字会半透明残留** —— `setCap/setBig/setEq/setTitle`
   靠 `.off` 类把 opacity 过渡到 0 来隐藏；页面不在前台时 CSS 过渡会停在中途，
   实测 class 已经是 `off` 而 computed opacity 仍然是 **0.96**，于是上一镜的
   `#big` 大字压在当前镜内容上。同源的另一个症状是**总结卡卡在看不见**——
   `showSum/askQ` 用 `setTimeout(50~60ms)` 去掉 `.off`，后台标签页里这个定时器
   会被节流，卡片就永远停在 opacity 0。
   → CSS 加 `#big.off,#cap.off,#eqBox.off,#titleBox.off,#sum.off,#quiz.off{visibility:hidden}`
     （`visibility` 不参与过渡，加上 `.off` 那一刻就真的不可见；淡入照旧，淡出变成立即消失。
     用 `visibility` 而不是 `display:none`，是因为 `flip()` 要靠 `getBoundingClientRect`
     量位置，`display:none` 会量成 0）；
     `showSum/askQ` 改成 `hidden=false` → 强制 reflow → **同步**去掉 `.off`，不再依赖定时器。
