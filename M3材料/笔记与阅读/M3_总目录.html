★ 考前最后一小时：只看这几处

主题最该确认的东西
T1 算例z → p → L → δ → 梯度 → 更新 → 复查这一串；δ = p − y、∂L/∂wᵢ = δ·xᵢ、∂L/∂b = δ；所有梯度用更新前的原参数算完再一起更新
表达能力单个 sigmoid 神经元的决策边界必然是直线；限制来自「仿射分数 + 单调激活 + 固定阈值」这个组合，不是单纯因为只有一个神经元；「再 train 久一点」是错误选项
激活函数σ′ = σ(1−σ)、tanh′ = 1 − tanh²；本课约定 ReLU′(0) = 0、Leaky′(0) = α；输出的符号和斜率的符号是两回事（Leaky 在 −2 处输出 −0.02、导数 +0.01）
输出–损失回归→线性 + MSE/MAE；二分类→sigmoid + BCE；互斥多类→softmax + CCE；多标签→每标签一个 sigmoid + BCE；整数标签用 sparse 版；⚠ from_logits 的实现不要再套一遍激活
隐藏层梯度四步：(p−y) → ×输出权重 → ×激活导数 → ×输入；某单元不激活 ⇒ 它的输入权重梯度全为 0；h=0 的那个输出权重梯度也是 0
batch/epoch100 个观测 / 批大小 20 ⇒ 1 epoch = 5 次更新；1/N 只除一次；平均改善 ≠ 每个样本都改善
自动微分tape 记录涉及 tf.Variable 的前向运算；tape.gradient 返回梯度但不更新参数；assign_sub 才改参数
泄漏先划分 → 只在训练集上算预处理参数 → 原样应用 → 用验证选 → 测试评一次；不用标签也会泄漏（[0,2] 均值 1，混入 100 变 34）；「无监督」≠「可以在测试集上拟合」
指标先声明正类，再逐格读行列标签——⚠ 讲义页是 [[TP, FN], [FP, TN]]、T3 复习课件是 [[TN, FP], [FN, TP]]（左上角 TN，同 sklearn），两份官方材料顺序相反；precision 分母 TP+FP、recall 分母 TP+FN；F1 = 2TP/(2TP+FP+FN)，不含 TN
ROC/AUC加正例往上、加负例往右；两个分母固定；配对法：随机正例分数更高的概率，平局算半胜，和梯形法互验；AUC 不决定阈值、不衡量校准、不编码代价
⚠ 四条最容易丢分的「概念性」答法
  • 凡是问「这次更新/这次损失下降说明了什么」，必须答「只证明在这一个样本（或训练集）上有改进，不证明泛化」；
  • 凡是问「训练强验证差」，先写「可能过拟合」，再补一句「在归因于方差之前，还要检查分布差异、验证样本过小、以及泄漏」；
  • 凡是涉及阈值，必须写「在验证数据上用代价与约束来选，然后冻结，最后在没碰过的测试集上评估一次」；
  • 凡是问「反向传播和梯度下降」，必须写成两件工作：反向传播算梯度、梯度下降用梯度改参数，反向传播本身不改任何权重。
