第 1 组：一个神经元做什么（T1-1 §1）
1. 一个人工神经元依次做哪三件事？
A. 过激活函数 → 加权求和 → 加偏置
B. 加权求和 → 加偏置 → 过激活函数
C. 加偏置 → 过激活函数 → 加权求和
D. 加权求和 → 过激活函数 → 加偏置
2. 下面哪一组量是训练时会被更新的「参数」？
A. 输入特征 x 与目标 y
B. 预激活 z 与激活输出 a
C. 权重 w 与偏置 b
D. 权重 w、偏置 b 与激活输出 a
3. 偏置 b 的作用是什么？
A. 与当前输入无关地平移分数
B. 给每个输入特征一个各自的缩放倍数
C. 把分数压缩到 0 和 1 之间
D. 决定隐藏层里有几个神经元
4. 某个输入的权重是负的，这意味着：
A. 该输入必须先取绝对值再参与计算
B. 该输入的数值越大，分数越大
C. 该输入会被忽略
D. 该输入的数值越大，分数越小
5. x = [1, 2]，w = [0.2, 0.4]，b = 0.1，则预激活 z 等于多少？
A. 0.7
B. 1.1
C. 1.0
D. 1.3
答案与解析
1. B —— z = w₁x₁ + w₂x₂ + b 先得到预激活，再 a = g(z)。⚠ 偏置是加在激活函数之前的。
2. C —— 只有权重和偏置是存下来的可调量。z 和 a 是每个样本现算的中间值，x 和 y 是给定的数据。⚠「优化器调整哪些量」是高频概念题。
3. A —— 偏置不乘任何输入，只整体平移 z。缩放是权重的事，压缩到 (0,1) 是 sigmoid 的事。
4. D —— 正权重 ⇒ 输入变大分数变大；负权重 ⇒ 反之。权重为 0 才是忽略该输入。
5. B —— 0.2×1 = 0.2，0.4×2 = 0.8，z = 0.2 + 0.8 + 0.1 = 1.1。这是贯穿整个 Topic 1 的那个算例。

A. 被用来计算预激活 z
B. 被用来决定判类阈值
C. 被用来初始化权重
D. 完全没有被用到
3. 跑完一次前向传播之后，网络的参数发生了什么变化？
A. 什么都没变，所以还没有发生学习
B. 权重变了，偏置没变
C. 权重和偏置都朝降低损失的方向变了一点

4. 只把 b 从 0.1 提到 0.6、其余不变，类别 1 的概率会怎样？
A. 下降，因为偏置变大会压低 sigmoid
B. 不变，因为偏置不乘输入
C. 上升，因为 z 从 1.1 变成 1.6
D. 先上升后下降，取决于输入的符号
5. 某模型对一个样本给出 p = 0.99。仅凭这个数可以断定什么？
A. 什么都不能断定——高置信度既不等于学过，也不等于正确
B. 这个预测一定是正确的
C. 它至少在训练集上已经收敛
D. 它的参数一定是从数据里学来的
答案与解析
1. C —— 0.750260 ≥ 0.5 ⇒ 判类 1。⭐ 概率（≈0.75）和类别标签（1）是两个不同的量，考试很爱考这个区分。
2. D —— ⚠ 前向传播只用当前参数把输入算到输出，y 在这一步没有被用到，它是后面算损失时用来评判这个预测的。
3. A —— ⚠ 前向传播不改变任何参数。改参数要等反向传播算出梯度、梯度下降执行更新之后。
4. C —— z = 0.2 + 0.8 + 0.6 = 1.6，sigmoid 递增 ⇒ 概率上升。这是讲义给的自测题。
5. A —— ⚠ 讲义原文的自测点：高置信度 ≠ 学过 ≠ 正确。随便设一组参数也能产生 0.99。
第 3 组：为什么一个神经元不够（T1-1 §3）
1. 单个 sigmoid 神经元在两个输入下的决策边界是什么形状？
A. 若干条互相平行的直线
B. 一条 S 形曲线，因为 sigmoid 是非线性的
C. 一个圆，半径由偏置决定
D. 一条直线
2. 「sigmoid 明明是非线性的，为什么决策边界还是直的？」正确的解释是：
A. sigmoid 在 0 附近可以近似成线性，所以边界近似是直线
B. 概率输出确实非线性，但类别改变恰好发生在 z = 0 处，而 z = 0 是一条直线
C. 只有当权重很小时边界才是直线，权重大了就会弯
D. 因为计算时做了四舍五入，边界被近似成了直线
3. 两类数据各占对角线上的两个角（异或型）。一个 sigmoid 神经元训练很久之后：
A. 能分对，但需要把输入先标准化
B. 只要学习率够小，最终一定能分对
C. 只要迭代次数够多，最终一定能分对
D. 仍然分不全对，这是模型表达能力的限制
4. w₁ = −1、w₂ = 0、b = 0 的神经元，它的决策边界是：
A. 一条水平线 x₂ = 0
B. 过原点的 45° 斜线
C. 一条竖直线 x₁ = 0
D. 不存在边界，输出恒为常数
5. 如果两个权重都为 0，这个神经元会怎样？
A. 对任何输入都输出同一个常数
B. 边界退化成一个点
C. 输出等于偏置本身
D. 自动忽略偏置，输出恒为 0.5
答案与解析
1. D —— 阈值 0.5 对应 z = 0，即 w₁x₁ + w₂x₂ + b = 0 —— 两个输入时这是一条直线。
2. B —— ⭐ 关键在 sigmoid 保序：正分数给出 >0.5、负分数给出 <0.5。所以「在哪里越过 0.5」完全由「在哪里 z 越过 0」决定。
3. D —— ⚠ 讲义专门警告：「再 train 久一点」是错误选项。任何一条直线都会把两类混在一起。
4. C —— z = −x₁，边界 z = 0 就是 x₁ = 0，一条竖线。这是讲义里「蓝点全在左、橙点全在右」那个能搞定的例子。
5. A —— z = b 与输入无关 ⇒ p = σ(b) 是常数。⚠ 输出是 σ(b) 而不是 b 本身。

答案与解析

2. D —— 隐藏层在输入与最终预测之间计算中间值。⚠ 这些特征不一定对应人能读懂的概念。

第 5 组：为什么层间必须非线性（T1-1 §5）
1. h = 2x + 1、s = 3h + 4，中间不加激活函数。整串等价于下面哪一个单层？
A. s = 6x + 5
B. s = 6x + 7
C. s = 5x + 7
D. s = 2x + 4
2. 「加权和 + 偏置」这种函数的专门叫法是：
A. 单调函数（monotonic function）
B. 凸函数（convex function）
C. 仿射函数（affine function）
D. 分段函数（piecewise function）
3. 把隐藏层换成 h = max(0, 2x + 1)、s = 3h + 4。x ≤ −0.5 时 s 等于多少？
A. 4
B. 0
C. 6x + 7
D. 3
4. x = 1 时，加 ReLU 与不加 ReLU 算出的 s 为什么相同？
A. 因为第二层的偏置抵消了 ReLU 的影响
B. 因为 x = 1 恰好是两段的折点
C. 因为 ReLU 对任何输入都不改变结果
D. 因为 ReLU 在正输入上是恒等映射，x = 1 落在不被截断的区域
5. 「隐藏层不放激活函数，只在最后放一个 sigmoid」行不行？
A. 行，sigmoid 已经提供了所需的非线性
B. 不行，因为 sigmoid 的输出不在 (0,1) 区间
C. 行，但需要把学习率调小
D. 不行，送进 sigmoid 之前的分数仍是输入的仿射函数，边界还是直线
答案与解析
1. B —— s = 3(2x + 1) + 4 = 6x + 3 + 4 = 6x + 7。⇒ 一个权重 6、偏置 7 的单层给出完全相同的输出，两层塌缩了。
2. C —— 「层塌缩成一个仿射函数」就是说整串可以被那一个等价计算替换掉。
3. A —— 此时 2x+1 ≤ 0 ⇒ h = 0 ⇒ s = 3×0 + 4 = 4（一段水平线）。x > −0.5 时才是 s = 6x + 7。两段在 x = −0.5 处相接。
4. D —— x = 1 ⇒ 2x+1 = 3 > 0，ReLU 原样输出，两者都得 s = 13。而 x = −1 落在被截断的区域：有 ReLU 得 4，无 ReLU 得 1。
5. D —— ⚠ sigmoid 让概率输出非线性，但 0.5 阈值仍对应分数为零 ⇒ 两个输入时仍是一条直边界。

5. 一个隐藏激活同时喂给后面多个单元时，它的梯度应该怎么处理？

B. 只取贡献最大的那条路径

答案与解析
1. B —— ∂p/∂w₂ = (∂p/∂z)·(∂z/∂v)·(∂v/∂w₂) = p(1−p) · 1 · x₂。一条路径内部相乘。

3. C —— 二者接近但不相同，这正是局部近似的含义。
4. B —— 1×2 + 1×3 = 5。校验：q = 1 时 F = 5，q = 1.01 时 F = 5.05。⚠ 只沿一支算会得到 2，漏掉另一支的贡献。
5. A —— ⭐ 相乘只在一条路径内部用；路径汇合处要相加。
第 9 组：接到损失上（T1-2 §7）

5. C —— 知道「怎样增大 p」并不能告诉我们这个改变是否改进了预测。

B. 对，只要训练集足够大，置信度越高说明模型学到的规律越可靠

5. C —— ⚠ 讲义专门加了这句警告。

5. 同一道考纲示例题还问：自动微分在这里算的是什么，为什么它本身不保证得到好模型？
A. 它算的是全局最优解，但需要更多数据才能找到
B. 它算的是损失的二阶导数，一阶信息不足以保证收敛
C. 它沿着被记录下来的运算求导数；合适的数据、建模选择与独立评估仍然必需

答案与解析
1. A —— ⚠⚠ 这是「最容易答错的概念题」。跑一次反向传播本身不改变任何权重，它也不是把前向的算术倒着跑一遍去重建输入。
2. B —— z = 0.5×3 + 0.5 = 2；z > 0 ⇒ a = 2；L = (2−4)²/2 = 2。这是 M3 考纲页给的官方示例大题。
3. C —— 输出误差 ∂L/∂a = a − y = −2；乘 ReLU′ = 1 得 ∂L/∂z = −2；再乘 ∂z/∂w = x = 3 得 −6，而 ∂z/∂b = 1 得 −2。
4. D —— w = 0.5 − 0.05×(−6) = 0.8；b = 0.5 − 0.05×(−2) = 0.6。⚠ 两个梯度都用更新前的原参数算。
5. C —— 官方答案校验里的原话要点。⭐ 大题要求写出中间步骤：「只给出正确的最终数字，可能不足以体现所需的理解」。
