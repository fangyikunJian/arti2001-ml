## 1. 一次更新只是开始

训练算法反复做：**选样本 → 算预测和损失 → 算新的梯度 → 更新参数 → 重复**。

> ⭐ **权重会变，观测到的训练标签不会变。**
> ⚠⚠ **训练损失下降只说明模型在拟合训练目标，不一定说明它能预测没见过的数据。**

### ⭐⭐ 四个阶段与各自的典型错误（很像考点清单）

| 阶段 | 做什么 | **典型错误** |
|---|---|---|
| **Forward** | 用**当前**参数算激活、预测、损失 | **复用更新之前的激活值** |
| **Backward** | 用**这一次前向**的结果算出全部损失梯度 | **在算隐藏层梯度之前就更新了输出权重** |
| **Update** | 减去「学习率 × 梯度」 | **把梯度加上去**，或步子过大 |
| **Repeat** | 用新参数做一次新的前向 | **每一步都复用旧梯度** |

> ⭐ 第二行那个错误正是上一课强调的：**必须用原始参数把全部梯度算完再一起更新。**

## 2. ⭐⭐ batch 和 epoch 是两个不同的单位

| 术语 | 定义 |
|---|---|
| **batch（批）** | **用来计算一次更新的那组观测** |
| **mini-batch** | 训练集的一个**子集** |
| **epoch（轮）** | **把训练集完整过一遍** |

```
L_batch = (1/N) Σₙ Lₙ        N = 当前批里的观测数
```
> ⚠ Topic 2 把单个损失叫 **ℓₙ**，这里写作 **Lₙ**，**指的是同一个量**。

### ⭐ 必考的计数题

> **100 个训练观测、批大小 20，每个观测每轮用一次** ⇒
> **一个 epoch 有 5 次更新**（100 ÷ 20）；**三个 epoch 就是 15 次更新**。

> **全批量梯度下降（full-batch）**：100 个全用上，**每个 epoch 只更新一次**。

### ⚠⚠ 平均只做一次

> **用平均损失时，每个样本贡献的是「它的梯度 ÷ N」。**
> **这个平均只做一次，不要在每一层再除一遍。**

**sigmoid/BCE 的输出分数梯度数组是 `(P − Y)/N`。**
（P 是预测概率数组，Y 是二元目标数组；每一项都是**平均 BCE 对那个观测输出分数的导数**。）

### ⭐ 一个很有意思的数值例子

> 两个样本对某参数的梯度分别是 **−0.2** 和 **+0.6**，**平均是 +0.2** ⇒ **梯度下降会减小这个参数**。
> ⚠⚠ **一次基于平均损失的更新，可能在改善平均的同时让某一个观测变差。**

## 4. ⭐⭐ 接到 Python：那个转置是最大的坑

> ⚠⚠ **手推时把一个输入存成「列」；代码里把观测存成「行」。**
> ⇒ **代码里每个权重矩阵都是手推版本的转置**：`W1 = W₁ᵀ`，`W2 = W₂ᵀ`，`b2` 装的是输出偏置 c。
> **转置只是行列互换，不改变网络本身。**

| 量 | 形状与含义 |
|---|---|
| `X`; `Y` | **(N,2)** 输入；**(N,1)** 观测二元目标 |
| `W1`; `b1` | **(2,2)** 隐藏权重；**(1,2)** 隐藏偏置。⭐ **代码 W1 的每一列属于一个接收的隐藏单元** |
| `Z`; `H` | **(N,2)** 隐藏预激活与 ReLU 激活 |
| `W2`; `b2` | **(2,1)** 输出权重 v₁,v₂；**(1,1)** 输出偏置 c |
| `S`; `P` | **(N,1)** 输出 logits 与 sigmoid 概率 |

### ⚠ 这里有个会掩盖问题的巧合

> **本例 W1 是方阵，所以转置不改变形状——但确实挪动了元素。**
> **换成 3 个隐藏单元、2 个输入特征**：**手推矩阵是 3×2，代码矩阵是 2×3**，输出权重的代码矩阵是 **3×1**。

### ⭐ 读一列来验证

**代码 `W1` 的第一列是 [0.2, 0.4]** —— 隐藏单元 1 接收 x₁、x₂ 的那两个权重。
对输入行 `[1, 2]`：`1×0.2 + 2×0.4 = 1.0`，加偏置 `0.1` ⇒ **1.1** ✓ 和手算一致。
第二列 `[−0.5, 0.3]` 给出另一个隐藏分数。

**第一行的结果**：`Z=[1.1, −0.1]`，`H=[1.1, 0]`，`S=[0.67]`，`P≈[0.661503]` —— **和上一课完全吻合**，四行的平均损失 **0.580352**。

### 代码里的三个要点

- **`@` 是矩阵乘法**
- **把一个「行形状」的偏置加到每一行上，靠的是 NumPy 广播**
- ⭐ **损失表达式直接从 logits 算 BCE**，**为的是避免对四舍五入过的概率取对数**

### 自测：N 个观测、2 个输入特征、3 个隐藏单元，H / P / Y 的形状？

```
H 是 (N, 3)     ← 行数 = 观测数，列数 = 隐藏单元数
P 是 (N, 1)     ← 每个观测一个概率
Y 是 (N, 1)     ← 每个观测一个目标
```

## 5. ⭐⭐⭐ 自动微分做什么、不做什么（考纲明确要求）

> **自动微分追踪一次前向计算里的各个运算，并应用链式法则求导数。**
> **它把你练过的那些算术自动化了。**

### ⚠⚠ 它**不**做这些（这句最可能出选择题）

> **它不会替你选一个有用的目标，不会修复数据泄漏，也不保证学习率是好的。**
> **参数更新是由优化器完成的。**

## 6. ⭐⭐⭐ 那个必考的 TensorFlow 例子

⚠ **它刻意换了设定**：**一个标量输入 2.0、一个 ReLU 神经元、平方误差损失、目标 5.0**。
**这不是前面那个二分类批量**——**链式法则的机制相同，但损失的导数不同**。

```python
w = tf.Variable(1.5)
b = tf.Variable(-1.0)
with tf.GradientTape() as tape:
    z = w * 2.0 + b
    a = tf.nn.relu(z)
    loss = 0.5 * (a - 5.0)**2
gw, gb = tape.gradient(loss, [w, b])
w.assign_sub(0.05 * gw)
b.assign_sub(0.05 * gb)
```

### ⭐⭐ 三个角色（考纲原文要求能解释的三件事）

| 问题 | 答案 |
|---|---|
| **tape 记录了什么？** | **`tf.Variable` 标记哪些量是可训练的；tape 在前向计算期间记录「涉及这些变量的运算」** |
| **`tape.gradient` 返回什么？** | **它应用链式法则，按请求的顺序 `[w, b]` 返回梯度 −6 和 −3**。⚠⚠ **它不更新参数** |
| **哪个操作真正改变参数？** | **`assign_sub`** —— 它执行随后的减法 |

### ⭐ 把数字追一遍（要会复现）

```
前向：  z = 1.5 × 2.0 + (−1.0) = 2
        a = ReLU(2) = 2
        loss = 0.5 × (2 − 5)² = 0.5 × 9 = 4.5

反向：  ∂loss/∂a = a − 5 = −3          （0.5(a−5)² 的导数）
        z = 2 > 0  ⇒ ReLU 贡献倍数 1
        ∂loss/∂w = (−3) × 1 × 2.0 = −6   ← 乘输入 2.0
        ∂loss/∂b = (−3) × 1 × 1   = −3   ← 偏置的倍数是 1

更新（η = 0.05）：
        w = 1.5  − 0.05 × (−6) = 1.8
        b = −1.0 − 0.05 × (−3) = −0.85

重新前向： z = 1.8 × 2 + (−0.85) = 2.75 = a
           loss = 0.5 × (2.75 − 5)² = 2.53125     ← 从 4.5 降下来了
```

> ⭐⭐ **两个梯度都是在任何一次更新之前算出来的** —— 又是那条纪律。

### ⚠ 自测：如果把两行 `assign_sub` 删掉，调用 `tape.gradient` 还能训练这个模型吗？

> **不能。** `tape.gradient` **只负责计算梯度**，**没有任何东西去改变参数**。
> ⭐ 这正是「**反向传播算梯度、优化器改参数**」那条区分在代码里的体现。

## 7. 两道总结自测

**Q1：解释完整的训练循环，以及为什么每次更新都需要重新计算。**
> **输入 → 预测 → 损失 → 梯度 → 更新 → 新的前向。**
> **因为参数变了，所有依赖参数的量（激活、预测、损失、梯度）全都过期了。**
> ⚠ 复用旧激活或旧梯度，算出来的就不是当前这一点处的下降方向。

**Q2（指向 Topic 3）：什么证据能区分「拟合了训练数据」和「学到了有用的模型」？**
> **训练损失下降只证明前者。** 要区分，必须看**留出数据上的证据**——
> **验证损失、训练与验证曲线的分叉**，这正是 Topic 3 的内容。
