T1 Tutorial · 网络基础（Network foundations）

官方给的设定（Tutorial 第 1 页）。这一份只考到输出层；隐藏层的反向传播在 Topic 2 教、在 Topic 2 考，这里不要求。

z = W₁x + b₁, h = ReLU(z), s = W₂h + c, p = σ(s)

x = [0, 3]ᵀ, y = 1, η = 0.1

⎡ 1 2 ⎤ ⎡ 0 ⎤
W₁ = ⎢ −1 1 ⎥ , b₁ = ⎢ 1 ⎥ , W₂ = [1 −1 2], c = −1
⎣ 0 1 ⎦ ⎣ −4 ⎦
★ 官方写明的约定（照抄到答卷上）
  • 自然对数（log = ln），判类阈值 0.5，答案保留 4–6 位小数，⚠ 中间值不要四舍五入；
  • ReLU′(z) = 1（z > 0）、0（z < 0）；这份题里没有任何隐藏预激活恰好为零，所以不必纠结 z = 0 的约定；
  • 下标是层号不是幂次也不是元素：W₁、b₁ 属隐藏层，W₂ 属输出层；
  • w_ji 连接输入 i 到隐藏单元 j（接收端在前）；输出权重 W₂ = [v₁, v₂, v₃]；
  • s 也叫 logit，δ = ∂L/∂s。

Q1 · 前向传播，以及 ReLU 为什么重要

1

形状与参数个数。 W₁ 是 3×2，W₂ 是 1×3。

W₁: 3×2 = 6 个权重 b₁: 3 个偏置
W₂: 1×3 = 3 个权重 c : 1 个偏置
可训练参数合计 = 6 + 3 + 3 + 1 = 13

⚠ 题目问的是 *all trainable weights and biases*，偏置要算进去。

2

隐藏层。

z₁ = 1(0) + 2(3) + 0 = 6
z₂ = −1(0) + 1(3) + 1 = 4
z₃ = 0(0) + 1(3) − 4 = −1

h = ReLU(z) = [6, 4, 0]ᵀ ← ⚠ 第三个单元被截断，h₃ = 0

⭐ h₃ = 0 是这整份 Tutorial 的枢纽：Q2 第 4 问「为什么第三个输出权重的梯度是零」和 Q1 第 5 问「去掉 ReLU 会怎样」都落在它身上。

3

输出层。

s = 1(6) + (−1)(4) + 2(0) + (−1) = 6 − 4 + 0 − 1 = 1
p = σ(1) = 1/(1 + e⁻¹) = 0.731059
4

损失与解读。 y = 1，所以 L = −log p。

L = −log(0.731059) = 0.313262

解读：p = 0.731059 ≥ 0.5 ⇒ 预测类别 1，和目标一致，判对了。但模型仍把约 26.9% 的概率分给了错误的类，所以损失不为零——⭐ 这正是「损失提供了阈值判定之外的连续信号」那一点。

5

去掉 ReLU（h = z），证明整串塌缩成一个仿射函数。

s = W₂(W₁x + b₁) + c = (W₂W₁)x + (W₂b₁ + c)

W₂W₁ = [1, −1, 2] · W₁ = [1(1)+(−1)(−1)+2(0), 1(2)+(−1)(1)+2(1)] = [2, 3]
W₂b₁ + c = 1(0) + (−1)(1) + 2(−4) + (−1) = −10

⇒ w̃ = [2, 3]ᵀ , c̃ = −10 （这就是题目要的 s = w̃ᵀx + c̃）

在 x = [0,3]ᵀ 处： s = 2(0) + 3(3) − 10 = −1 p = σ(−1) = 0.268941

为什么和第 3 问不同：ReLU 把 z₃ = −1 截成了 0，于是第三条路径对 s 的贡献从 v₃·z₃ = 2(−1) = −2 变成 v₃·h₃ = 0。差额正好是 1 − (−1) = 2。

⚠⚠ 后果比数字更重要：去掉 ReLU 后 p = 0.2689 < 0.5，预测从类别 1 翻成类别 0，判错了。⭐ 这一问是「深度本身不增加表达力、必须有非线性隐藏激活」在具体数字上的演示。

Q2 · 推导并使用学习信号

1

依赖路径（题目要求画出来并给每个箭头标局部导数）：

v₁ ──(∂s/∂v₁ = h₁)──▶ s ──(∂p/∂s)──▶ p ──(∂L/∂p)──▶ L

其中 h₁ = 6 就是「乘在 v₁ 上的那个值」
2

三个局部导数，相乘得到 ∂L/∂v₁。

∂s/∂v₁ = h₁ = 6
∂p/∂s = p(1−p) = 0.731059 × 0.268941 = 0.196612
∂L/∂p = −1/p = −1.367879 （y = 1 时 L = −log p）

∂L/∂v₁ = (−1.367879)(0.196612)(6) = −1.613649

再证 δ = p − y，题目要求数值上和代数上各证一遍：

数值： δ = (∂L/∂p)(∂p/∂s) = (−1.367879)(0.196612) = −0.268941
p − y = 0.731059 − 1 = −0.268941 ✓ 相等

代数： δ = (−1/p) · p(1−p) = −(1−p) = p − 1 = p − y （因为 y = 1）
3

用捷径一次算完四个梯度。

∂L/∂W₂ = δ hᵀ = (−0.268941)·[6, 4, 0]

∂L/∂v₁ = −1.613649 ∂L/∂v₂ = −1.075766 ∂L/∂v₃ = 0
∂L/∂c = δ = −0.268941
4

解读（这一问全是文字分）。

  • 负梯度的局部含义：梯度下降 θ ← θ − η·∂L/∂θ，梯度为负 ⇒ 参数会变大；也就是说在当前这一点上，略微增大 v₁、v₂ 和 c 会降低损失。⚠ 这是局部方向，不保证大步更新也成立。
  • 为什么第三个输出权重的梯度是零：∂L/∂v₃ = δ·h₃，而 h₃ = ReLU(−1) = 0。⚠ 不是因为 δ 为零，也不是因为 v₃ 本身有什么特别——是这个隐藏单元对这一个观测不激活，这条路径被 ReLU 掐断了。
  • 算梯度 ≠ 改参数：这一问算出来的是反向传播的产物；参数要等到 Q3 用梯度下降才真正改变。⭐ 这两件事是本模块反复考的区分。

Q3 · 更新一次，然后复查预测

1

梯度下降规则与更新（η = 0.1）。

θ_new = θ − η · ∂L/∂θ

v₁ = 1 − 0.1(−1.613649) = 1 + 0.161365 = 1.161365 ← 一次数值代入
v₂ = −1 − 0.1(−1.075766) = −0.892423
v₃ = 2 − 0.1(0) = 2 （没变）
c = −1 − 0.1(−0.268941) = −0.973106

⚠ 减去一个负数 = 增大，和 Q2 第 4 问的解读一致。⚠ 四个梯度都是在更新前的参数状态上算的，然后一起更新。

用新参数重新跑一次输出计算（隐藏层与 h 保持不变，题目这样规定）。

s = 1.161365(6) + (−0.892423)(4) + 2(0) + (−0.973106) = 2.425390

判类有没有变？为什么损失能改善而类别不变？

  • 没变：更新前 p = 0.731059 ≥ 0.5 判类 1，更新后 p = 0.918743 ≥ 0.5 还是类 1。
  • 损失仍然改善了 0.228513，因为 BCE 看的是概率本身，不是阈值判定之后的类别。⭐ 概率从 0.731 推到 0.919，更靠近目标 y = 1，所以 −log p 明显变小。这正是「准确率没动、损失却在降」那种情形的微观版本。
  • 这能说明在没见过的数据上也好吗？不能。 ⚠ 这只是同一个观测上的一次局部改进；它既不证明收敛，也不是泛化的证据。要判断泛化，必须看留出数据上的表现（Topic 3）。
⭐ 这份 Tutorial 的答题骨架（扩展题可直接套）

① 前向（z → h → s → p → L，每步留 6 位）→ ② 写出 δ = p − y 并说明它是 sigmoid+BCE 的化简 → ③ 用 ∂L/∂W₂ = δhᵀ、∂L/∂c = δ 一次算完 → ④ 同步更新，明说「所有梯度用更新前的参数算」 → ⑤ 重新跑前向给出新的 s、p、L → ⑥ 收一句局限：只证明这一个样本上有改进，不是泛化的证据。

选做 extension · 同样的预测，目标改成 y = 0

起点完全不变（原参数 W₂ = [1,−1,2]、c = −1，以及 Q1 算出的 s 和固定的 h），只把观测到的标签改成 y = 0。

1

先预测符号，再算。 p 没变还是 0.731059，而现在 y = 0：

δ = p − y = 0.731059 − 0 = +0.731059 ← ⚠ 由负转正

∂L/∂v₁ = 0.731059 × 6 = 4.386351
∂L/∂v₂ = 0.731059 × 4 = 2.924234
∂L/∂v₃ = 0.731059 × 0 = 0 ← h₃ = 0，仍然是零
∂L/∂c = 0.731059

更新（η = 0.1）： v₁ = 0.561365 v₂ = −1.292423 v₃ = 2 c = −1.073106
2

重新计算分数、概率与 BCE。

s = 0.561365(6) + (−1.292423)(4) + 2(0) + (−1.073106) = −2.874610
p = σ(−2.874610) = 0.053423
L = −log(1 − p) = −log(0.946577) = 0.054903 ← y = 0 时用 −log(1−p)

为什么更新方向反过来了？ ⭐ 因为 δ = p − y 里变的是 y，不是 p。原来的预测一个字都没改（p 还是 0.731059），但现在这个概率是「分给错误类别的」，所以损失要求把 logit 往下推。

⚠ 顺带注意判类也翻了：p = 0.053423 < 0.5 ⇒ 预测类别 0，与新的 y = 0 一致。

⚠ extension 真正在考的一句话

同一个预测，好不好完全取决于目标是什么。δ = p − y 把这件事写死了：预测 p 只决定大小，目标 y 决定方向。⭐ 这也解释了为什么「前向传播没用到 y」——因为方向要等损失出现才有。

⭐ 官方答案。Q3 复用 T1 那个网络做隐藏层任务，所以上一节的前向结果可以直接接着用：z = [6, 4, −1]ᵀ，h = [6, 4, 0]ᵀ，s = 1，p = σ(1)，δ = p − 1 ≈ −0.268941。

★ 这份 worksheet 的约定（和 T1 略有不同，注意）
  • ReLU′(0) = 0 被写成 implementation convention —— T1 那份说「没有预激活恰好为零」所以不必纠结，这一份明确给了约定；
  • 观测是列向量（Observations are columns）；
  • 半平方误差 L_half = ½(p − y)²，logit 梯度是 (p − y)p(1 − p)；
  • ⭐ 官方一句很精炼的总结：sigmoid 输出配 BCE 时链式化简成 p − y，但隐藏激活自己的局部导数仍然留在链条里。

Q2 · 损失值与学习信号

1

回归损失。 预测 ŷ = (2.5, 4)，目标 y = (3, 1) ⇒ 残差 y − ŷ = 0.5 和 −3。

MSE = (0.25 + 9)/2 = 4.625 MAE = (0.5 + 3)/2 = 1.75

⭐ 官方用占比把「谁更敏感」量化了：大的那个残差贡献了平方误差总量的 9/9.25 ≈ 97%，却只占绝对误差总量的 3/3.5 ≈ 86%。⇒ 平方把大误差放得更大，所以 MSE 对它更敏感。

⚠ 另一句也要写：MAE 保持目标的单位；MSE 的单位是目标单位的平方。

2

三个 BCE 值。

(y, p) = (1, .9) ⇒ −ln(.9) = 0.105361
(y, p) = (0, .2) ⇒ −ln(1 − .2) = 0.223144
(y, p) = (1, .6) ⇒ −ln(.6) = 0.510826

和 = 0.839330 均值 = 0.839330/3 = 0.279777

哪一个贡献最大：第三个。官方的理由写得很准——它给自己那个真实类别分配的概率最低。

3

两种搭配的 logit 梯度对比（y = 1、p = .6）。

BCE： p − y = −0.4
半平方： (p − y)·p(1−p) = (−0.4)(0.6)(0.4) = −0.096

多出来的那个 sigmoid 斜率在这里是 p(1−p) = 0.24

⚠ 官方的限定句：p 趋近 0 或 1 时这个因子趋近于零，所以即使是「有把握却判错」的预测，它也会削弱输出端的学习信号。

⭐ 还有一句很值钱：输出端的这个约分并不消除隐藏激活的导数——BCE 救的是输出层，救不了隐藏层。

4

多分类。 p = (.2, .5, .3)，真实类别是第 3 类。

one-hot 目标 y = (0, 0, 1)
L = −[0·ln(.2) + 0·ln(.5) + 1·ln(.3)] = −ln(.3) = 1.203973
logit 梯度 p − y = (.2, .5, −.7) ← 三项之和为 0

符号怎么读：减去正的梯度会压低 logit 1 和 2；减去负的梯度会抬高 logit 3。

5

解读后来的结果（题目直接给：p = (.1, .3, .6)、损失 .510826、梯度 (.1, .3, −.4)）。

真实类别的概率 .3 → .6，翻了一倍
损失下降 ln 2 ≈ 0.693147 （1.203973 − 0.510826 = 0.693147）
预测类别从第 2 类变成第 3 类

⚠ 最后那一问是概念分：为什么更新一个网络权重还需要链式法则？官方答——logit 取决于权重和激活，所以权重的梯度还要包含「这个权重如何影响各个 logit」；logit 梯度本身不是权重梯度。

Q3 · 一个隐藏权重的梯度与训练过程

1

追 w₁₂ → z₁ → h₁ → s → p → L（注意这里是 T1 那个网络）。

∂L/∂w₁₂ = (∂L/∂p)(∂p/∂s)(∂s/∂h₁)(∂h₁/∂z₁)(∂z₁/∂w₁₂)
= δ × v₁ × ReLU′(z₁) × x₂
= (−0.268941) × 1 × 1 × 3 = −0.806824

更新： w₁₂ = 2 − 0.1(−0.806824) = 2.080682

符号的含义：梯度为负 ⇒ 局部增大这个权重会降低损失。

⚠ 官方补了一句很好的对照：如果隐藏层用的是 sigmoid，它自己的那个导数因子就会留在链条里（这里因为 ReLU 在正半轴导数是 1，才「看不见」）。

2

隐藏单元 3 的两个零，原因不同（这是本题的概念重点）。

哪个梯度为零直接原因
它的输入权重与偏置梯度⚠ ∂L/∂h₃ 其实不为零（= 2δ），但它的分数是负的 ⇒ ReLU 导数为 0，把传入的梯度挡住了
它的输出权重 v₃ 的梯度因为它的输入激活 h₃ = 0

⚠⚠ 官方明确写了：两者都不能确立永久失活。

  • 平均损失下，每个观测只贡献它自己梯度的 1/N。四个观测的输出 logit delta (p − y)/4 ≈ [−0.059214, 0.096154, −0.134979, 0.191462]。⚠ 官方把两种错法都点名了：除两次会让梯度太小；不除则求的是「和」的导数而不是「平均」的。
  • 形状：h.T @ delta2 是 (3,4)×(4,1) ⇒ (3,1)，每个输出权重一个梯度。第一个输出权重：0.9(−0.059214) + 0(0.096154) + 0.2(−0.134979) + 1.2(0.191462) = 0.149466，为正 ⇒ 梯度下降会把它减小，η = 0.1 时从 0.8 变成约 0.785053。

Q5 要点 · 一段代码里的两个独立错误

题目给的场景：某同学算完输出层梯度后立刻更新 W₂，然后用更新后的 W₂ 去算隐藏层梯度；并且用 W1 + learning_rate*dW1 更新 W₁。官方说这里有两个彼此独立的错误：

#错在哪为什么错
①在算隐藏层梯度之前就更新了 W₂“mixes parameter states”——两个参数状态混在一起，算出来的不再是原损失的导数
②把梯度加上去（W1 + rate*dW1）“is an ascent step”——学习率为正时，最小化损失必须减
官方给的正确写法：

old = [a.copy() for a in parameters]
grads = gradients(X, y, old) # 全部梯度在同一个状态上算
parameters = [a - rate*d for a, d in zip(old, grads)]
⭐ 自动微分那一问的标准答法

自动微分会算什么：追踪这一次前向计算里的各个运算，按链式法则给出各参数的梯度。优化器随后做什么：用这些梯度执行参数更新。它能保证学习率合适吗——不能。⭐ 官方要你把这一问接回 Q3：Q3 那张表里 η = 100 把损失推到 4.62，而自动微分对此毫无意见——它只负责求导，不负责步长。

扩展自学要点 · 数值梯度检查

  • 做法：对每个参数元素，复制一份、把那一个元素 ±ε 扰动，用中心差分 (L₊ − L₋)/(2ε) 和解析梯度比。
  • ⚠ 这是调试手段，不是训练算法；而且 “near a ReLU kink the derivative may not exist”——在 ReLU 的折点附近导数可能不存在，那里对不上是正常的。
  • 重复训练：30 步、η = 0.1，每一步都要重新算梯度，记录初始损失和每步之后的损失。
  • ⚠ 官方要求解释三件事：为什么梯度必须每步重算（参数变了，所有依赖参数的量都过期）、为什么损失曲线下降不是泛化的证明、为什么数值检查比反向传播慢（每个参数要跑两次完整前向）。

Q5 选对输出与损失三个设计各有一处输出激活或损失不合适（如预测摄氏温度，预测值必须允许负数），要指出问题、给出正确搭配、并说明为什么匹配四种任务的输出层与损失
★ Q4 和 Q5 直接就是扩展题素材
  • Q4 的流程（训练集拟合 → 验证选择 → 合并重拟合 → 测试评一次）是 T3 考纲第一条的落地版，扩展题问「如何选定并报告」时照搬即可。
