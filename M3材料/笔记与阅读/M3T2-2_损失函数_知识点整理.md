## 1. ⚠⚠ 记号：ℓ 和 L 不是一回事

| 记号 | 含义 |
|---|---|
| **ℓᵢ = ℓ(yᵢ, ŷᵢ)** | **单个样本**的损失 |
| **L = (1/N) Σᵢ ℓᵢ** | 在一个数据集或 mini-batch 上的**平均**经验损失 |

> ⚠ **Topic 1 用 L 表示单个观测的损失**；**到了 Topic 2，那个量叫 ℓᵢ，L 改成了平均值。**
> 跨 Topic 看材料时这里最容易混。

**其它约定**：
- **i 索引观测，k 索引类别**
- **所有 log 和 ln 都是自然对数**
- **K** = 互斥类别的个数
- 二分类里 **p（强调激活时写 a）是预测概率，不是阈值判出的类别**
- 二分类 sigmoid 输出时，**z 是原始分数（logit）**，**p = σ(z)**
- 多分类里 **yᵢₖ 和 pᵢₖ** 分别是观测 i 对类别 k 的目标指示和预测概率

## 2. 回归损失：MSE 与 MAE

| 损失 | 平均形式 | 解读 |
|---|---|---|
| **MSE** 均方误差 | L = (1/N) Σ (yᵢ − ŷᵢ)² | **平方** ⇒ **大误差被加倍重视** |
| **MAE** 平均绝对误差 | L = (1/N) Σ \|yᵢ − ŷᵢ\| | **线性增长**，对极端误差**不如 MSE 敏感** |

### ⭐ 官方算例（要会算）

目标 **[3, −1]**，预测 **[2, 1]** ⇒ 残差（预测 − 目标）= **[−1, 2]**

```
平方： [1, 4]  ⇒  MSE = (1+4)/2 = 2.5
取绝对值： [1, 2]  ⇒  MAE = (1+2)/2 = 1.5
```

> ⚠ **平方误差不允许正负误差互相抵消。**
> ⚠ **单位不同**：MSE 的单位是**目标单位的平方**，MAE **保持目标的单位**。

### 自测：某个残差从 2 变成 4，两种贡献各怎么变？

```
平方误差贡献： 4 → 16    （×4，因为是平方）
绝对误差贡献： 2 →  4    （×2，线性）
```

### ⚠ 页面特意加的限定

> **MAE 在「需要对极端目标值稳健」时可能有用，但选择应当反映数据生成过程和误差的真实代价，而不是套用「某个损失总是更好」这种规则。**

⭐ 另外两条值得记：
- **一个残差 10，对平方误差贡献 100，对绝对误差贡献 10。**
- ⚠⚠ **MAE 能降低对极端残差的敏感度，但它修不了系统性的错误标签、缺失的人群、或者数据泄漏。**
- **MSE 和 MAE 估计的是目标的不同概括量**：分别对应**条件均值**和**条件中位数**。

## 3. 分类损失

### 二元交叉熵 BCE（y ∈ {0,1}，p ∈ (0,1)）

```
L_BCE = −(1/N) Σᵢ [ yᵢ·log pᵢ + (1−yᵢ)·log(1−pᵢ) ]
```

### 多类交叉熵 CCE（K 个互斥类别，one-hot 目标 yᵢₖ，softmax 概率 pᵢₖ）

```
L_CCE = −(1/N) Σᵢ Σₖ yᵢₖ · log pᵢₖ
```

> ⭐ 因为**恰好只有一个目标分量是 1**，所以**单样本损失就是「给正确类别的那个概率」的负对数**。

### ⭐⭐ Sparse categorical cross-entropy（M3 考纲点名）

> **它用整数类别标签代替 one-hot 向量，但表示的是同一个计算。**

### ⭐ 官方算例

类别编号 **1, 2, 3**，真实类别是 **2** ⇒ one-hot 目标 **[0, 1, 0]**
概率 **[0.1, 0.7, 0.2]**：

```
loss = −(0·ln0.1 + 1·ln0.7 + 0·ln0.2) = −ln 0.7 ≈ 0.3567
```

> ⭐ **只有「分配给观测到的那个类别」的概率进入这个 one-hot 损失。**
> ⚠⚠ **整数标签的实现可能把同样三个类别编号成 0, 1, 2 —— 永远要核对映射关系。**

---

## 4. 把损失和概率、任务联系起来

- **全部交叉熵计算都用自然对数 ln。**
- ⭐ **最小化「观测到的类别」的负对数概率，等价于最大化它的似然。**
- 📌 对照 M2：**GMM 是通过提高观测输入的概率密度来拟合的；分类器则是给「给定的目标类别」分配概率。**

### ⭐ 数值感（y = 0 的情形，容易算反）

| 情形 | 正确类别的概率 | 损失 |
|---|---|---|
| y = 0，p = 0.8 | **0.2**（因为正确类是 0） | −ln(0.2) ≈ **1.609** |
| y = 0，p = 0.1 | **0.9** | −ln(0.9) ≈ **0.105** |

> ⭐ **有把握但判错，会受到很大的惩罚。**

### ⚠⚠ 损失 ≠ 准确率（考点）

> **损失是一个优化目标；准确率数的是阈值判定之后的决策。**
> **两个分类器可能做出完全相同的硬判定，却有不同的交叉熵——因为它们的概率不同。**

⚠ **只有在任务、单位、聚合约定都可比时，才能比较损失数值。**

## 5. ⭐⭐⭐ 输出–损失配对表（考纲逐条点名）

| 任务 | 输出 | 常用损失 |
|---|---|---|
| **连续回归** | 线性 | **MSE 或 MAE** |
| **二分类** | 一个 sigmoid 概率 | **二元交叉熵** |
| **互斥多类** | softmax 概率 | **多类交叉熵** |
| **可共现的多标签** | 每标签一个 sigmoid | **每标签各做一次 BCE** |

### ⚠⚠ 一个极易踩的工程坑

> **软件里数值稳定的损失函数常常直接接收原始 logits，内部自己做 sigmoid 或 softmax。**
> **用这种选项时，不要再把激活函数套第二遍。**

### 自测：四个互斥类别，标签存成整数 0–3，用什么输出和损失？

> **softmax 输出 + sparse categorical cross-entropy。**
> （整数标签 ⇒ 用 sparse 版；互斥 ⇒ 用 softmax。）

## 6. 从单样本损失到训练目标

### ⭐ 算例

目标 **[1, 0]**，概率 **[0.8, 0.3]**：

```
第一个（y=1, p=0.8）： −ln(0.8) ≈ 0.2231
第二个（y=0, p=0.3）： 正确类概率 = 0.7 ⇒ −ln(0.7) ≈ 0.3567
                        ↑ 注意这里要用 1−p

和   = 0.5798
均值 = 0.2899
```

> ⭐ **平均梯度 = 各个单样本梯度之和 ÷ 样本数。**
> ⚠⚠ **求导之前，先说清楚这道题用的是「和」、「平均」还是「半平方误差」。**

### ⚠⚠ 两个不同的导数（最容易混的一处）

```
对概率求导：  ∂ℓ/∂p = −y/p + (1−y)/(1−p)
对 logit 求导：∂ℓ/∂z = p − y        ← 已经包含了 sigmoid 的链式因子
```

> ⭐ 后者就是 T1 学的那个 **δ = p − y**。**两者不是一回事，别张冠李戴。**

### 数值保护与校准

- **ε（epsilon）** 是一个很小的正数（如 **10⁻⁷**），用来让概率**远离恰好的 0 和 1**。
- **ln(0) 无定义。** 手算时用严格介于 0 和 1 之间的概率；教学代码里**裁剪到 [ε, 1−ε]** 可以避免无穷大。
- ⚠⚠ **裁剪只是改变了极端的数值，不能被误当成「模型校准良好」的证据。**
- **校准（calibration）的定义**：**预测概率与观测频率一致**——在被赋予概率 0.8 的那些案例里，**大约 80% 应该是正例**。

## 7. ⭐⭐⭐ 为什么 sigmoid 和 BCE 是绝配（本课最该记的推导）

设 **a = p = σ(z)**，y 是二元目标。

### ⚠ 先说清楚「半平方误差」不是 MSE

```
ℓ_half-square = ½(a − y)²     ⇒  对 a 的导数 = (a − y)
```
> ⚠ **这不是上面那个 MSE 公式**：普通平方误差求导给的是 **2(a−y)**，而在 N 个观测上取平均还会多一个 **1/N**。
> **下面的式子用的是「半平方」这个约定。**

### 两种搭配对 logit 的导数

```
sigmoid + 半平方误差：  ∂ℓ/∂z = (a − y) · a(1−a)
                                           └─ 多出来的这个因子是祸根

sigmoid + BCE：         ∂ℓ/∂z = a − y        ⭐ 干净利落
```

> ⭐⭐ **sigmoid 饱和时，a(1−a) 非常小。**
> ⇒ **对一个「有把握但判错」的二分类预测，BCE 给出的纠正梯度比 MSE 强得多。**

### ⭐ 官方算例（y = 1，a = 0.01，即非常自信地判错了）

```
半平方：  (0.01 − 1) × 0.01 × 0.99 = (−0.99)(0.0099) = −0.009801
BCE：     0.01 − 1                                    = −0.99
```

> **两者的符号都主张抬高 logit，但半平方的梯度小了整整两个数量级**——**因为 sigmoid 的局部斜率太小。**

⚠ **页面的限定**：
> **这个优势只针对「这一对输出–损失的组合」。BCE 并不能阻止深层网络中别处出现小梯度。**

### 自测：y = 1、p = 0.2 时，p − y 是哪个导数？

> **是对 logit 的导数**：∂ℓ/∂z = 0.2 − 1 = **−0.8**。
> 链式法则把它和「对概率的导数」连起来：**∂ℓ/∂z = (∂ℓ/∂p)·(∂p/∂z)**，其中 **∂p/∂z = p(1−p)**。

## 8. ⭐⭐ softmax + 交叉熵的学习信号

```
pₖ = exp(zₖ) / Σⱼ exp(zⱼ)          ℓ = −Σₖ yₖ ln(pₖ)

⇒  ∂ℓ/∂zₖ = pₖ − yₖ
```

> ⭐ 这是**对 logit 的导数**，**不是对概率、也不是对权重的导数**。
> 页面说：**可以直接使用这个结果，不必推导完整的 softmax 雅可比矩阵。**

### 三步操作法

1. 把 one-hot 目标**按和概率相同的类别顺序**写出来
2. **用概率向量减去目标向量**
3. **解读符号**：**正确类别那一项是负的** ⇒ 梯度下降会**抬高**那个 logit；**其余项是正的** ⇒ 它们的 logit 被**压低**

### ⭐ 官方算例

p = **(0.1, 0.7, 0.2)**，真实类别是 **2**（类别编号 1,2,3）：

```
y = (0, 1, 0)
loss = −ln(0.7) ≈ 0.357
logit 梯度 = p − y = (0.1, −0.3, 0.2)
```

> ⭐⭐ **这三项加起来等于零。** 这是个很好的自查。
> ⭐ **正确类概率趋近 1 时梯度趋近 0；有把握地判错则给出很大的纠正信号。**

### ⚠ 别忘了这只是中间量

> **网络真正更新的是共享的权重和偏置。** 要用链式法则从这些 logit 导数得到它们的梯度；
> **改动一个权重可能影响好几个 logit 和好几个观测。**
> **对 N 个样本的平均损失，就把各样本的参数梯度取平均。**

⭐ 这把二分类的 **p − y** 推广到了互斥多类。

## 9. 总结自测

**Q：一个分类器降低了训练 BCE，但没有改变任何类别判定。它学到东西了吗？在新数据上有用吗？**

> **学到了**——它改进了**概率估计**（损失对概率敏感，而准确率只看阈值后的判定，所以准确率没动很正常）。
> ⚠ **但这不能证明它在新数据上有用**：这只是训练集上的改进，**泛化要靠验证/测试证据**。

> 看公式前面有没有 **(1/N) Σᵢ** —— 有就是平均损失，没有就是单样本。

## ⭐ 速查卡

```
ℓᵢ = 单样本损失        L = (1/N)Σℓᵢ = 平均损失      ⚠ T1 的 L 是这里的 ℓ

回归： MSE = (1/N)Σ(y−ŷ)²        MAE = (1/N)Σ|y−ŷ|
       ⚠ MSE 单位是目标单位的平方；MAE 保持原单位
       ⚠ MSE→条件均值   MAE→条件中位数

分类： BCE = −(1/N)Σ[y·ln p + (1−y)·ln(1−p)]
       CCE = −(1/N)ΣΣ y_ik·ln p_ik   ⇒ 单样本 = −ln(正确类的概率)
       sparse 版 = 整数标签，同一个计算

配对： 回归→线性+MSE/MAE    二分类→sigmoid+BCE
       互斥多类→softmax+CCE  多标签→每标签 sigmoid+BCE
       ⚠ 软件的 from_logits 选项会内部做激活，别套第二遍

梯度： ∂ℓ/∂p = −y/p + (1−y)/(1−p)      ← 对概率
       ∂ℓ/∂z = p − y                    ← 对 logit（含 sigmoid 链式因子）
       softmax+CE： ∂ℓ/∂z_k = p_k − y_k  ⭐ 各项和为 0

⭐ sigmoid+半平方： ∂ℓ/∂z = (a−y)·a(1−a)   ← 饱和时几乎归零
   sigmoid+BCE：   ∂ℓ/∂z = a−y            ← 不受饱和拖累
   算例 y=1,a=0.01： −0.009801  vs  −0.99
```
