## 1. ⭐⭐⭐ 关键区分：输出值 vs 导数

| | 作用在哪 | 干什么 |
|---|---|---|
| **激活值 a = g(z)** | **前向** | 往下一层传递 |
| **局部导数 g′(z)** | **反向** | **乘在传回来的损失梯度上** |

> ⚠⚠ **大的输出不代表大的梯度**（a large output need not imply a large gradient）。这两件事互不相干。

**具体怎么乘**：
```
传入的损失梯度 0.6  ×  局部导数 0.25  =  传出去的梯度 0.15
```
> ⭐ **若局部导数为 0，这条路径对这个样本的梯度贡献就是 0。**

## 2. ⭐⭐⭐ 四个激活函数（必须会默写这张表）

| 函数 | 定义 | **导数** | 要点 |
|---|---|---|---|
| **Sigmoid** | g(z) = 1/(1+e^(−z)) | **g′ = g(1−g)** | 映到 **(0,1)**；适合二分类输出概率；**会饱和** |
| **tanh** | g(z) = tanh z | **g′ = 1 − g²** | 映到 **(−1,1)**；**输出范围关于 0 对称**；**也会饱和** |
| **ReLU** | g(z) = max(0, z) | **z<0 → 0；z>0 → 1** | 高效，**正半轴不饱和**；**负输入拿到零梯度** |
| **Leaky ReLU** | g(z) = max(αz, z) | **z<0 → α；z>0 → 1** | **保留一点负侧梯度**，可减少死亡 ReLU |

### ⚠⚠ 课程自己规定的约定（考试按这个判）

**ReLU 和 Leaky ReLU 在 z = 0 处不可导**，各家软件用不同约定。**本课规定**：

```
ReLU′(0) = 0
LeakyReLU′(0) = 0.01     （当 α = 0.01 时）
```

> ⭐ α 是你自己选的一个小正数，**通常 0 < α < 1**，本课例子用 **α = 0.01**。

### ⚠ tanh 的两个坑

1. **它不是普通的正切函数**。双曲正切的定义是：
   ```
   tanh(z) = (e^z − e^(−z)) / (e^z + e^(−z))
   ```
   用计算器的 **hyperbolic tangent** 键，或者用上面这个指数公式。
2. **tanh 的「输出范围关于零对称」≠「激活的实际均值为零」**——页面专门加了这句括注（the actual activation mean need not be zero）。

**算例**：tanh(1) ≈ **0.7616**，其导数 = 1 − 0.7616² ≈ **0.4200**。
> ⚠ **中间步骤多留几位，最后一步才四舍五入。**

## 3. ⭐⭐ 三个点上的数值表（最可能直接出计算题）

| 函数 | z = −2 | z = 0 | z = 2 |
|---|---|---|---|
| **Sigmoid 输出** | 0.119 | 0.500 | 0.881 |
| **Sigmoid 导数** | **0.105** | **0.250** | **0.105** |
| **tanh 输出** | −0.964 | 0 | 0.964 |
| **tanh 导数** | **0.071** | **1** | **0.071** |
| **ReLU 输出** | 0 | 0 | 2 |
| **ReLU 导数** | **0** | **0** ← 课程约定 | **1** |
| **Leaky ReLU 输出**（α=0.01） | **−0.02** | 0 | 2 |
| **Leaky ReLU 导数** | **0.01** | **0.01** ← 课程约定 | **1** |

### ⭐ 把 z = −2 这一列拆开看（页面专门讲解的一列）

```
sigmoid：a ≈ 0.1192  ⇒  导数 = a(1−a) ≈ 0.1050
ReLU：   输出 0       ⇒  局部导数 0
Leaky：  输出 −0.02   ⇒  导数 +0.01
```

> ⚠⚠ **注意 Leaky ReLU 这一格：输出是负的（−0.02），导数却是正的（+0.01）。**
> 页面原话：**输出的符号和斜率的符号是两回事。**

### 自测：z = −2、传入损失梯度 0.6 时，过 ReLU 和 Leaky ReLU 各传出多少？

```
过 ReLU：        0.6 × 0    = 0        ← 这条路径彻底断了
过 Leaky ReLU：  0.6 × 0.01 = 0.006    ← 很小，但没断
```

## 4. ⭐⭐ 饱和与「死亡 ReLU」

### 饱和（saturation）→ 梯度消失

**sigmoid 和 tanh 的导数在输入绝对值很大时会变得非常小。** 跨越很多层连乘这些小导数，就产生**梯度消失（vanishing gradient）**。

> **页面给的量级感**：五个 0.1 连乘 = **0.00001**，而这还没算上权重因子。

⚠⚠ **但页面特意加了限定**：
> **真实的梯度还包含那些权重、以及跨多条路径的求和。所以「激活斜率小」只是一个成因，不是完整的诊断。**

⇒ 考试里**别把梯度消失一股脑归给激活函数**，这个分寸要有。

### 死亡 ReLU（dead / dying ReLU）

一个 ReLU 单元可能变成**不激活**的：**如果它的预激活对所有相关的训练样本都是负的，它的梯度就是零，可能再也收不到有用的更新。**

⚠⚠ **页面给了一个很重要的限定**：
> **一个 ReLU 对某个观测不激活，对另一个观测可能是激活的。只有当它在相关的那批输入上一直不激活时，才叫它「死了」。**

⇒ **「某个样本上 ReLU 输出 0」≠「这个单元死了」。** 这是个很容易答错的点。

## 5. ⭐⭐ 非线性的概率输出，笔直的决策边界（T1 讲过，这里给了具体数字）

取 **w₁ = w₂ = 1，b = 0** ⇒ **z = x₁ + x₂**

| (x₁, x₂) | z | p = σ(z) | 判类 |
|---|---|---|---|
| (−1, −1) | −2 | ≈ **0.119** | 0 |
| (1, −1) | **0** | **0.500** | **1** ← 见下 |
| (1, 1) | 2 | ≈ **0.881** | 1 |

> ⚠ **中间那个点正好落在边界上**，按本课「**p ≥ 0.5 判类 1**」的约定，**判为类别 1**。

**两种读图方式**（页面用 A/B 两个面板对照）：
- **面板 A 当函数读**：每个输入对有一个概率，由曲面高度表示 ⇒ **这是一个弯曲的非线性曲面，不是平面**。
- **面板 B 当分类规则读**：等高线连接输出值相同的位置，**0.5 那条等高线就是类别改变的地方**。

**接起来**：σ(z) = 0.5 恰好在 z = 0 ⇒ 边界是 **x₁ + x₂ = 0**，**一条直线**——尽管概率曲面是弯的。

### ⚠⚠ 这里有一个措辞很讲究的点

> **限制来自「仿射分数 + 单调激活 + 固定阈值」这个组合，而不是单纯因为「模型只有一个神经元」。**

⭐ 所以**光把多个仿射层叠在最后那个 sigmoid 前面，直边界的限制依然在**。
⇒ **必须有非线性的隐藏激活**，输出分数才可能是「非线性中间特征的加权组合」，它对原始输入就不再是仿射的，**它的零等高线才可能弯曲或分成几段**。

> ⚠ 但页面也补了一句：**隐藏层的非线性让这种边界成为可能，并不保证随便哪组参数都能产生这样的边界。**

## 6. ⭐⭐⭐ 输出层怎么选（M3 考纲逐条点名的内容）

| 任务 | 输出层 | 说明 |
|---|---|---|
| **回归** | **线性输出** | 目标是无约束的实数 |
| **二分类** | **一个 sigmoid** | 表示 **P(y=1 \| x)** |
| **互斥多分类** | **softmax** | **p_k = e^(z_k) / Σ_j e^(z_j)**，概率**加起来等于 1** |
| **多标签**（可同时成立） | **每个标签各一个 sigmoid** | ⚠ **标签之间不必统计独立** |

> **术语**：**logit** 是过 sigmoid 或 softmax **之前**的原始分数，**不是概率**。
> K 个类别时，z_k 和 p_k 分别是类别 k 的分数和概率。

### ⭐ softmax 算例（要会手算）

三个类别的 logits **[1, 2, 0]**：
```
取指数：  [e¹, e², e⁰] ≈ [2.718, 7.389, 1]
求和：    2.718 + 7.389 + 1 = 11.107
归一化：  [0.245, 0.665, 0.090]
```
> **第二类概率最大，三者加起来等于 1。** ✓

### ⭐⭐ 数值稳定技巧：先减去最大的 logit

```
[1, 2, 0] − 2 = [−1, 0, −2]     ⇒  归一化后概率完全相同
```
> **目的**：避免算出不必要的巨大指数。
> ⭐ 这也说明 **softmax 具有平移不变性**——**给每个 logit 都加 5，概率完全不变。**

### ⚠⚠ 三道必考的判断题

| 问题 | 答案 |
|---|---|
| 互斥分类任务里，**两个 softmax 概率能都等于 0.8 吗**？ | **不能**。softmax 的概率加起来必须是 1，0.8+0.8 = 1.6 > 1 |
| 一张图既有猫又在户外，**两个 sigmoid 输出能都等于 0.8 吗**？ | **能**。多标签的各个 sigmoid **各自独立输出，不必加起来等于 1** |
| 给每个 logit 都加 5，softmax 概率变吗？ | **不变**（平移不变性） |

> ⭐ 对于「猫」和「户外」这种可共现的标签，**各自的 sigmoid 输出可以都很高，且不必加起来等于 1**。
> 共享的隐藏特征仍然可能捕捉到标签之间的关系。
> **关键区分是：互斥的类别 vs 可以同时出现的标签。**

## 7. 总结自测

**Q：为什么说激活值、激活导数、损失是三个不同的量？**
> - **激活值**：前向传下去的那个数；
> - **激活导数**：反向时乘在损失梯度上的**局部倍数**；
> - **损失**：衡量预测与目标差距的那个标量。
> ⭐ 三者在计算图上处于不同位置，**大小之间没有必然联系**。

**Q（页面的 Study check）：对每个函数，说出它的输出范围、在一个正输入和一个负输入处的导数、以及它适不适合做输出层的一个理由。**
> 照第 2、3 节那两张表回答即可。⭐ **适不适合做输出层**的关键：
> **sigmoid 适合二分类**（输出就是概率）；**ReLU 不适合**（输出无上界、且负半轴恒为 0）；
> **线性输出适合回归**；**softmax 适合互斥多分类**。

## ⭐ 速查卡

```
导数：  σ′ = σ(1−σ)        tanh′ = 1 − tanh²
        ReLU′  = 0 (z<0), 1 (z>0),  本课约定 ReLU′(0) = 0
        Leaky′ = α (z<0), 1 (z>0),  本课约定 Leaky′(0) = α = 0.01

反向：  传出梯度 = 传入梯度 × 局部导数      导数为 0 ⇒ 这条路径断掉

输出层： 回归→线性   二分类→sigmoid
        互斥多分类→softmax(和为1)   多标签→每标签一个 sigmoid(和不必为1)

softmax： p_k = e^(z_k) / Σ e^(z_j)      ⭐ 先减最大 logit，概率不变
```
