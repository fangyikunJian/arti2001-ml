## 1. 从预测到学习目标

前向传播用**当前**权重和偏置算出一个预测。它**既不告诉你这个预测有没有用，也不改变参数**。

**损失函数**拿 p 和已知目标 y 比较，返回一个数（单个样本记作 L）。**损失越小 = 按所选损失函数衡量匹配得越好。**

> ⭐ 页面给的区分例子：当 **y = 1** 时，本课用的二元交叉熵给 **p = 0.9 的损失比 p = 0.6 更小**。
> ⚠ 注意：**两个预测在 0.5 阈值下都判类 1**，但损失能区分它们的概率估计。
> 若 y = 0，偏好反过来。

⇒ **目标和损失共同定义了「改进」是什么意思。**
⚠ 但这只是针对**一个**带标签样本；光有自信的预测**不能**说明在新数据上表现好。

### 训练的四步

| 步骤 | 内容 |
|---|---|
| Predict | 用当前参数跑一次前向 |
| Measure loss | 把预测和已知目标比较 |
| **Compute gradients** | 求「每个权重和偏置的微小变化会怎样影响损失」 |
| Update | 用这些梯度调整参数，然后用新的前向重复 |

> ⚠ **自测题：把 p 调大总是改进吗？** 不是——取决于 y。y=0 时把 p 调大反而让损失变大。

## 2. ⭐⭐ 反向传播到底是什么（最容易答错的概念题）

一个网络可能有很多权重偏置。隐藏层的权重是**通过后面的神经元间接**影响最终预测的。我们需要一个系统的办法去追踪这些影响，而不是靠猜、也不是把每个参数单独试一遍。

- **导数**衡量「输出对输入的微小变化有多敏感」。
- 损失依赖很多参数时，它的**梯度**把每个参数各自的那一份敏感度收集到一起。
- **反向传播**是高效算出这些梯度的方法：前向跑完之后，**从损失往回**穿过产生它的那些运算，用**链式法则**把相继运算的敏感度组合起来。它**复用中间结果**，所以共享的部分不用重复算。

### ⚠⚠ 两件不同的工作——必考

| | 干什么 |
|---|---|
| **反向传播** | **计算**梯度 |
| **梯度下降**（更新方法） | **使用**这些梯度去改变参数，朝损失下降的方向迈一个合适大小的步子 |

> ⚠ **跑一次反向传播本身不改变任何权重。**
> ⚠ 它**也不是**把前向的算术倒着跑一遍去重建输入。

## 3. 计算图

**计算图是「运算及其依赖关系」的示意图，不是数据点的散点图。** 运算节点做小计算，箭头表示它们需要哪些值。这让「从一个权重到预测」的路线变得可见。

沿用同一个神经元：x₁=1, x₂=2, w₁=0.2, w₂=0.4, b=0.1

```
u = w₁x₁ ,  v = w₂x₂ ,  z = u + v + b ,  p = σ(z)
```

| 阶段 | 运算 | 值 |
|---|---|---|
| 第一支 | u = 0.2 × 1 | **0.2** |
| 第二支 | v = 0.4 × 2 | **0.8** |
| 合并 | z = u + v + 0.1 | **1.1** |
| 变换 | p = σ(z) | **0.750260** |

> ⚠ **u 和 v 是临时的中间计算值，不是输出层权重。**（别和 v₁、v₂ 混。）

### 记号约定
- **Δ**（大写 delta）表示"一个变化量"：Δu 是输入的微小变化，Δf 是由此产生的输出变化。
- **′**（撇）表示导数，如 f′(u)。
- **∂** 用于**偏导数**——函数有好几个独立输入时，**其它独立输入保持不变**。
- **≈** 表示约等于。
- **d**（如 dF/dq）表示 F 作为单个变量的函数时的普通导数。

## 4. 导数 = 敏感度

导数回答："在当前值附近，这个输入每变化一个单位，输出变化多少？"
- **正导数** ⇒ 小幅增加会**抬高**输出
- **负导数** ⇒ **降低**输出
- **大小**描述这个效应在局部的强弱
- ⚠ **它不规定我们应该把参数更新多远。**

### 官方的标量例子（说明「局部近似」）

f(u) = u²，在 u = 3 处斜率 f′(3) = 2×3 = **6**。

```
u: 3 → 3.01        f: 9 → 9.0601        实际变化 0.0601
导数估计的变化：   6 × 0.01 = 0.06
```

> ⭐ 差那一点点，是因为**斜率本身沿着这条弯曲的函数在变**。这是**局部近似**。
> ⚠ 对照：前面那个**仿射**的分数计算里，变化是**精确的**（因为斜率不变）。

### ⭐ 局部导数对照表（要背）

| 运算 | 局部导数 | 含义 |
|---|---|---|
| r = a + b | ∂r/∂a = 1；∂r/∂b = 1 | **加法原样传递**变化 |
| r = a·b | ∂r/∂a = b；∂r/∂b = a | **另一个因子**决定缩放倍数 |
| r = a² | ∂r/∂a = 2a | 敏感度取决于当前值 |
| p = σ(z) | **∂p/∂z = p(1−p)** | sigmoid 递增，敏感度取决于**它的输出** |

> ⚠ 表里的 a、b 是通用的运算数，**不是**别处那个激活 a 和偏置 b。

## 5. ⭐⭐ 链式法则：沿一条路径**相乘**

一个权重的影响必须穿过它和最终概率之间的每一个运算。

**路径：w₂ → v → z → p**

```
∂p/∂w₂ = (∂p/∂z) · (∂z/∂v) · (∂v/∂w₂)
       = p(1−p)  ·    1     ·    x₂
```

代入数字：
```
p(1−p) = 0.750260 × 0.249740 ≈ 0.187370
∂p/∂w₂ = 0.187370 × 1 × 2    ≈ 0.374740
```

⇒ w₂ 增加 0.01，p 大约增加 **0.003747**。

### ⭐ 官方做的「近似校验」（很能说明问题）

```
新分数 z = 1.12  ⇒  p ≈ 0.753989
实际增量 ≈ 0.003729        导数预测 0.003747
```
> 二者**接近但不相同**，因为 **sigmoid 是非线性的，斜率在这一步里略有变化**。
> ⚠ 正的导数告诉我们"在这里增大 w₂ 会抬高 p"，但**还没告诉我们这样做是否可取**——因为我们还没把 p 和目标比较。

### 反向读图（从右往左）

```
起点 ∂p/∂p = 1          （p 自己变一个单位，自己就变一个单位）
过 sigmoid   × 0.187370
过 加法      × 1
过 乘法 v=w₂x₂  × x₂ = 2
───────────────────────
累积结果  ∂p/∂w₂ ≈ 0.374740
```
w₁ 和偏置那两支同理可追。

### 局部 vs 端到端
- **∂p/∂z** 只描述 sigmoid 那一步 —— **局部**
- **∂p/∂w₂** 包含从权重到概率的**整条路径** —— **端到端**

## 6. ⭐⭐ 一个值影响多条路径时：把贡献**相加**

**相乘只在一条路径内部用。** 如果一个量通过**好几条**路径影响结果，还必须把这些路径的效应**加起来**。

官方的小例子：共享值 q 喂给两支，再合并

```
q ──→ r = 2q ──┐
               ├──→ F = r + t
q ──→ t = 3q ──┘

dF/dq = (∂F/∂r)(dr/dq) + (∂F/∂t)(dt/dq)
      =    1  × 2      +    1  × 3       =  5
```

校验：q = 1 时 F = 5；q = 1.01 时 F = 5.05。✓

> ⚠ **只沿 r = 2q 那一支算，会得到 2，漏掉另一支的贡献。**
> ⭐ 在网络里，**一个隐藏激活可能喂给后面多个单元**，所以**它的梯度要收集所有这些路径的贡献**。

## 7. 把反向计算接到损失上

前面算的是 ∂p/∂w₂（权重怎样影响**概率**）。训练需要的是 **∂L/∂w₂**（权重怎样影响**损失**）。

> ∂L/∂w₂ 的意思是：**其它参数和给定的观测保持不变**时，损失对 w₂ 的局部变化率。

把前向依赖链延长一节：**w₂ → v → z → p → L**（目标 y 也是损失计算的一个输入）。
反向就多出一个局部导数：

```
∂L/∂w₂ = (∂L/∂p) × (∂p/∂w₂)
```

### ⭐ 符号分析（考点）

| 因子 | 在本例中 | 理由 |
|---|---|---|
| ∂L/∂p | **负** | y = 1 且用 BCE 时，**增大 p 会降低损失** |
| ∂p/∂w₂ | **正** | 刚算出来是 +0.374740 |
| 乘积 ∂L/∂w₂ | **负** | ⇒ **对这个观测，略微增大 w₂ 会降低损失** |

> ⚠ 这是**局部方向**，**不保证**大步更新也成立。

### 反向传播的完整工作方式
1. 从选定的最终损失开始，**∂L/∂L = 1**
2. 往回累积敏感度
3. 每经过一个运算就**乘**上局部导数
4. 路径汇合处就**加**上各自的贡献
5. **用的是同一次前向传播留下的值**

> ⭐ **只有在参数梯度全部算完之后，梯度下降才去改变权重和偏置。**

## 8. 四道自测题的要点

| 问题 | 要点 |
|---|---|
| 前向值和导数有什么区别？ | 前向值是**算出来的量**；导数是**敏感度**，描述改变某个输入会怎样影响输出 |
| 计算图怎样为训练做准备？ | 它让**从每个参数到损失的路线**变得可见，从而能系统地反向追踪敏感度并复用中间结果 |
| 反向传播和梯度下降各贡献了什么？ | **反向传播算梯度；梯度下降用梯度改参数。**两者是不同的工作 |
| 只有 ∂p/∂w₂ 够不够决定一次更新？ | **不够**。它没和目标比较过，缺 ∂L/∂p；而且它也不规定步长 |
