M3 T1 第 1 课 · 神经网络能学什么

源页面：Neural network introduction: What can a network learn? ｜ https://learn.adelaide.edu.au/courses/30362/pages/neural-network-introduction-what-can-a-network-learn ｜ 整理日期：2026-10-13 ｜ 对应考纲：Topic 1「网络结构与参数维度、前向传播」

1. 一个人工神经元做三件事

加权 → 加偏置 → 过激活函数。

z = w₁x₁ + w₂x₂ + b （pre-activation，预激活 / 分数）
a = g(z) （g 是激活函数，a 是输出）
量含义⚠ 是不是参数
x₁, x₂观测到的输入特征，由样本给定否，是数据
w₁, w₂权重，每个输入的可调贡献是，训练时会变
b偏置，与当前输入无关的可调偏移是
z预激活：加权和加偏置否，算出来的
a激活输出否——⚠ 它随输入而变，不是存下来的参数
  • 权重的方向性：正权重 ⇒ 该输入变大时分数变大；负权重 ⇒ 反之。
  • 偏置：不改变输入，只平移分数。

⚠ 考点易混：a 是「算出来的中间值」，不是参数。问「优化器调整哪些量」时，答案只有权重和偏置。

2. ★ 官方算例（要会复现）

给定 x = [1, 2]，目标 y = 1，初始 w₁ = 0.2, w₂ = 0.4, b = 0.1：

加权： 0.2 × 1 = 0.2 0.4 × 2 = 0.8
求和： z = 0.2 + 0.8 + 0.1 = 1.1
激活： p = σ(1.1) = 1/(1+e^(−1.1)) ≈ 0.750260
判类： 规则「p ≥ 0.5 判类 1」 ⇒ 预测类别 1
★ 概率(≈0.75) 和类别标签(1) 是两个不同的量

，考试爱考这个区分。

概率也写作 P(y=1 | x)，读作「给定输入 x 时类别为 1 的概率」。它是模型的估计，不是正确性的保证。

这整个过程叫前向传播（forward pass）：信息用当前参数从输入流到输出。

⚠ 没有任何参数改变，所以还没有发生学习。 目标 y 在这一步没有被用到——它是训练时用来评判这个预测的。

自测题（页面给的）

  1. 只把 b 从 0.1 提到 0.6，其余不变 ⇒ z = 1.6，概率上升。
  2. 某模型给出 p = 0.99 —— 光凭这个数不能断定它的参数是从数据学来的，也不能断定预测是对的。高置信度 ≠ 学过 ≠ 正确。

3. ⚠⚠ 为什么一个神经元不够——本课最爱考的一个点

决策边界必然是直线

预测规则是「p ≥ 0.5 判类 1」。而 sigmoid 恰好在 z = 0 时等于 0.5，所以决策边界是：

w₁x₁ + w₂x₂ + b = 0

两个输入时，这个方程描述的是一条直线（只要权重不全为 0）。改权重和偏置能平移或旋转这条线，但不能把它弄弯，也不能变出好几条线。

（若两个权重都为 0，预测对任何输入都是常数，同样解决不了。）

★★ 「sigmoid 是非线性的，边界怎么还是直的？」

这是页面专门拎出来讲的一处，必考：

问的是什么答案
概率输出是不是输入的非线性函数？是。sigmoid 让 p 对输入非线性。
决策边界（预测类别发生改变的地方）是什么形状？仍是直线。因为在阈值 0.5 处，类别改变恰好发生在 z = 0 这个位置。

原理：sigmoid 保序——正分数给出 >0.5 的概率，负分数给出 <0.5 的概率。所以「哪里越过 0.5」完全由「哪里 z 越过 0」决定。

什么样的模式一个神经元搞不定

  • 能搞定：蓝点全在左、橙点全在右 ⇒ 一条竖线分开。

例：w₁ = −1, w₂ = 0, b = 0 ⇒ z = −x₁，蓝点分数为正、橙点为负。

  • 搞不定：两类各占对角线上的两个角（异或型）。任何一条直线都会把类别混在一起。
⚠ 关键推论

如果一个 sigmoid 神经元在这种模式上一直出错，训练更久也不可能全分对。

这是模型表达能力的限制，不是训练不足。「再train久一点」是错误选项。

4. 连成网络

  • 层（layer）：计算中处于同一阶段的一组单元。
  • 输入层：提供特征值。
  • 隐藏层：在输入与最终预测之间计算中间值。「隐藏」指这些是内部值，既不是观测到的输入特征、也不是要求的输出。

⚠ 权重下标的读法（容易记反）

w_ji = 从输入 i 到隐藏神经元 j 的权重
第一个下标 = 接收的隐藏神经元
第二个下标 = 输入

所以 w₁₁ 和 w₁₂ 喂给 h₁，w₂₁ 和 w₂₂ 喂给 h₂。输出权重 v₁、v₂ 分别乘 h₁、h₂。

  • 每条有标注的连线都是一个独立的可调参数。
  • 每个计算型神经元都有自己的权重和偏置。
  • ⚠ 图上交叉的箭头不构成额外的神经元。
  • 神经元里标的字母是它的输出名，不是它的权重。

隐藏激活是什么

隐藏激活是用学到的权重算出来的中间特征。不同的权重让不同神经元响应不同的输入组合。

⚠ 这些特征不一定对应人能读懂的概念（比如"某个传感器坏了"）。

⚠ 激活是针对每个样本重新算的，它本身不是存下来的权重。

本课用的激活函数搭配

  • 隐藏层：ReLU，g(z) = max(0, z) —— 「负分数输出 0，否则原样输出」。ReLU(−2) = 0，ReLU(2) = 2。
  • 输出层（二分类）：sigmoid。

5. ★★ 为什么层间必须有非线性——带数字的塌缩论证

光堆层数没用。 如果每层只做"乘权重加偏置"，整串可以改写成一个加权和加偏置。

不加激活函数（会塌缩）

设一个输入 x、一个隐藏值 h、最终分数 s：

第一层： h = 2x + 1
第二层： s = 3h + 4
代入： s = 3(2x + 1) + 4 = 6x + 3 + 4 = 6x + 7

⇒ 一个权重为 6、偏置为 7 的单层，对任何输入都给出完全相同的输出。

两层算下来还是一条直线。

术语：「加权和 + 偏置」叫仿射函数（affine function）。

「层塌缩成一个仿射函数」就是说——整串可以被那一个等价计算替换掉。

插入 ReLU（不再塌缩）

权重偏置完全不变，只让隐藏神经元把负分数置零：

h = max(0, 2x + 1) s = 3h + 4
条件hs
x ≤ −0.5（此时 2x+1 ≤ 0）0s = 3×0 + 4 = 4
x > −0.5（此时 2x+1 > 0）2x + 1s = 6x + 7

两段在 x = −0.5 处相接，该点 s = 4。左边是平的，右边上升——出现了一个折点。

★ 所以没有任何单个仿射计算能对所有输入复现这个函数。

每一段都是直线，但整个函数不是一条直线。

自测：x = −1 时，有 ReLU 得 s = 4，无 ReLU 得 s = 1；x = 1 时两者都是 13。

（x=1 落在 ReLU 不起作用的区域，所以一致；x=−1 落在被截断的区域，所以不同。）

⚠ 「只在最后放个 sigmoid 不行吗？」

不行。 没有非线性的隐藏激活，送进最后那个 sigmoid 之前的分数仍然是原始输入的仿射函数。sigmoid 让概率输出变成非线性，但它的 0.5 阈值仍然对应分数为零——两个输入时仍是一条直的边界。

6. 网络学习时改变的是什么

监督训练反复做这个循环：

步骤做什么
Predict用当前权重和偏置做一次前向传播
Compare用已知目标和损失函数（预测误差的数值度量）评判这个预测
Adjust用「参数如何影响损失」的信息更新权重和偏置
Repeat重新计算预测，在训练样本上继续

⚠ 考点：一次更新中到底什么变了

对固定的一个训练样本 x = [1,2]、y = 1：

问题答案
优化器调整哪些存下来的量？只有权重和偏置
更新之后，同样的输入再过一遍，激活和预测会变吗？会变——因为参数变了
我们会改输入值或目标标签来降低误差吗？绝对不会

★ 网络学到的"知识"是分布在全部权重和偏置里的；

单个神经元一般不存储一条完整的事实。

⚠ 表达能力更强不保证训练成功，也不保证在新数据上预测得好——必须在训练用过的样本之外评估。

7. 其它要知道的术语

  • 前馈网络（feed-forward）：数值从输入经隐藏层流到输出，没有回环。
  • 深度（deep）：指这种层层复合，不是指像人一样思考。
  • 优化器（optimiser）：更新参数的那条规则。

M3 T1 第 2 课 · 反向传播基础：计算图与梯度

源页面：Backpropagation foundations: computational graphs and gradients ｜ https://learn.adelaide.edu.au/courses/30362/pages/backpropagation-foundations-computational-graphs-and-gradients ｜ 整理日期：2026-10-13 ｜ 对应考纲：Topic 1「计算图、链式法则基础」

1. 从预测到学习目标

前向传播用当前权重和偏置算出一个预测。它既不告诉你这个预测有没有用，也不改变参数。

损失函数拿 p 和已知目标 y 比较，返回一个数（单个样本记作 L）。损失越小 = 按所选损失函数衡量匹配得越好。

★ 页面给的区分例子：当 y = 1 时，本课用的二元交叉熵给 p = 0.9 的损失比 p = 0.6 更小。

⚠ 注意：两个预测在 0.5 阈值下都判类 1，但损失能区分它们的概率估计。

若 y = 0，偏好反过来。

⇒ 目标和损失共同定义了「改进」是什么意思。

⚠ 但这只是针对一个带标签样本；光有自信的预测不能说明在新数据上表现好。

训练的四步

步骤内容
Predict用当前参数跑一次前向
Measure loss把预测和已知目标比较
Compute gradients求「每个权重和偏置的微小变化会怎样影响损失」
Update用这些梯度调整参数，然后用新的前向重复
⚠ 自测题：把 p 调大总是改进吗？

不是——取决于 y。y=0 时把 p 调大反而让损失变大。

2. ★★ 反向传播到底是什么（最容易答错的概念题）

一个网络可能有很多权重偏置。隐藏层的权重是通过后面的神经元间接影响最终预测的。我们需要一个系统的办法去追踪这些影响，而不是靠猜、也不是把每个参数单独试一遍。

  • 导数衡量「输出对输入的微小变化有多敏感」。
  • 损失依赖很多参数时，它的梯度把每个参数各自的那一份敏感度收集到一起。
  • 反向传播是高效算出这些梯度的方法：前向跑完之后，从损失往回穿过产生它的那些运算，用链式法则把相继运算的敏感度组合起来。它复用中间结果，所以共享的部分不用重复算。

⚠⚠ 两件不同的工作——必考

干什么
反向传播计算梯度
梯度下降（更新方法）使用这些梯度去改变参数，朝损失下降的方向迈一个合适大小的步子
⚠ 跑一次反向传播本身不改变任何权重。

⚠ 它也不是把前向的算术倒着跑一遍去重建输入。

3. 计算图

计算图是「运算及其依赖关系」的示意图，不是数据点的散点图。 运算节点做小计算，箭头表示它们需要哪些值。这让「从一个权重到预测」的路线变得可见。

沿用同一个神经元：x₁=1, x₂=2, w₁=0.2, w₂=0.4, b=0.1

u = w₁x₁ , v = w₂x₂ , z = u + v + b , p = σ(z)
阶段运算值
第一支u = 0.2 × 10.2
第二支v = 0.4 × 20.8
合并z = u + v + 0.11.1
变换p = σ(z)0.750260
⚠ u 和 v 是临时的中间计算值，不是输出层权重。

（别和 v₁、v₂ 混。）

记号约定

  • Δ（大写 delta）表示"一个变化量"：Δu 是输入的微小变化，Δf 是由此产生的输出变化。
  • ′（撇）表示导数，如 f′(u)。
  • ∂ 用于偏导数——函数有好几个独立输入时，其它独立输入保持不变。
  • ≈ 表示约等于。
  • d（如 dF/dq）表示 F 作为单个变量的函数时的普通导数。

4. 导数 = 敏感度

导数回答："在当前值附近，这个输入每变化一个单位，输出变化多少？"

  • 正导数 ⇒ 小幅增加会抬高输出
  • 负导数 ⇒ 降低输出
  • 大小描述这个效应在局部的强弱
  • ⚠ 它不规定我们应该把参数更新多远。

官方的标量例子（说明「局部近似」）

f(u) = u²，在 u = 3 处斜率 f′(3) = 2×3 = 6。

u: 3 → 3.01 f: 9 → 9.0601 实际变化 0.0601
导数估计的变化： 6 × 0.01 = 0.06

★ 差那一点点，是因为斜率本身沿着这条弯曲的函数在变。这是局部近似。

⚠ 对照：前面那个仿射的分数计算里，变化是精确的（因为斜率不变）。

★ 局部导数对照表（要背）

运算局部导数含义
r = a + b∂r/∂a = 1；∂r/∂b = 1加法原样传递变化
r = a·b∂r/∂a = b；∂r/∂b = a另一个因子决定缩放倍数
r = a²∂r/∂a = 2a敏感度取决于当前值
p = σ(z)∂p/∂z = p(1−p)sigmoid 递增，敏感度取决于它的输出

⚠ 表里的 a、b 是通用的运算数，不是别处那个激活 a 和偏置 b。

5. ★★ 链式法则：沿一条路径相乘

一个权重的影响必须穿过它和最终概率之间的每一个运算。

路径：w₂ → v → z → p

∂p/∂w₂ = (∂p/∂z) · (∂z/∂v) · (∂v/∂w₂)
= p(1−p) · 1 · x₂

代入数字：

p(1−p) = 0.750260 × 0.249740 ≈ 0.187370
∂p/∂w₂ = 0.187370 × 1 × 2 ≈ 0.374740

⇒ w₂ 增加 0.01，p 大约增加 0.003747。

★ 官方做的「近似校验」（很能说明问题）

新分数 z = 1.12 ⇒ p ≈ 0.753989
实际增量 ≈ 0.003729 导数预测 0.003747

二者接近但不相同，因为 sigmoid 是非线性的，斜率在这一步里略有变化。

⚠ 正的导数告诉我们"在这里增大 w₂ 会抬高 p"，但还没告诉我们这样做是否可取——因为我们还没把 p 和目标比较。

反向读图（从右往左）

起点 ∂p/∂p = 1 （p 自己变一个单位，自己就变一个单位）
过 sigmoid × 0.187370
过 加法 × 1
过 乘法 v=w₂x₂ × x₂ = 2
───────────────────────
累积结果 ∂p/∂w₂ ≈ 0.374740

w₁ 和偏置那两支同理可追。

局部 vs 端到端

  • ∂p/∂z 只描述 sigmoid 那一步 —— 局部
  • ∂p/∂w₂ 包含从权重到概率的整条路径 —— 端到端

6. ★★ 一个值影响多条路径时：把贡献相加

相乘只在一条路径内部用。 如果一个量通过好几条路径影响结果，还必须把这些路径的效应加起来。

官方的小例子：共享值 q 喂给两支，再合并

q ──→ r = 2q ──┐
├──→ F = r + t
q ──→ t = 3q ──┘

dF/dq = (∂F/∂r)(dr/dq) + (∂F/∂t)(dt/dq)
= 1 × 2 + 1 × 3 = 5

校验：q = 1 时 F = 5；q = 1.01 时 F = 5.05。✓

⚠ 只沿 r = 2q 那一支算，会得到 2，漏掉另一支的贡献。

★ 在网络里，一个隐藏激活可能喂给后面多个单元，所以它的梯度要收集所有这些路径的贡献。

7. 把反向计算接到损失上

前面算的是 ∂p/∂w₂（权重怎样影响概率）。训练需要的是 ∂L/∂w₂（权重怎样影响损失）。

∂L/∂w₂ 的意思是：其它参数和给定的观测保持不变时，损失对 w₂ 的局部变化率。

把前向依赖链延长一节：w₂ → v → z → p → L（目标 y 也是损失计算的一个输入）。

反向就多出一个局部导数：

∂L/∂w₂ = (∂L/∂p) × (∂p/∂w₂)

★ 符号分析（考点）

因子在本例中理由
∂L/∂p负y = 1 且用 BCE 时，增大 p 会降低损失
∂p/∂w₂正刚算出来是 +0.374740
乘积 ∂L/∂w₂负⇒ 对这个观测，略微增大 w₂ 会降低损失

⚠ 这是局部方向，不保证大步更新也成立。

反向传播的完整工作方式

  1. 从选定的最终损失开始，∂L/∂L = 1
  2. 往回累积敏感度
  3. 每经过一个运算就乘上局部导数
  4. 路径汇合处就加上各自的贡献
  5. 用的是同一次前向传播留下的值
★ 只有在参数梯度全部算完之后，梯度下降才去改变权重和偏置。

8. 四道自测题的要点

问题要点
前向值和导数有什么区别？前向值是算出来的量；导数是敏感度，描述改变某个输入会怎样影响输出
计算图怎样为训练做准备？它让从每个参数到损失的路线变得可见，从而能系统地反向追踪敏感度并复用中间结果
反向传播和梯度下降各贡献了什么？反向传播算梯度；梯度下降用梯度改参数。两者是不同的工作
只有 ∂p/∂w₂ 够不够决定一次更新？不够。它没和目标比较过，缺 ∂L/∂p；而且它也不规定步长

0. 这一课的主线

预测 → 损失 → 梯度 → 更新 → 复查

沿用同一个神经元：x = [1, 2]，y = 1，w = [0.2, 0.4]，b = 0.1

⇒ 分数 z = 1.1，类别 1 概率 p = 0.750260

阈值判类已经对了（0.750 ≥ 0.5 ⇒ 判 1），但模型仍把一部分概率分给了错误的类。

★ 损失提供了一个连续的学习信号，即使类别标签不再变化。

★ 这个设定其实就是把逻辑回归看成一个可训练的神经元。

1. 二元交叉熵 BCE

L = −[ y·log p + (1−y)·log(1−p) ] （自然对数）
y 的取值化简成含义
y = 1L = −log(p)给类别 1 的概率越大，损失越小
y = 0L = −log(1−p)反过来

怎么读这个式子：y 非 0 即 1，所以两项里只会剩一项。(0,1) 区间内概率的自然对数是负的，前面那个负号让损失变成正的。给观测到的那一类分配低概率 ⇒ 惩罚更大。

⚠⚠ 两个必考的坑

  1. 损失里用的是概率 p，不是阈值判出来的类别标签。
绝对不要

先把 p 四舍五入成类别标签再取对数。

  1. y = 1 时的数值感：
pL = −log(p)
0.5≈ 0.6931
0.750260≈ 0.287335 ← 本例
0.9≈ 0.1054

★ p = 0.75 和 p = 0.90 在 0.5 阈值下都判类 1，但 BCE 给 0.90 更小的损失

⇒ 这就是「对/错」之外多出来的信号。

⚠ 但这只是对一个带标签样本的目标函数，并不是说在没见过的或有噪声的数据上，把置信度推向 1 总是合适的。

  • logit = 过 sigmoid 之前的原始分数，这里就是 z。

  • 带下标 i 的导数里，i 选的是某个输入特征和它的权重（这里 i = 1 或 2）。

2. ★★★ 学习信号 δ = p − y（全课最该记的公式）

损失梯度衡量损失对某个参数或分数的微小变化如何响应。负导数意味着该量略微增大会在局部降低损失。

⚠ 注意区别：第 2 课求的是概率的导数，这一课求的是损失的导数。

推导（页面说明这是为了解释、不是让你背）

y = 1 时追两个运算：

L = −log(p) ⇒ ∂L/∂p = −1/p ≈ −1.332871
p = σ(z) ⇒ ∂p/∂z = p(1−p) ≈ 0.187370

链式相乘：
∂L/∂z = (−1/p) × p(1−p) = −(1−p) = p − 1 ≈ −0.249740

结论：对 sigmoid 输出 + BCE，链式法则把「对分数的导数」化简成预测减目标

δ = ∂L/∂z = p − y ≈ 0.750260 − 1 = −0.249740

★ δ 是损失的敏感度，不是一个新的预测值。

再往回一步，得到参数梯度

因为 z = w₁x₁ + w₂x₂ + b，所以 ∂z/∂wᵢ = xᵢ、∂z/∂b = 1：

∂L/∂wᵢ = δ · xᵢ ∂L/∂b = δ
参数损失梯度解读
w₁−0.249740 × 1 = −0.249740略微增大会降低损失
w₂−0.249740 × 2 = −0.499480局部效应是 w₁ 的两倍
b−0.249740略微增大会抬高分数、降低损失

⚠⚠ 两个权重的梯度不同，只是因为两个输入的数值不同（x₁=1, x₂=2）。

这里梯度绝对值更大，不构成「特征更重要」的一般性排序。 —— 这是页面专门警告的一个误读。

3. ★★ 一次梯度下降更新

θ_new = θ − η · (∂L/∂θ)

θ 代表任一个可训练参数（w₁、w₂ 或 b），η 是学习率（步长）。

★★ 所有梯度都必须用更新前的原始参数值算。

梯度指向损失局部上升的方向，减去它就是朝相反方向走。

取 η = 0.1 的完整计算

w₂,new = 0.4 − 0.1 × (−0.499480) = 0.4 + 0.049948 = 0.449948
w₁,new = 0.2 − 0.1 × (−0.249740) = 0.2 + 0.024974 = 0.224974
b,new = 0.1 − 0.1 × (−0.249740) = 0.1 + 0.024974 = 0.124974
⚠ 减去一个负数 = 增大。

三个梯度都是负的，所以三个参数都变大。

⚠⚠ 先把三个梯度全部算完，再从同一个状态一起更新这三个参数（不能算一个更一个）。

更新后复查（要会算这张表）

新分数 z = 0.224974 × 1 + 0.449948 × 2 + 0.124974 ≈ 1.249844
新概率 p = σ(1.249844) ≈ 0.777273
新损失 L = −log(0.777273) ≈ 0.251964
量更新前一次更新后
分数 z1.1000001.249844
类别 1 概率 p0.7502600.777273
BCE 损失0.2873350.251964

⚠⚠ 这只证明在这一个训练样本上有改进，不证明模型能泛化到新观测。

⚠ 要再走一步，必须重新跑前向、重新算梯度。

4. 配套活动：Computational graph by hand

用的是同一个模型（x₁=1, x₂=2, w₁=0.2, w₂=0.4, b=0.1）。

⚠ 这个活动的最终量是概率 p，还没接损失——是在接损失之前先练敏感度。

u = w₁x₁ , v = w₂x₂ , z = u + v + b , p = σ(z)

三个任务：

  1. 画图并计算：画出两条乘法支汇合到 z、再喂给 sigmoid；标出观测输入、参数、中间值；算 u, v, z, p。
  2. 先预测再追一条路径：不先算，先判断增大 w₂ 会抬高还是降低 p；然后算 ∂p/∂w₂，并估计 w₂ 增加 0.01 的效果。

5. 两道总结自测题

Q：反向传播和梯度下降各贡献了学习的哪一部分？

反向传播计算梯度（用链式法则从损失往回累积敏感度）；梯度下降使用这些梯度、按学习率决定的步长改变参数。反向传播本身不改变任何权重。

Q：这次成功的更新是否说明一个神经元能学会任何模式？

不能。

这只说明在这一个样本上损失下降了。第 1 课已经证明：

单个 sigmoid 神经元的决策边界必然是直线，对角分布那种模式再训练多久也分不开——那是模型表达能力的限制。

★ 速查卡（考场上最常用的一串）

前向： z = Σwᵢxᵢ + b p = σ(z) = 1/(1+e^(−z))
损失： y=1 ⇒ L = −log p y=0 ⇒ L = −log(1−p)
信号： δ = ∂L/∂z = p − y ← sigmoid + BCE 专属化简

更新： θ_new = θ − η·∂L/∂θ ← 全部梯度用原参数算完再一起更新
