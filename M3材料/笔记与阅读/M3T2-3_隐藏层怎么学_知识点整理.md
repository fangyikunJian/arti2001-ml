## 0. 这一课要回答的问题

> **隐藏神经元没有自己的观测目标，那怎么决定该怎样改它的权重？**

**答案：追踪它对最终损失的影响。** 隐藏权重改变隐藏分数 → 改变激活 → 改变输出分数 → 最终改变损失。
**链式法则把这串效应连起来，所以隐藏权重可以用和输出神经元同一个最终目标来训练。**

## 1. 网络设定

⚠ **这是一组全新的起始参数，不是 T1 那次更新之后的参数。**
观测仍是 **x = [1, 2]**，目标 **y = 1**。

| 单元 | 输入权重 | 偏置 | 激活 |
|---|---|---|---|
| **隐藏 1** | [0.2, 0.4] | 0.1 | **ReLU** |
| **隐藏 2** | [−0.5, 0.3] | −0.2 | **ReLU** |
| **输出**（输入是 h₁, h₂） | [0.7, −0.4] | −0.1 | **Sigmoid** |

> 📌 隐藏 1 用的是 T1 那套权重偏置，**但激活换成了 ReLU**。

### 记号

- **h₁, h₂** = 隐藏输出；**z₁, z₂** = 它们过 ReLU 之前的分数
- **s** = 最终分数（特意用 s 以区别于隐藏分数）；**p = σ(s)**
- **L** = 这一个观测的 BCE 损失 ⚠ **等同于损失那一课里的 ℓ**
- ⚠ **W 和 b 的下标表示「第几层」，不是幂次**：W₁/b₁ 属隐藏层，W₂ 属输出层
- **w_ji** 连接输入特征 i 到隐藏单元 j；**W₂ = [v₁, v₂]**，**c** 是输出偏置

### ⚠ ReLU 在 0 处的约定（再强调一次）

> ReLU′ = 1（z>0）、0（z<0）。**在恰好为零处数学导数无定义，本课的计算和 notebook 一律用 0。**

## 2. 前向传播

| 步骤 | 计算 | 含义 |
|---|---|---|
| 隐藏 1 | z₁ = 0.2(1) + 0.4(2) + 0.1 = **1.1** ⇒ h₁ = **1.1** | **对这个观测是激活的** |
| 隐藏 2 | z₂ = −0.5(1) + 0.3(2) − 0.2 = **−0.1** ⇒ h₂ = **0** | **对这个观测不激活** |
| 输出分数 | s = 0.7(1.1) − 0.4(0) − 0.1 = **0.67** | 组合两个隐藏激活 |
| 预测与损失 | p = σ(0.67) = **0.661503**；L = −log p = **0.413241** | 与 y = 1 比较 |

> ⚠ **ReLU 不会把隐藏值变成概率——h₁ 完全可以大于 1**（这里就是 1.1）。

### 两道自测

| 问题 | 答案 |
|---|---|
| h₂ = 0，若只把它的输出权重从 −0.4 改成 −0.3，p 会变吗？ | **不会**。因为 **h₂ = 0**，乘以任何权重都是 0 |
| h₂ = 0 是否意味着隐藏单元 2 永远帮不上忙？ | **不是**。⚠ **「在这个观测上不激活」≠「永远不激活」** |

## 3. ⭐⭐⭐ 反向：追一个隐藏权重到损失

挑 **从 x₂ 到隐藏单元 1 的那个权重 0.4**，记作 **w₁₂**
> （**行 1 选隐藏单元 1，列 2 选输入 2**）

**路径：w₁₂ → z₁ → h₁ → s → p → L**

### 四步，每步回答一个更小的问题

```
Step 1  从输出分数起步（sigmoid + BCE 的化简，和 T1 一样）
        ∂L/∂s = p − y = 0.661503 − 1 = −0.338497

Step 2  走到隐藏激活 h₁
        s = 0.7h₁ − 0.4h₂ − 0.1  ⇒  ∂s/∂h₁ = 0.7   ← 就是那个输出权重
        ∂L/∂h₁ = (−0.338497)(0.7) = −0.236948

Step 3  穿过 ReLU
        z₁ = 1.1 > 0  ⇒  局部导数 = 1  ⇒  原样通过
        ∂L/∂z₁ = (−0.236948)(1) = −0.236948
        ⚠ 隐藏单元 2 此刻分数为负，它那边的导数是 0

Step 4  到达选定的权重
        ∂z₁/∂w₁₂ = x₂ = 2
        ∂L/∂w₁₂ = (−0.236948)(2) = −0.473896
```

### 更新这一个权重（η = 0.1）

```
w₁₂,new = 0.4 − 0.1 × (−0.473896) = 0.447390
```
> **梯度为负 ⇒ 在局部增大这个权重有利于这个正例。**

### ⭐ 自测：为什么隐藏层的梯度里会出现输出权重 0.7？

> 因为**隐藏激活对损失的影响必须穿过输出层**。
> **0.7 正是 s 对 h₁ 的局部导数**——没有它，这条链就断了。
> ⇒ **这也解释了 L11 片子里那句「上层权重会出现在下层的梯度里」。**

---

## 4. ⭐⭐ 完成整步更新

### 全部梯度（都用**原始**参数算）

```
输出权重梯度 = (p − y)·[h₁, h₂] = (−0.338497)·[1.1, 0] = [−0.372347, 0]
输出偏置梯度 = p − y            = −0.338497

隐藏 1 的输入权重梯度 = [−0.236948, −0.473896]
隐藏 1 的偏置梯度     = −0.236948
隐藏 2 的输入权重梯度 = [0, 0]      ← 因为它这次不激活
```

> ⚠⚠ **先用原始的输出权重把这些全部算完，然后所有参数一起更新。**

### 一步之后（η = 0.1）

| 参数 | 更新后 |
|---|---|
| 隐藏 1 权重与偏置 | **[0.223695, 0.447390]；0.123695** |
| **隐藏 2 权重与偏置** | **[−0.5, 0.3]；−0.2 ← 完全没变** |
| 输出权重与偏置 | **[0.737235, −0.4]；−0.066150** |
| 新的概率与损失 | **p = 0.700487；L = 0.355979**（原为 p=0.661503；L=0.413241） |

> ⭐ 注意两处「没变」：
> - **隐藏 2 整个没动**——它这次不激活，梯度全是 0；
> - **输出的第二个权重 −0.4 也没动**——因为它的梯度 = (p−y)·h₂ = (p−y)·0 = 0。

### 验算（要会复现）

```
隐藏 1 新分数 = 0.223695(1) + 0.447390(2) + 0.123695 ≈ 1.242169   （仍为正，ReLU 照常通过）
新输出分数 s ≈ 0.849619
新概率 p = σ(0.849619) ≈ 0.700487
```

> ⚠ **用未四舍五入的值计算才准确。**
> ⚠ **只有重新跑一次完整的前向，才能确认「改变全部参数」的合并效果。**
> ⚠ **这个改进只针对这一个样本，不是泛化的证据。**

### ⭐⭐ 自测：为什么隐藏层梯度必须用原来的 0.7，而不是更新后的 0.737235？

> 因为**所有梯度都要在同一个参数状态上求值**——也就是**做前向传播时的那个状态**。
> ⚠ 若中途换用新值，算的就不是这一点处的梯度了，**更新方向会失真**。
> 📌 这和 T1「三个梯度全部算完再一起更新」是同一条纪律。

## 5. 两道总结自测

**Q：隐藏权重没有自己的类别标签，怎么学？**
> **不需要单独的目标。** 它通过「隐藏分数 → 激活 → 输出分数 → 损失」这条链影响最终损失，
> **链式法则把这串效应连起来**，所以可以**用和输出神经元同一个最终观测目标**来训练它。

**Q：反向传播和梯度下降是两套不同的更新规则吗？**
> **不是**，它们是**两件不同的工作**：**反向传播负责算梯度，梯度下降负责用梯度改参数。**
> （这条在 T1 第 2 课已经强调过，是反复考的点。）

## 6. 配套活动：M3 T2 ReLU by hand

> **目的**：看简单的非线性隐藏单元怎样**组合出一个新形状**。
> ⚠ 这是一个**回归式**的小构造、**线性输出**，**不是类别概率模型**。
> **输出特意叫 r，以免和损失那课里的观测目标 y 混淆。**

### 结构

**两个并联的 ReLU 单元，输出相减。两个单元都直接从同一个 x 取输入。**

```
两个输入权重都 = 1
隐藏偏置分别是  0  和  −2
输出权重分别是 +1 和 −1
```

> ⚠⚠ **A 不喂给 B**——**每一支都直接从 x 算**，两个结果再一起进入减法。
> ⚠ **A 和 B 是算出来的隐藏激活，不是训练得到的参数**（这些值是为了演示表示能力而挑的）。

### 三段计算

```
A = ReLU(x)        B = ReLU(x − 2)        r = A − B

x < 0      ：A = 0,     B = 0,      r = 0
0 ≤ x < 2  ：A = x,     B = 0,      r = x
x ≥ 2      ：A = x,     B = x − 2,  r = x − (x−2) = 2
```

### 写成分段函数

```
        ⎧ 0      x < 0
r(x) =  ⎨ x      0 ≤ x < 2
        ⎩ 2      x ≥ 2
```

> **画出来是一条「先平、再上升、再变平」的折线，折点在 x = 0 和 x = 2。**

### ⭐ 自测：x > 2 之后，两个隐藏输出都还在涨，为什么最终输出不涨了？

> 因为**它们以完全相同的速率上涨，而又被相减**——**差值因此是常数。**
> ⭐ 这就是**用 ReLU 搭出「饱和平台」的办法**：两条同斜率的斜坡相减。

### ⚠ 自测：这个构造是否证明「训练一定能发现这组权重」？

> **不能。** 页面明说这些值是**为了演示表示能力而挑选的，不是训练实验得来的**。
> ⇒ **「网络能表示某个函数」和「训练能找到它」是两件事**——这条在 T1 也强调过。

## ⭐ 速查卡：隐藏层梯度四步

```
① ∂L/∂s  = p − y                     （sigmoid + BCE）
② ∂L/∂hⱼ = (∂L/∂s) × vⱼ              （乘上该隐藏单元的输出权重）
③ ∂L/∂zⱼ = (∂L/∂hⱼ) × g′(zⱼ)         （穿过激活；ReLU 时是 1 或 0）
④ ∂L/∂wⱼᵢ = (∂L/∂zⱼ) × xᵢ            （乘上该权重对应的输入）
   ∂L/∂bⱼ  = ∂L/∂zⱼ

⚠ 全部梯度用「同一个（原始）参数状态」算完，再一起更新
⚠ 某隐藏单元不激活 ⇒ 它的输入权重梯度全为 0，该单元这一步完全不动
⚠ h=0 的那个输出权重，梯度 = (p−y)·h = 0，也不动
```
