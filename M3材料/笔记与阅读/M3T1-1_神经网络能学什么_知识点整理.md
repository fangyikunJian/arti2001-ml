## 1. 一个人工神经元做三件事

**加权 → 加偏置 → 过激活函数。**

```
z = w₁x₁ + w₂x₂ + b        （pre-activation，预激活 / 分数）
a = g(z)                    （g 是激活函数，a 是输出）
```

| 量 | 含义 | ⚠ 是不是参数 |
|---|---|---|
| x₁, x₂ | 观测到的输入特征，由样本给定 | 否，是数据 |
| w₁, w₂ | 权重，每个输入的可调贡献 | **是**，训练时会变 |
| b | 偏置，与当前输入无关的可调偏移 | **是** |
| z | 预激活：加权和加偏置 | 否，算出来的 |
| a | 激活输出 | **否**——⚠ 它随输入而变，**不是存下来的参数** |

- **权重的方向性**：正权重 ⇒ 该输入变大时分数变大；负权重 ⇒ 反之。
- **偏置**：不改变输入，只平移分数。

> ⚠ 考点易混：`a` 是「算出来的中间值」，不是参数。问「优化器调整哪些量」时，答案只有**权重和偏置**。

## 2. ⭐ 官方算例（要会复现）

给定 **x = [1, 2]**，目标 **y = 1**，初始 **w₁ = 0.2, w₂ = 0.4, b = 0.1**：

```
加权：  0.2 × 1 = 0.2      0.4 × 2 = 0.8
求和：  z = 0.2 + 0.8 + 0.1 = 1.1
激活：  p = σ(1.1) = 1/(1+e^(−1.1)) ≈ 0.750260
判类：  规则「p ≥ 0.5 判类 1」 ⇒ 预测类别 1
```

> ⭐ **概率(≈0.75) 和类别标签(1) 是两个不同的量**，考试爱考这个区分。
> 概率也写作 P(y=1 | x)，读作「给定输入 x 时类别为 1 的概率」。它是模型的**估计**，不是正确性的保证。

**这整个过程叫前向传播（forward pass）**：信息用**当前参数**从输入流到输出。
⚠ **没有任何参数改变，所以还没有发生学习。** 目标 y 在这一步**没有被用到**——它是训练时用来评判这个预测的。

### 自测题（页面给的）
1. 只把 b 从 0.1 提到 0.6，其余不变 ⇒ z = 1.6，概率**上升**。
2. 某模型给出 p = 0.99 —— **光凭这个数不能断定**它的参数是从数据学来的，**也不能断定预测是对的**。高置信度 ≠ 学过 ≠ 正确。

## 3. ⚠⚠ 为什么一个神经元不够——本课最爱考的一个点

### 决策边界必然是直线

预测规则是「p ≥ 0.5 判类 1」。而 **sigmoid 恰好在 z = 0 时等于 0.5**，所以决策边界是：

```
w₁x₁ + w₂x₂ + b = 0
```

两个输入时，这个方程描述的是**一条直线**（只要权重不全为 0）。改权重和偏置能**平移或旋转**这条线，**但不能把它弄弯，也不能变出好几条线**。
（若两个权重都为 0，预测对任何输入都是常数，同样解决不了。）

### ⭐⭐ 「sigmoid 是非线性的，边界怎么还是直的？」

这是页面专门拎出来讲的一处，必考：

| 问的是什么 | 答案 |
|---|---|
| **概率输出**是不是输入的非线性函数？ | **是**。sigmoid 让 p 对输入非线性。 |
| **决策边界**（预测类别发生改变的地方）是什么形状？ | **仍是直线**。因为在阈值 0.5 处，类别改变恰好发生在 **z = 0** 这个位置。 |

> 原理：**sigmoid 保序**——正分数给出 >0.5 的概率，负分数给出 <0.5 的概率。所以「哪里越过 0.5」完全由「哪里 z 越过 0」决定。

### 什么样的模式一个神经元搞不定

- **能搞定**：蓝点全在左、橙点全在右 ⇒ 一条竖线分开。
  例：w₁ = −1, w₂ = 0, b = 0 ⇒ z = −x₁，蓝点分数为正、橙点为负。
- **搞不定**：两类各占**对角线上的两个角**（异或型）。任何一条直线都会把类别混在一起。

> ⚠ **关键推论**：如果一个 sigmoid 神经元在这种模式上一直出错，**训练更久也不可能全分对**。
> 这是**模型表达能力的限制**，不是训练不足。「再train久一点」是错误选项。

## 4. 连成网络

- **层（layer）**：计算中处于同一阶段的一组单元。
- **输入层**：提供特征值。
- **隐藏层**：在输入与最终预测之间计算中间值。「隐藏」指这些是**内部值**，既不是观测到的输入特征、也不是要求的输出。

### ⚠ 权重下标的读法（容易记反）

```
w_ji  =  从输入 i 到隐藏神经元 j 的权重
         第一个下标 = 接收的隐藏神经元
         第二个下标 = 输入
```
所以 **w₁₁ 和 w₁₂ 喂给 h₁**，**w₂₁ 和 w₂₂ 喂给 h₂**。输出权重 v₁、v₂ 分别乘 h₁、h₂。

- 每条有标注的连线都是一个**独立的可调参数**。
- 每个计算型神经元都有**自己的**权重和偏置。
- ⚠ 图上交叉的箭头**不构成额外的神经元**。
- 神经元里标的字母是**它的输出名**，不是它的权重。

### 隐藏激活是什么

隐藏激活是**用学到的权重算出来的中间特征**。不同的权重让不同神经元响应不同的输入组合。

> ⚠ 这些特征**不一定对应人能读懂的概念**（比如"某个传感器坏了"）。
> ⚠ 激活是**针对每个样本重新算的**，它**本身不是存下来的权重**。

### 本课用的激活函数搭配
- **隐藏层：ReLU**，g(z) = max(0, z) —— 「负分数输出 0，否则原样输出」。ReLU(−2) = 0，ReLU(2) = 2。
- **输出层（二分类）：sigmoid**。

## 5. ⭐⭐ 为什么层间必须有非线性——带数字的塌缩论证

**光堆层数没用。** 如果每层只做"乘权重加偏置"，整串可以改写成**一个**加权和加偏置。

### 不加激活函数（会塌缩）

设一个输入 x、一个隐藏值 h、最终分数 s：

```
第一层： h = 2x + 1
第二层： s = 3h + 4
代入：   s = 3(2x + 1) + 4 = 6x + 3 + 4 = 6x + 7
```

> ⇒ **一个权重为 6、偏置为 7 的单层，对任何输入都给出完全相同的输出。**
> 两层算下来**还是一条直线**。

**术语**：「加权和 + 偏置」叫**仿射函数（affine function）**。
「层塌缩成一个仿射函数」就是说——整串可以被那一个等价计算替换掉。

### 插入 ReLU（不再塌缩）

权重偏置完全不变，只让隐藏神经元把负分数置零：

```
h = max(0, 2x + 1)        s = 3h + 4
```

| 条件 | h | s |
|---|---|---|
| x ≤ −0.5（此时 2x+1 ≤ 0） | 0 | s = 3×0 + 4 = **4** |
| x > −0.5（此时 2x+1 > 0） | 2x + 1 | s = **6x + 7** |

两段在 **x = −0.5** 处相接，该点 **s = 4**。左边是平的，右边上升——**出现了一个折点**。

> ⭐ **所以没有任何单个仿射计算能对所有输入复现这个函数。**
> 每一段都是直线，但整个函数不是一条直线。

**自测**：x = −1 时，有 ReLU 得 s = 4，无 ReLU 得 s = 1；x = 1 时两者都是 13。
（x=1 落在 ReLU 不起作用的区域，所以一致；x=−1 落在被截断的区域，所以不同。）

### ⚠ 「只在最后放个 sigmoid 不行吗？」

**不行。** 没有非线性的隐藏激活，**送进最后那个 sigmoid 之前的分数仍然是原始输入的仿射函数**。sigmoid 让概率输出变成非线性，但它的 0.5 阈值仍然对应分数为零——两个输入时仍是**一条直的边界**。

## 6. 网络学习时改变的是什么

监督训练反复做这个循环：

| 步骤 | 做什么 |
|---|---|
| **Predict** | 用当前权重和偏置做一次前向传播 |
| **Compare** | 用已知目标和**损失函数**（预测误差的数值度量）评判这个预测 |
| **Adjust** | 用「参数如何影响损失」的信息更新权重和偏置 |
| **Repeat** | 重新计算预测，在训练样本上继续 |

### ⚠ 考点：一次更新中到底什么变了

对固定的一个训练样本 x = [1,2]、y = 1：

| 问题 | 答案 |
|---|---|
| 优化器调整哪些**存下来的**量？ | **只有权重和偏置** |
| 更新之后，同样的输入再过一遍，激活和预测会变吗？ | **会变**——因为参数变了 |
| 我们会改输入值或目标标签来降低误差吗？ | **绝对不会** |

> ⭐ 网络学到的"知识"是**分布在全部权重和偏置里**的；
> **单个神经元一般不存储一条完整的事实。**
> ⚠ 表达能力更强**不保证**训练成功，也**不保证**在新数据上预测得好——必须在训练用过的样本之外评估。

## 7. 其它要知道的术语

- **前馈网络（feed-forward）**：数值从输入经隐藏层流到输出，**没有回环**。
- **深度（deep）**：指这种**层层复合**，**不是**指像人一样思考。
- **优化器（optimiser）**：更新参数的那条规则。
