第 1 组：输出值 vs 导数（T2-1 §1）
1. 激活值 a = g(z) 和局部导数 g′(z) 分别在哪一步起作用？
A. a 用在反向乘在传回的梯度上，g′ 用在前向往下一层传递
B. a 用在前向往下一层传递，g′ 用在反向乘在传回的梯度上
C. 两者都只在前向用到，反向另有一套独立的局部系数
D. 两者都只在反向用到，前向传的是未经激活的预激活 z
2. 「大的激活输出意味着大的梯度」这个说法：
A. 正确，输出越大梯度越大
B. 正确，但只对 ReLU 成立
C. 错误，这两件事互不相干
D. 错误，应该说输出越大梯度越小
3. 传入的损失梯度是 0.6，这一步的局部导数是 0.25，传出去的梯度是多少？
A. 0.15
B. 0.85
C. 2.4
D. 0.6
4. 某一步的局部导数恰好为 0，会发生什么？
A. 梯度原样通过，不受影响
B. 梯度反号
C. 这一层的参数会被重置为初始值
D. 这条路径对这个样本的梯度贡献变成 0
5. 激活值、激活导数、损失三者的大小关系是：
A. 激活值越大，损失一定越小
B. 三者在计算图上位置不同，大小之间没有必然联系
C. 激活导数越大，损失一定越小
D. 三者成正比，可以互相推算
答案与解析
1. B —— ⭐⭐ 这是整课的骨架：把「激活函数对预测做了什么」和「它的导数对学习做了什么」分开。
2. C —— ⚠⚠ 页面原话：a large output need not imply a large gradient。
3. A —— 0.6 × 0.25 = 0.15。反向就是不断乘局部导数。
4. D —— ⭐ 这正是 ReLU 负半轴和「死亡 ReLU」的机制来源。
5. B —— ⭐ 这是第 7 节的总结自测：三者是三个不同的量。
第 2 组：四个激活函数及其导数（T2-1 §2）
1. sigmoid 的导数是什么？
A. g′ = 1 − g²
B. g′ = max(0, g)
C. g′ = g(1 − g)
D. g′ = 1/(1 + e^(−g))
2. tanh 的输出范围和导数分别是：
A. (0,1)，g′ = g(1−g)
B. [0,∞)，g′ = 0 或 1
C. (−∞,∞)，g′ = 1
D. (−1,1)，g′ = 1 − g²
3. tanh(1) ≈ 0.7616，它在该点的导数是多少？
A. 0.4200
B. 0.2384
C. 0.7616
D. 0.5800
4. 关于 tanh，下面哪一句是对的？
A. 它就是三角函数里的正切，可以用计算器的 tan 键
B. 它等于 2·sigmoid(z)，可以直接换算
C. 它是双曲正切，tanh(z) = (e^z − e^(−z))/(e^z + e^(−z))
D. 它的输出范围是 (0, 2)，所以比 sigmoid 宽一倍
5. Leaky ReLU 相比 ReLU 的主要好处是什么？
A. 保留一点负侧梯度，可以减少死亡 ReLU
B. 把输出压缩到 (0,1)，便于解释成概率
C. 在正半轴的梯度更大，收敛更快
D. 完全消除了梯度消失问题
答案与解析
1. C —— 1 − g² 是 tanh 的导数，别记混。sigmoid 映到 (0,1)、会饱和。
2. D —— tanh 输出范围关于 0 对称。⚠ 但「输出范围关于零对称」不等于「激活的实际均值为零」—— 页面专门加了这句括注。
3. A —— 1 − 0.7616² ≈ 0.4200。⚠ 中间步骤多留几位，最后一步才四舍五入。
4. C —— ⚠ 它不是普通的正切函数，要用计算器的 hyperbolic tangent 键。
5. A —— g(z) = max(αz, z)，z<0 时导数是 α 而不是 0。⚠ 它并不能完全消除梯度消失。
第 3 组：三个点上的数值表（T2-1 §3）
1. 本课规定 ReLU′(0) 等于多少？
A. 1
B. 0.5
C. 无定义，考试不会考
D. 0
2. z = 2 时 sigmoid 的导数约等于多少？
A. 0.881
B. 0.105
C. 0.250
D. 0.119
3. z = −2 时，Leaky ReLU（α = 0.01）的输出和导数分别是：
A. 输出 −2，导数 1
B. 输出 −0.02，导数 −0.01
C. 输出 0，导数 0.01
D. 输出 −0.02，导数 +0.01
4. z = 0 时 tanh 的导数是多少？
A. 0
B. 0.071
C. 1
D. 0.5
5. z = −2、传入损失梯度 0.6，过 ReLU 和过 Leaky ReLU 分别传出多少？
A. ReLU 传出 0，Leaky ReLU 传出 0.006
B. 都是 0.6，激活函数不改变梯度大小
C. ReLU 传出 0.006，Leaky ReLU 传出 0
D. ReLU 传出 0.6，Leaky ReLU 传出 0.06
答案与解析
1. D —— ⚠⚠ ReLU 在 z = 0 处数学上不可导，各家软件约定不同。本课规定 ReLU′(0) = 0、LeakyReLU′(0) = α = 0.01，考试按这个判。
2. B —— σ(2) ≈ 0.881 ⇒ 0.881 × 0.119 ≈ 0.105。对照：z = 0 时导数是 0.250（最大值），z = −2 时也是 0.105。
3. D —— ⚠⚠ 页面专门讲解的一格：输出的符号和斜率的符号是两回事。
4. C —— 1 − 0² = 1，这是 tanh 导数的最大值。对照 z = ±2 时只有 0.071。
5. A —— 0.6×0 = 0（这条路径彻底断了）；0.6×0.01 = 0.006（很小，但没断）。
第 4 组：饱和与死亡 ReLU（T2-1 §4）
1. 「饱和」指的是什么现象？
A. 激活输出超出了函数本身的值域，必须截断回 (0,1) 区间
B. sigmoid 和 tanh 在输入绝对值很大时导数变得非常小
C. 训练损失连续若干轮不再下降，优化过程完全停滞
D. 权重在反复更新中绝对值无限增大，最终溢出
2. 把梯度消失全部归因于激活函数的斜率，这样的诊断：
A. 正确，激活斜率是唯一成因
B. 不完整，还应该加上学习率这一项
C. 正确，但只适用于 sigmoid
D. 不完整，真实梯度还包含权重以及跨多条路径的求和
3. 某个 ReLU 单元在一个观测上输出 0，可以说它「死了」吗？
A. 可以，输出 0 就是死亡 ReLU 的定义
B. 不可以，它对另一个观测可能是激活的
C. 可以，但要先确认学习率不大于 0.1
D. 不可以，ReLU 永远不会死
4. 死亡 ReLU 的本质原因是什么？
A. 它的输出超过了上界，被截断
B. 它的权重被初始化成了 0
C. 它的预激活对所有相关训练样本都是负的，梯度因此为零
D. 它所在的层被优化器跳过了
5. 下面哪种激活函数在正半轴不饱和？
A. ReLU
B. tanh
C. sigmoid
D. 以上三者都会饱和
答案与解析
1. B —— 跨越很多层连乘这些小导数就产生梯度消失。页面给的量级感：五个 0.1 连乘 = 0.00001。
2. D —— ⚠⚠ 页面特意加的限定：「激活斜率小」只是一个成因，不是完整的诊断。
3. B —— ⚠⚠ 只有当它在相关的那批输入上一直不激活时，才叫它死了。这是个很容易答错的点。
4. C —— 零梯度 ⇒ 可能再也收不到有用的更新。Leaky ReLU 保留 α 的斜率正是为了缓解这个。
5. A —— ReLU 正半轴导数恒为 1。代价是负输入拿到零梯度。

1. w₁ = w₂ = 1、b = 0 时，点 (1, −1) 的 z 和判类分别是：
A. z = 0，判类 0
B. z = 0，判类 1
C. z = 2，判类 1
D. z = −2，判类 0
2. 把概率输出当作曲面来看，它是什么形状？
A. 一个平面，因为 z 是输入的仿射函数
B. 一组互相平行的直线
C. 一个弯曲的非线性曲面
D. 一个阶梯状的分段常数面
3. 决策边界是直线这个限制，来自什么？
A. 「仿射分数 + 单调激活 + 固定阈值」这个组合
B. 因为使用了 sigmoid 这个特定函数
C. 单纯因为模型只有一个神经元
D. 因为输入只有两个特征
4. 有了非线性的隐藏激活之后，决策边界：
A. 一定会变弯，只要隐藏层里有一个 ReLU 单元就够了
B. 会变成若干条互相平行的直线，条数等于隐藏单元个数
C. 仍然必然是直线，非线性只改变概率曲面不改变边界
D. 可能弯曲或分成几段，但不保证随便哪组参数都能产生这样的边界
5. 点 (−1, −1) 在 w₁ = w₂ = 1、b = 0 下的概率约为多少？
A. 0.964
B. 0.500
C. 0.881
D. 0.119
答案与解析
1. B —— z = 1 + (−1) = 0 ⇒ p = 0.500。⚠ 按本课「p ≥ 0.5 判类 1」的约定，正好落在边界上的点判为类别 1。
2. C —— 面板 A 当函数读是弯曲曲面；面板 B 当分类规则读，0.5 那条等高线就是类别改变的地方。
3. A —— ⚠⚠ 这里措辞很讲究。⭐ 所以光把多个仿射层叠在最后那个 sigmoid 前面，直边界的限制依然在。
4. D —— ⚠ 页面补的那一句限定：隐藏层的非线性让这种边界成为可能，并不保证。
5. D —— z = −2 ⇒ σ(−2) ≈ 0.119 ⇒ 判类 0。对照 (1,1)：z = 2 ⇒ 0.881 ⇒ 判类 1。

1. 每张照片恰好属于六个类别中的一个，标签存成整数 0–5。应该用什么？
A. 一个线性输出 + 均方误差
B. 六个独立 sigmoid 输出 + 二元交叉熵
C. 六个 softmax 输出 + sparse categorical cross-entropy

2. 一张图可以同时带「猫」和「户外」两个标签，应该用什么输出层？
A. softmax，让两个概率加起来等于 1
B. 每个标签各一个 sigmoid，各自独立输出
C. 一个线性输出，用阈值切成多段
D. 一个 sigmoid，再按大小排序取前两名
3. logits [1, 2, 0] 的 softmax 概率约为：
A. [0.245, 0.665, 0.090]
B. [0.333, 0.333, 0.333]
C. [0.200, 0.700, 0.100]
D. [2.718, 7.389, 1.000]
4. 给每个 logit 都加 5，softmax 概率会怎样？
A. 全部变大
B. 完全不变
C. 最大的那个变大，其余变小
D. 全部趋近于 1/K
5. 互斥分类任务里，两个 softmax 概率能都等于 0.8 吗？
A. 不能，softmax 的概率加起来必须是 1，而 0.8 + 0.8 = 1.6
B. 能，只要类别数足够多，剩下的概率质量够分配给其它类别
C. 能，softmax 不限制单个概率的大小，只要每一项都在 (0,1) 内即可
D. 不能，softmax 每一项的输出上界被归一化限制在 0.5 以内
答案与解析
1. C —— 这是 M3 考纲页给的官方示例选择题。softmax 表示互斥的类别，sparse 版损失接受整数类别标签。
2. B —— ⚠ 多标签的各个 sigmoid 不必加起来等于 1，而且标签之间不必统计独立。
3. A —— 取指数 ≈ [2.718, 7.389, 1]，和 = 11.107，归一化即得。三者加起来等于 1。
4. B —— ⭐ softmax 具有平移不变性。数值稳定技巧「先减去最大的 logit」正是利用这一点，目的是避免算出不必要的巨大指数。
5. A —— 对照：多标签的两个 sigmoid 可以都是 0.8。关键区分是：互斥的类别 vs 可以同时出现的标签。
第 7 组：ℓ 与 L · 回归损失（T2-2 §1–2）
1. 记号 ℓᵢ 和 L 分别指什么？
A. ℓᵢ 是平均损失，L 是单样本损失
B. 两者都是单样本损失，只是层级不同
C. ℓᵢ 是单样本损失，L = (1/N)Σℓᵢ 是平均损失
D. ℓᵢ 是损失，L 是对数似然
2. 目标 [3, −1]、预测 [2, 1]，MSE 等于多少？
A. 1.5
B. 0.5
C. 5.0
D. 2.5
3. 某个残差从 2 变成 4，平方误差与绝对误差的贡献各变成几倍？
A. 平方 ×2，绝对 ×2
B. 平方 ×4，绝对 ×2
C. 平方 ×2，绝对 ×4
D. 平方 ×16，绝对 ×4
4. MSE 和 MAE 在单位上有什么区别？
A. MSE 是目标单位的平方，MAE 保持目标的单位
B. MSE 保持目标单位，MAE 是单位的平方
C. 两者都保持目标的单位
D. 两者都是无量纲的
5. 「数据里有极端值，所以改用 MAE 就对了」这个说法：
A. 对，MAE 天然优于 MSE
B. 对，只要极端值占比低于 5%
C. 不完整，应该同时用两个损失取平均
D. 不完整，选择应反映数据生成过程和误差的真实代价
答案与解析
1. C —— ⚠⚠ Topic 1 用 L 表示单个观测的损失，到 Topic 2 那个量改叫 ℓᵢ。跨 Topic 最容易混。
2. D —— 残差（预测 − 目标）= [−1, 2]，平方 [1, 4]，MSE = (1+4)/2 = 2.5。同一组数的 MAE = (1+2)/2 = 1.5。
3. B —— 4 → 16 是 ×4（平方），2 → 4 是 ×2（线性）。一个残差 10 对平方误差贡献 100、对绝对误差贡献 10。
4. A —— 另外 MSE 和 MAE 估计的是目标的不同概括量：分别对应条件均值和条件中位数。
5. D —— ⚠⚠ 而且 MAE 修不了系统性的错误标签、缺失的人群、或者数据泄漏。
第 8 组：分类损失（T2-2 §3–4）
1. one-hot 目标下的多类交叉熵，单样本损失等于什么？
A. 所有类别概率的负对数之和
B. 最大概率的负对数
C. 给正确类别的那个概率的负对数
D. 概率向量与目标向量的欧氏距离
2. 真实类别是 2（编号 1,2,3），概率 [0.1, 0.7, 0.2]，损失是多少？
A. −ln 0.1 ≈ 2.303
B. −ln 0.2 ≈ 1.609
C. ln 0.7 ≈ −0.3567
D. −ln 0.7 ≈ 0.3567
3. sparse categorical cross-entropy 和普通 categorical cross-entropy 的关系是：
A. 它在类别很多时会丢弃小概率项，所以结果不同
B. 它是对稀疏特征设计的，和标签格式无关
C. 它用整数类别标签代替 one-hot 向量，表示的是同一个计算
D. 它用的是以 2 为底的对数
4. y = 0、p = 0.8 时，交叉熵损失约等于多少？
A. 0.105
B. 1.609
C. 0.223
D. 0.357
5. 两个分类器做出完全相同的硬判定，它们的交叉熵一定相同吗？
A. 不一定，因为它们的概率可能不同
B. 一定相同，判定相同则损失相同
C. 一定相同，除非阈值不是 0.5
D. 不一定，但差距不会超过 0.5
答案与解析
1. C —— ⭐ 因为恰好只有一个目标分量是 1，所以 只有「分配给观测到的那个类别」的概率进入损失。
2. D —— one-hot 目标 [0,1,0]，只剩中间那一项。⚠ 全部交叉熵计算都用自然对数 ln。
3. C —— ⚠⚠ 整数标签的实现可能把类别编号成 0,1,2 —— 永远要核对映射关系。
4. B —— 正确类是 0，它的概率是 1 − 0.8 = 0.2 ⇒ −ln(0.2) ≈ 1.609。⭐ 有把握但判错，会受到很大的惩罚。对照 y=0、p=0.1 时只有 0.105。
5. A —— ⚠ 损失是一个优化目标；准确率数的是阈值判定之后的决策。而且只有在任务、单位、聚合约定都可比时，才能比较损失数值。
第 9 组：输出–损失配对与平均（T2-2 §5–6）
1. 软件里「数值稳定」的损失函数常常直接接收原始 logits。使用时要注意什么？
A. 要把学习率调小一个数量级
B. 只能用于二分类，不能用于多分类
C. 要先把 logits 归一化到 (0,1)

第 10 组：为什么 sigmoid 配 BCE（T2-2 §7–8）
1. 「半平方误差」ℓ = ½(a − y)² 和讲义里的 MSE 公式有什么不同？
A. 两者完全相同，½ 只是为了书写方便，不影响任何导数

C. 半平方只能用于分类任务，MSE 只能用于连续回归任务
D. 半平方在取对数之后才求导，所以多出一个自然对数因子

B. (a − y) / a(1−a)
C. a(1−a)
D. (a − y) · a(1−a)
3. y = 1、a = 0.01（非常自信地判错）时，两种搭配的 logit 梯度各是多少？
A. 半平方 −0.009801，BCE −0.99
B. 半平方 −0.99，BCE −0.009801
C. 两者都是 −0.99
D. 两者都是 −0.009801
4. 「用了 BCE 就不会有小梯度问题了」这个说法：
A. 错误，这个优势只针对这一对输出–损失组合，深层网络别处仍可能出现小梯度
B. 正确，只要网络不超过三层，BCE 就能保证梯度不衰减
C. 正确，BCE 从根本上解决了梯度消失，与网络深度无关
D. 错误，BCE 的 logit 梯度其实比半平方误差的更小一些
5. softmax + 交叉熵的 logit 梯度 p − y 有一个很好的自查性质，是什么？

B. 各项的绝对值相等
C. 各项加起来等于零
D. 各项加起来等于 1
答案与解析
1. B —— ⚠ 推导前先说清楚用的是哪个约定，否则系数就错了。
2. D —— ⭐⭐ 多出来的 a(1−a) 就是祸根：sigmoid 饱和时它非常小。
3. A —— (0.01−1)×0.01×0.99 = −0.009801 vs 0.01−1 = −0.99。符号都主张抬高 logit，但半平方小了整整两个数量级。
4. A —— ⚠ 页面的限定。
5. C —— 例：p = (0.1,0.7,0.2)、真实类别 2 ⇒ 梯度 (0.1, −0.3, 0.2)，和为 0。⭐ 正确类别那一项是负的 ⇒ 梯度下降会抬高那个 logit。
