## ⭐⭐ Module 3 记号表（跨全模块通用，考场速查）

下标 1 / 2 加在**矩阵**名上表示**第几层**；加在小写符号上表示**第几个单元或输入**。

| 符号 | 含义 |
|---|---|
| **x**（元素 xᵢ） | 一个观测的输入列向量 |
| **W₁, b₁** | 隐藏层权重矩阵与偏置列；**w_ji = 从输入 i 到隐藏单元 j 的权重** |
| **z**（元素 zⱼ） | 隐藏层分数 / 预激活：**z = W₁x + b₁** |
| **h**（元素 hⱼ） | 隐藏层输出：**h = g(z)**，g 是隐藏激活（如 ReLU） |
| **m** | 隐藏单元个数 |
| **W₂ = [v₁ … v_m], c** | 输出层权重与输出偏置 |
| **s** | 输出分数 / **logit**：**s = W₂h + c** |
| **p** | 类别 1 的预测概率：**p = σ(s)** |
| **y, ŷ** | 观测目标；ŷ 是数值预测（如回归里） |
| **L, δ** | 损失；**δ = ∂L/∂s 是输出学习信号**（sigmoid 输出 + BCE 时 **δ = p − y**） |
| **η** | 梯度下降更新里的学习率 |

### ⚠ 两个容易栽的记号陷阱

1. **单神经元的课**写的是 `z = wᵀx + b`、`a = g(z)`；**多层的课**用上面那套 z/h/s/p。别混。
2. **代码里**名为 `W1`、`W2` 的数组存的是 **W₁ᵀ 和 W₂ᵀ**（转置），因为数据数组里**每一行是一个观测**。
3. 损失记号跨 Topic 会变：**T1 用 L 表示单个观测的损失；T2 用 ℓ 表示单观测、用 L 表示多观测的平均。**

## 模块定位

- **Module 1 / 2 按「训练信息」分类**（监督 / 无监督）；**Module 3 讲的是一个模型家族，不是第三种学习范式。**
- 神经网络在监督、无监督、以及自监督（目标由数据自己构造）场景下都能用。
- 本课核心聚焦：**用于监督预测的小型前馈网络**；更高级的架构只作背景了解。
- **前馈（feed-forward）** = 信息从输入经隐藏层流向输出，**没有回环**。
- **深度（deep）** 指这种层层复合，**不是**指像人一样思考。

| Topic | 内容 |
|---|---|
| **T1** 理解网络与一次学习步 | 神经元、前向预测、计算图与反向传播基础，**以单神经元的一次更新收尾** |

1. 描述神经网络的基本架构与组成部分，**包括激活函数和损失函数**。

## Topic 1 的前置要求与学习顺序

**开始前应该已经会**：
- 计算加权和、知道偏置的作用
- 检查基本矩阵乘法的维度
- 回忆 M1 的 sigmoid，并**区分概率和阈值判出的类别标签**
- 区分「观测到的输入与目标」和「预测与可训练参数」

> 不需要事先懂反向传播，第 2 课会introduce所需的导数与链式法则。

**学习顺序**：
1. What can a network learn? → 神经元、层、非线性表示
2. Neural network playgrounds → 分类与回归两种任务里探索预测
3. Backpropagation foundations → 损失、敏感度、链式法则 → 然后做 **Computational graph by hand**
4. How one neuron learns → 算损失梯度、做一次更新、复查结果

**预计学习时间**：约 **3.5–4 小时**（不含排定的 tutorial 和 practical）。

> ⚠ **不要求在 Topic 2 之前会算隐藏层梯度。**
