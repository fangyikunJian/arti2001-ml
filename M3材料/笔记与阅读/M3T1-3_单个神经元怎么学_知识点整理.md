## 0. 这一课的主线

```
预测  →  损失  →  梯度  →  更新  →  复查
```

沿用同一个神经元：**x = [1, 2]，y = 1，w = [0.2, 0.4]，b = 0.1**
⇒ 分数 z = 1.1，类别 1 概率 p = 0.750260

> 阈值判类已经**对了**（0.750 ≥ 0.5 ⇒ 判 1），但模型仍把一部分概率分给了错误的类。
> ⭐ **损失提供了一个连续的学习信号，即使类别标签不再变化。**
> 📌 这个设定其实就是**把逻辑回归看成一个可训练的神经元**。

---

## 1. 二元交叉熵 BCE

```
L = −[ y·log p + (1−y)·log(1−p) ]        （自然对数）
```

| y 的取值 | 化简成 | 含义 |
|---|---|---|
| y = 1 | **L = −log(p)** | 给类别 1 的概率越大，损失越小 |
| y = 0 | **L = −log(1−p)** | 反过来 |

**怎么读这个式子**：y 非 0 即 1，所以**两项里只会剩一项**。(0,1) 区间内概率的自然对数是负的，前面那个负号让损失变成正的。**给观测到的那一类分配低概率 ⇒ 惩罚更大。**

### ⚠⚠ 两个必考的坑

1. **损失里用的是概率 p，不是阈值判出来的类别标签。**
   > **绝对不要**先把 p 四舍五入成类别标签再取对数。
2. y = 1 时的数值感：

| p | L = −log(p) |
|---|---|
| 0.5 | ≈ **0.6931** |
| 0.750260 | ≈ **0.287335** ← 本例 |
| 0.9 | ≈ **0.1054** |

> ⭐ p = 0.75 和 p = 0.90 **在 0.5 阈值下都判类 1**，但 BCE 给 0.90 更小的损失
> ⇒ **这就是「对/错」之外多出来的信号。**
> ⚠ 但这只是对一个**带标签样本**的目标函数，**并不是说在没见过的或有噪声的数据上，把置信度推向 1 总是合适的**。

### ⚠ 记号约定（跨 Topic 容易混）

| 记号 | 本课（T1） | Topic 2 |
|---|---|---|
| 单个观测的损失 | **L** | **ℓ**（小写 ell） |
| 多个观测的平均损失 | —（本课只有一个观测，不需要平均） | **L** |

- **logit** = 过 sigmoid 之前的原始分数，这里就是 **z**。
- **δ**（小写 delta）是一个**有名字的损失梯度**；⚠ 和表示"有限变化量"的 **Δ** 不是一回事。
- 带下标 i 的导数里，**i 选的是某个输入特征和它的权重**（这里 i = 1 或 2）。

## 2. ⭐⭐⭐ 学习信号 δ = p − y（全课最该记的公式）

**损失梯度**衡量损失对某个参数或分数的微小变化如何响应。**负导数**意味着该量**略微增大会在局部降低损失**。

> ⚠ 注意区别：第 2 课求的是**概率**的导数，这一课求的是**损失**的导数。

### 推导（页面说明这是为了解释、不是让你背）

y = 1 时追两个运算：

```
L = −log(p)      ⇒  ∂L/∂p = −1/p      ≈ −1.332871
p = σ(z)         ⇒  ∂p/∂z = p(1−p)    ≈  0.187370

链式相乘：
∂L/∂z = (−1/p) × p(1−p) = −(1−p) = p − 1 ≈ −0.249740
```

### 结论：对 sigmoid 输出 + BCE，链式法则把「对分数的导数」化简成**预测减目标**

```
δ = ∂L/∂z = p − y ≈ 0.750260 − 1 = −0.249740
```

> ⭐ δ 是**损失的敏感度**，**不是一个新的预测值**。

### 再往回一步，得到参数梯度

因为 z = w₁x₁ + w₂x₂ + b，所以 **∂z/∂wᵢ = xᵢ**、**∂z/∂b = 1**：

```
∂L/∂wᵢ = δ · xᵢ              ∂L/∂b = δ
```

| 参数 | 损失梯度 | 解读 |
|---|---|---|
| w₁ | −0.249740 × 1 = **−0.249740** | 略微增大会降低损失 |
| w₂ | −0.249740 × 2 = **−0.499480** | 局部效应是 w₁ 的**两倍** |
| b | **−0.249740** | 略微增大会抬高分数、降低损失 |

> ⚠⚠ **两个权重的梯度不同，只是因为两个输入的数值不同（x₁=1, x₂=2）。**
> **这里梯度绝对值更大，不构成「特征更重要」的一般性排序。** —— 这是页面专门警告的一个误读。

## 3. ⭐⭐ 一次梯度下降更新

```
θ_new = θ − η · (∂L/∂θ)
```

θ 代表任一个可训练参数（w₁、w₂ 或 b），η 是**学习率**（步长）。

> ⭐⭐ **所有梯度都必须用更新前的原始参数值算。**
> 梯度指向损失**局部上升**的方向，**减去**它就是朝相反方向走。

### 取 η = 0.1 的完整计算

```
w₂,new = 0.4 − 0.1 × (−0.499480) = 0.4 + 0.049948 = 0.449948
w₁,new = 0.2 − 0.1 × (−0.249740) = 0.2 + 0.024974 = 0.224974
b,new  = 0.1 − 0.1 × (−0.249740) = 0.1 + 0.024974 = 0.124974
```

> ⚠ **减去一个负数 = 增大。**三个梯度都是负的，所以三个参数都变大。
> ⚠⚠ **先把三个梯度全部算完，再从同一个状态一起更新这三个参数**（不能算一个更一个）。

### 更新后复查（要会算这张表）

```
新分数 z = 0.224974 × 1 + 0.449948 × 2 + 0.124974 ≈ 1.249844
新概率 p = σ(1.249844)                            ≈ 0.777273
新损失 L = −log(0.777273)                          ≈ 0.251964
```

| 量 | 更新前 | 一次更新后 |
|---|---|---|
| 分数 z | 1.100000 | **1.249844** |
| 类别 1 概率 p | 0.750260 | **0.777273** |
| BCE 损失 | 0.287335 | **0.251964** |

> ⭐ **概率朝目标移动，损失下降。类别标签仍然是 1，但损失改善了。**
> ⚠⚠ 这**只证明在这一个训练样本上有改进**，**不证明模型能泛化到新观测**。
> ⚠ 要再走一步，必须**重新跑前向、重新算梯度**。
> 📌 展示的数值是四舍五入过的，**计算过程中要保留完整精度**。

### 两道自测题

| 问题 | 答案 |
|---|---|
| 如果 w₁ 更新时用了**加号**会怎样？ | 得到 0.2 + (−0.024974) = 0.175026，**局部上会让损失变大**（走错了方向） |
| 这次更新应该同时改变 x 或 y 吗？ | **绝对不**。只有权重和偏置被更新；输入和目标是给定的数据 |

## 4. 配套活动：Computational graph by hand

用的是同一个模型（x₁=1, x₂=2, w₁=0.2, w₂=0.4, b=0.1）。
⚠ **这个活动的最终量是概率 p，还没接损失**——是在接损失之前先练敏感度。

```
u = w₁x₁ ,  v = w₂x₂ ,  z = u + v + b ,  p = σ(z)
```

三个任务：
1. **画图并计算**：画出两条乘法支汇合到 z、再喂给 sigmoid；标出观测输入、参数、中间值；算 u, v, z, p。
2. **先预测再追一条路径**：不先算，先判断增大 w₂ 会抬高还是降低 p；然后算 ∂p/∂w₂，并估计 w₂ 增加 0.01 的效果。
3. **解释学习还需要什么**：知道「怎样增大 p」**并不能**告诉我们这个改变是否改进了预测——还需要**目标 y 和损失**。

## 5. 两道总结自测题

**Q：反向传播和梯度下降各贡献了学习的哪一部分？**
> 反向传播**计算**梯度（用链式法则从损失往回累积敏感度）；梯度下降**使用**这些梯度、按学习率决定的步长**改变参数**。反向传播本身不改变任何权重。

**Q：这次成功的更新是否说明一个神经元能学会任何模式？**
> **不能。** 这只说明在这一个样本上损失下降了。第 1 课已经证明：
> **单个 sigmoid 神经元的决策边界必然是直线**，对角分布那种模式**再训练多久也分不开**——那是模型表达能力的限制。

## ⭐ 速查卡（考场上最常用的一串）

```
前向：  z = Σwᵢxᵢ + b        p = σ(z) = 1/(1+e^(−z))
损失：  y=1 ⇒ L = −log p      y=0 ⇒ L = −log(1−p)
信号：  δ = ∂L/∂z = p − y          ← sigmoid + BCE 专属化简
梯度：  ∂L/∂wᵢ = δ·xᵢ        ∂L/∂b = δ
更新：  θ_new = θ − η·∂L/∂θ   ← 全部梯度用原参数算完再一起更新
```
