      T2-011. 路线图与这一周的考核重点

      聚类是无监督学习里用来提出有用分组的核心任务。结果取决于所选特征、缩放、算法与参数，所以一个拟合出来的划分应当被当作基于模型的提案，而不是自动就是数据里的「真实」分组。

      算法一句话定义关键特点
      k-means把观测划分成预先给定的 k 个簇，最小化到各簇质心的平方欧氏距离之和每个点都必须有标签；倾向紧致、凸的区域
      DBSCAN从连通的稠密区域构建簇，稀疏区域的点可被标为噪声不需要预先给 k；能还原非球形；对缩放与 eps/min_samples 非常敏感
      ★ 讲义原文的考核重点（ASSESSMENT FOCUS）

      你需要能够：计算并解释小例子、比较算法假设、用不止一种证据来论证结论。

      你不需要记住软件的默认值。

      八条学习成果

      1. 把聚类解释为「在无标签数据中发现结构」；
      2. 对一个小数据集执行 k-means 的指派步与质心更新步；
      3. 解释 k-means 的目标函数，并评估一个 k 的选择；
      4. 用 DBSCAN 的邻域规则识别核心点、边界点、噪声点；
      5. 比较 k-means 与 DBSCAN 的假设与行为；
      6. 解释特征缩放与参数选择如何影响聚类结果；
      7. 在 Python 里拟合两者并解释主要输出；
      8. 用内部证据、稳定性、假设与领域有用性来评估聚类结果。

      T2-022. 什么是聚类：相似是建模选择

      聚类按照所用的表示与建模选择，把观测分组成：组内相对相似、组间相对不相似。

      ★★ 和分类的根本差别

      分类有已知的类标签要去复现；聚类没有。

      但聚类也不是在自动搜索唯一正确的分组：分析者仍然要选择怎么表示观测、怎么度量相似、用哪个算法、参数怎么设。

      四件事一改，结果就可能变

      可变项内容
      特征 / 表示用哪些信息来描述每个观测
      特征缩放量级大的特征会不会主导比较
      距离或模型假设这个方法能表示什么形状的组
      算法与参数例如 k-means 的 k，或 DBSCAN 的邻域设置
      ⭐ 讲义举的那个例子，很好用来答简答题

      两位顾客年度消费相同、但购买频率差别很大。

      如果表示里只有年度消费，算法就用不上频率来区分他们。

      如果消费以美元计（量级大），而频率只在 1 到 20 之间，未缩放的欧氏距离会被消费主导。

      加入并适当缩放频率，就改变了「相似」的含义，于是可能改变拟合出来的簇 —— 尽管这两位顾客本身一点没变。

      七步实用工作流

      1. 定义目的：这个分组要支持什么决策或探索；
      2. 选定观测单位：比如一行一个顾客，而不是一行一笔交易；
      3. 构建表示：选特征、处理缺失与重复、必要时变换或缩放；
      4. 检查几何：看图或摘要，留意离群点、弯曲结构、密度不均、高维效应；
      5. 拟合不止一种配置：比较相邻的 k、多次初始化、几组 DBSCAN 邻域设置；
      6. 评估多个信号：内部分数 + 稳定性 + 模型假设 + 领域有用性；
      7. 谨慎解释：描述各组之间差在哪，不要把数字标签当成身份。

      T2-033. k-means：算法与目标函数

      前提：欧氏距离

      d(x, y) = √( (x1−y1)² + (x2−y2)² + … + (xn−yn)² ) = √( Σi=1n(xi−yi)² )
      ⭐ 手算时不用开根号

      指派步只是比大小，而平方根是单调的，所以直接比平方距离即可。Tutorial 的参考答案也是这么做的，还省掉了无理数。

      四步算法

      步骤内容
      ① 初始化选 k（靠领域知识或肘部法等）；初始化质心。实践中常用 k-means++，因为它把起始中心拉开。不同起点会收敛到不同局部解，所以要多次初始化并保留 WCSS 最低的那次
      ② 指派对每个点算到每个质心的欧氏距离，归给最近的那个质心
      ③ 更新每个簇的新质心是所有被指派进来的点的均值：µi = (1/m)Σj=1m xj
      ④ 迭代重复 ②③，直到：指派不再变化 / 质心稳定 / 达到最大迭代次数

      ★★ 为什么这两步有效：目标函数

      WCSS = Σi=1k Σx∈C_{i} d(x, µi)² （也叫 inertia / 惯性）
      ★★★ 两步为什么单调不增（大题常考）
      • 指派步不会增加 WCSS，因为每个观测都被指派给当前离它最近的质心；
      • 更新步不会增加 WCSS，因为在簇固定的前提下，均值正是让平方距离之和最小的那个点。

      重复这两步会收敛到一个局部解，不一定是全局最小。

      ⚠ 不要从目标函数里读出它没说的东西

      WCSS 低只意味着：在所选特征、所选缩放和这个 k 下，观测离各自的质心近。

      它不显式地最大化簇间分离，也不证明拟合出来的组对应自然类别或有用的真实分组。

      手算例题 1 · 讲义的一维四点（完整一轮）

      四个一维观测 {1, 2, 8, 9}，k = 2，初始质心 µ1 = 1、µ2 = 8。

      指派

      1 和 2 离 µ1 近；8 和 9 离 µ2 近 ⇒ C1 = {1,2}，C2 = {8,9}

      更新
      µ1' = (1+2)/2 = 1.5 µ2' = (8+9)/2 = 8.5
      算 WCSS
      WCSS = (1−1.5)² + (2−1.5)² + (8−8.5)² + (9−8.5)² = 0.25×4 = 1
      再指派

      分组不变 ⇒ 这一轮已收敛。

      ⚠ 这个计算说明了什么、没说明什么

      它说明了指派与均值更新为什么不会让 WCSS 上升。

      它没有证明 2 就是这个应用正确的分组数。

      T2-03 / T2-064. 选 k：用证据，不是用答案键

      ★★★ 关于 inertia 的那句必须分清的话（讲义特意澄清过）

      全局最优的 inertia 不会随 k 增大而上升（因为更多质心的解可以表示更少质心的解）。

      但是：不同次拟合可能落到不同的局部极小，所以「实测到的」inertia 不一定单调下降。

      ⇒ 所以要多次初始化，并把肘部、silhouette、稳定性、图形与应用含义合起来看。

      讲义给的示例表

      kInertiaSilhouette解读
      21420.58粗分组
      3760.64较强的暂定候选
      4550.52更细，但分离度更差

      这里 k = 3 是一个可辩护的暂定选择：它 silhouette 最好，inertia 的下降也最有用。但仍应跨初始化或跨样本复核，并对照应用含义。

      Study check

      为什么一个 inertia 更低的解，可能反而没有一个 inertia 更高的解有用？

      k 大一点还是小一点

      更小的 k更大的 k
      分组粒度更粗：更多观测被并进更少、更大的簇更细：分成更多、更小的簇
      代价值得区分的模式可能被合并；簇内变异/inertia 通常更高额外的细分可能不稳定、难解释、或与应用无关
      ⭐ 讲义的例子

      零售商做一次简单的营销活动，也许三个咖啡偏好簇就够；而产品设计任务可能需要更细的分组。

      哪个值都不是自动正确的「真」答案；有用的粒度取决于要支持的决策。

      可辩护的选择要同时看五类证据

      • inertia 与肘部形态；
      • silhouette 或别的合适的内部度量；
      • 跨初始化、跨样本、跨相邻 k 的稳定性；
      • 数据的几何形状与特征缩放是否适合 k-means；
      • 得到的组在上下文里是否可解释、有用。

      T2-035. 初始化：k-means++ 与 n_init

      k-means++ 从数据里选第一个质心，之后偏好离已选质心更远的点作为后续质心。这把起始质心铺开在整个数据集上，通常比随意摆放给出更好的起点。

      在 scikit-learn 里，n_init 指的是用不同种子完整跑几次 k-means，保留 inertia 最低的那次结果。n_init=10 就是独立试十次初始化。

      ⚠ 两个常见误读
      • n_init 不是迭代次数，是「完整重跑几遍」；
      • 默认值会随 scikit-learn 版本和初始化方法而变，要可复现就显式写出来。
      手算例题 3 · 稳定性：标签 vs 成员（讲义的四点例子）

      A=(0,0) B=(0,2) C=(4,0) D=(4,2)，k = 2。不同起始质心得到三次收敛结果：

      运行A,B,C,D 的标签分组Inertia
      10,0,1,1{A,B}, {C,D}4
      21,1,0,0{A,B}, {C,D}4
      30,1,0,1{A,C}, {B,D}16
      运行 1 与 2

      成员完全相同，只是标签号互换了。质心是 (0,1) 与 (4,1)，四个平方距离各为 1，合计 4。

      运行 3

      质心是 (2,0) 与 (2,2)，四个平方距离各为 4，合计 16。这是一个不同且更差的局部解 —— 尽管它在继续更新下也保持稳定。

      ★★ 这题的考点：比较必须是「标签无关」的

      单纯去数「标签数字不一样的点有几个」，会把运行 1 和 2 错判成不同。

      正确做法是比较哪些观测仍然待在一起。

      ⭐ 两种稳定性检查，查的不是同一件事

      重复随机种子查的是优化敏感性；重采样观测查的是抽样稳定性。两者都不能单独确立领域有用性。

      T2-036. k-means 什么时候合适

      当质心是一个有意义的摘要、而且在所选特征空间里各组相当紧致时，k-means 最合适。它的平方距离目标带来五个必须考虑的点：

      考虑点内容
      特征缩放数值范围大得多的特征会主导欧氏距离。单位不可比时标准化是有用的基线，但缩放应当反映领域含义
      几何形状k-means 偏好紧致、凸、以质心为中心的区域，会横切弯曲或非凸的组
      簇的大小与密度大小、散布或密度差别很大的组，用一个质心表示会很差
      离群点极端观测会把均值质心从主体拽走
      表示换特征或换变换，就换了「最近」的含义，也就可能换掉整个划分

      T2-047. DBSCAN：密度是局部定义的

      DBSCAN（Density-Based Spatial Clustering of Applications with Noise）能发现非质心形状的稠密区域，并且可以把区域之外的观测留着不指派。它不需要预先给出簇数，但结果仍然取决于距离表示以及 eps 与 MinPts 两个参数。

      ★ 密度的定义是「局部」的

      当一个点的 eps-邻域里至少有 MinPts 个观测时，它就处在稠密区域。

      连通的核心点构成簇的骨架；附近的非核心点可以作为边界点加入；落在所有已发现稠密区域之外的观测，在当前设置下被标为噪声。

      四步高层流程

      1. 访问一个未处理的观测：检查所有与它距离 ≤ eps 的观测，包括它自己；
      2. 判定三类点（见下表）；
      3. 从核心点扩张：递归地把通过相邻核心点可达的观测加进来。边界点加入簇，但不扩张簇。
      4. 重复：访问下一个未处理的观测，直到所有观测都被检查过。
      类型判据
      核心点 Core它自己的邻域里至少有 MinPts 个观测
      边界点 Border它在某个核心点的邻域内，但它自己不是核心点
      噪声点 Noise既不是核心点，也不在任何核心点的邻域内
      ⚠⚠ 三个最容易丢分的细节
      • 邻域包含点自己。scikit-learn 的 min_samples 也是把该点算在内的，和本课的约定一致；
      • 只有核心点才能继续密度可达链。边界点进了簇就到此为止；
      • 先被标成噪声的点，可能后来变成边界点。如果 A 在 B 之前被访问，A 可能被临时标为噪声；等 B 被认出是核心点、簇扩张过来，A 就成了边界点。

      两个参数与四种偏差

      参数含义
      eps（ε）数据点周围邻域的半径
      MinPts成为核心点所需的最少观测数（sklearn 里是 min_samples，含该点自己）
      设置偏差后果
      eps 太小稠密区域可能碎裂，很多观测留着没被指派
      eps 太大本来不同的稠密区域可能被合并
      MinPts 太小微弱的局部模式也会被当成簇
      MinPts 太大真实的较小或较低密度的组会留着没被指派
      ⚠ DBSCAN 的结构性弱点

      当真实的簇密度差别很大时，一组全局的 eps 与 MinPts 可能描述不好所有区域。

      手算例题 4 · 讲义的一维五点

      A=0, B=0.5, C=1.0, D=3.0, E=3.4；eps = 0.6，MinPts = 3，邻域含点自己。

      点邻域|N|角色
      A{A, B}2边界
      B{A, B, C}3核心
      C{B, C}2边界
      D{D, E}2噪声
      E{D, E}2噪声
      判定理由

      B 的邻域有 3 个点，达到 MinPts ⇒ 核心。A 和 C 各自落在核心点 B 的邻域里，但自己邻居不够，不能扩张簇 ⇒ 边界。

      结果

      发现的簇是 {A, B, C}；在这组设置下 D 和 E 是噪声。

      若 eps 提高到 1.1、MinPts 仍为 3，会有什么变化？（提示：先重算每个点的邻域大小，注意 D 与 E 之间的距离是 0.4。）

      手算例题 5 · Tutorial Q2 — 二维六点（完整）

      A=(2,2) B=(3,3) C=(3,4) D=(4,3) E=(8,7) F=(9,8)；ε = 2，MinPoints = 3。用欧氏距离，邻域含点自己，距离 ≤ ε 算在邻域内。

      ① 列出每个点的 ε-邻域
      点ε-邻域|N|角色
      A{A, B}2边界
      B{A, B, C, D}4核心
      C{B, C, D}3核心
      D{B, C, D}3核心
      E{E, F}2噪声
      F{E, F}2噪声
      ② 三类点

      B、C、D 是核心点。A 不是核心，但它落在核心点 B 的邻域里 ⇒ 边界点。E 与 F 是噪声。

      ③ 最终结果
      Cluster 1 = {A, B, C, D} noise = {E, F}

      为什么先被标噪声的点能变成边界点：临时的噪声标签不是最终的 —— 当后来的某个核心点扩张出簇时，先前访问过的、落在该核心点邻域里的非核心点就成了边界点。

      ⭐ 手算小技巧：把要比的距离平方一下

      ε = 2 ⇒ ε² = 4。于是只要比 (Δx)² + (Δy)² ≤ 4，不用开根号。比如 A 到 C：1² + 2² = 5 > 4 ⇒ 不在邻域内。

      形式化定义（6 条）

      #名称定义
      1ε-邻域Nε(p) = { q ∈ D | dist(p,q) ≤ ε }
      2核心点p 是核心点，当且仅当 |Nε(p)| ≥ MinPts
      3直接密度可达q 在 Nε(p) 内且 p 是核心点 ⇒ q 从 p 直接密度可达
      4密度可达存在链 p1…pn，p1=p，pn=q，每个 pi+1 从 pi 直接密度可达
      5密度相连存在 o，使 p 与 q 都从 o 密度可达
      6簇非空子集 C 满足：极大性（p∈C 且 q 从 p 密度可达 ⇒ q∈C）与连通性（C 中任意 p,q 密度相连）
      ⚠ 「噪声」是算法标签，不是事实判断

      讲义的原话很克制：对固定的数据、特征、缩放、距离度量、eps 与 MinPts，噪声就是「不属于任何已发现簇」的那些观测。

      这是在那组设置下的算法性标注，不是「这些观测是测量错误或真实异常」的已验证陈述。

      sklearn 的 label −1 只表示「在当前设置下未被指派到稠密区域」。

      ⚠ 边界点的归属可能不稳定

      一个边界点有时会落在不止一个簇的可达范围内。它最终归谁，可能取决于遍历顺序；而核心点构成的连通集合要稳定得多。⇒ 对孤立的边界点归属要谨慎解读。

      缩放怎样改变邻域

      DBSCAN 用距离，所以特征单位直接决定哪些点落在 eps-邻域里。如果一个特征在数千量级、另一个只在 0 到 10，大尺度那个会主导欧氏距离。

      • 单位不可比时要缩放或变换；标准化是有用的基线，强离群点扭曲均值与标准差时可考虑稳健缩放；
      • 缩放要先定、eps 后定 —— eps 的数值含义随表示而变；
      • 若聚类属于某个训练/评估流程，缩放器只在训练数据上拟合，再复用到后续数据。

      • 增大 k ⇒ 强制 k-means 分出更多簇；
      • 增大 ε ⇒ 纳入更多邻居，可能合并 DBSCAN 的簇；减小 ε ⇒ 可能制造更多噪声；
      • 增大 MinPoints ⇒ 要求更稠密的区域才能形成核心点。
      ★★ Tutorial Q3 第 6 问（高分答法）

      情形：k-means 结果 silhouette 很高，但跨初始化时成员变化很大，而且分组没有明确的应用含义。

      不应该只凭分数接受这个结果。silhouette 是内部几何证据：高值支持「紧致且分离」的分组，但不能证明分组稳定或有意义。成员变化本身就是不稳定的证据。

      该补的检查：跨种子/样本/相邻参数重复分析；检视簇的形状与摘要；检查分组是否回答了应用问题。可辩护的结论要把分数与稳定性、假设、领域证据合起来。

      实验结果
      选 kinertia 从 k=2 的 288.735 降到 k=3 的 73.979（降 214.756）；再到 k=4 只降 11.398。silhouette 在 k=3 达到 0.714（k=2 是 0.502，k=4 是 0.580）⇒ 选 k=3

      MinPts 扫描（eps=0.32）min_samples 3 ⇒ 254/5/5；12 ⇒ 199/43/22。两次都是 3 个簇

      双月形数据DBSCAN eps=0.28 得到 2 条弯曲带、0 噪声（silhouette 0.3793）；k-means 得 2 组但横切（silhouette 0.4944，反而更高）
      ★★★ 双月形那一组数字是现成的大题素材

      silhouette 更偏向 k-means（0.4944 > 0.3793），但应用要的是「连通的弯曲带」，所以该选 DBSCAN。

      原因：silhouette 比较的是簇内平均距离与到另一簇的平均距离。一条弯曲带上相距很远的两点会抬高簇内距离，哪怕它们属于同一个连通组。

      ⚠ 还有两个陷阱：eps=0.15 碎成 19 个簇、52/320 是噪声，它的 0.4835 只算在 268 个非噪声点上，和另外两个用全部 320 点算的分数不是同一个评估总体；只剩一个簇时 silhouette 是 NaN（没有可比的另一个簇），NaN 不等于质量为零。

      ⚠ 关于噪声标签的那一句，答题时最好照抄

      「记录本身的含义没有变，变的是距离表示。噪声是在所选设置下的算法性标注，不是记录有误的证明。」
