          T1-022. 什么是无监督学习

          给定 N 个观测 {x1, …, xN}，没有目标标签，算法按自己的目标与假设去找一个有用的表示、分组或概率模型。

          ⚠ 最容易被想当然的一条

          算法可能把无标签图片按颜色、形状或学到的视觉特征分组，这些组也许对应猫和狗，但没有任何保证：结果取决于所用的特征、缩放、距离或模型假设。

          簇是模型产出的摘要，需要人去解释，不是自动发现的真实类别。

          本课深考的四个方法

          方法任务一句话
          PCA线性降维找方差最大的正交方向
          k-means基于质心的硬聚类每个点归给最近的质心
          DBSCAN基于密度的聚类 + 噪声识别连通的稠密区域就是一个簇
          GMM概率密度建模 + 软聚类每个点对每个成分都有一个概率

          关联规则挖掘、异常检测、层次聚类、非线性降维、自监督表示学习等只在「版图」页作背景介绍，不直接考。

          T1-054. 维度灾难与降维

          维度灾难指特征数增加时出现的那一堆困难：数据点变得稀疏、距离变得不那么有信息量、可视化更难，模型通常需要更多数据和算力才能学到可靠模式。

          ⚠ 高维本身不是毛病

          讲义的措辞是「High dimensionality is not automatically a problem」——它只是要求我们去问：该保留哪些结构、这个降维后的表示要拿来干什么。

          降维可能带来的四种好处（都带前提）

          好处具体是什么⚠ 前提
          可视化与探索投到 2–3 维就能看图二维图不保证保住每一个重要关系
          压缩与效率变量更少，存储与计算更省—
          降噪与去冗余丢掉的方向若主要是噪声或重复信息这个假设必须自己去验
          下游建模紧凑表示可能帮到后续模型也可能删掉有用信息；要比对验证集表现，不能假定更好

          PCA 到底保留了什么

          先把特征均值去掉，然后 PCA 找出一组互相正交的主方向（协方差矩阵的特征向量）。把观测投到这些方向上，得到主成分得分。第一个方向抓住输入数据里方差最大的方向；之后每个方向在与前面所有方向正交的前提下，抓住剩余方差里最大的那部分。

          ★★★ 这一讲最重要的一句话：PCA 保的是方差，不是意义

          PCA 不使用目标标签。所以「输入方差高」和「对预测有用」是两回事。

          一个高方差方向可能描述的是光照、测量单位或别的干扰因素；而一个低方差方向可能恰恰分开了两个类别。

          PCA 可能提升、可能降低、也可能完全不改变下游预测表现。

          PCA 不是线性回归

          线性回归PCA
          用不用标签用目标变量 y只用输入特征
          在最小化什么在目标 y 上的预测误差等价于最小化低维重构的平方正交误差
          几何上量的是沿 y 轴方向的竖直距离垂直于主方向的距离
          ⚠ 这是选择题的常客

          两者画出来都是一条直线，但误差的量法不同：回归量竖直距离，PCA 量垂直（正交）距离。所以同一堆点，回归线和 PC1 一般不是同一条线。

          T1-065. 概念：方向、得分、重构

          PCA 构造出叫做主成分的新特征。每个成分都是原始特征的线性组合，并按它们捕获的变异量排序。

          量回答什么问题含义
          主方向 principal direction该朝特征空间的哪个方向看？协方差矩阵的单位特征向量；它的各个分量描述原始特征如何贡献于这个方向
          得分 score某一个观测在这个方向上处在哪儿？把中心化后的观测投到该方向上得到的坐标
          重构 reconstruction保留的那些得分对应原特征空间里的什么近似？把得分映射回特征空间，再把均值加回去
          ⭐ 一句话区分

          方向是一支箭（d 维，单位长），得分是一个数（这个观测在箭上的位置）。一个数据集只有 d 个方向，但每个观测各有自己的一组得分。

          ★ 符号的正负无所谓

          components_ 里某一行取反，会让对应的所有得分取反，但它代表同一条 PCA 轴、同一个重构。考试里看到答案的符号和你算的相反，先别慌。

          Study check
          • 主方向和主成分得分有什么不同？
          • 为什么主方向的符号不改变它代表的那条一维轴？
          • 举一个低方差方向仍然重要的情形。

          T1-076. ★ 核心数学：六个步骤

          这一页讲义标着 * CORE MATH *，是 T1 最可能出大题的地方。

          Step 1 · 从数据开始

          数据集 X 有 n 个观测、d 个特征。每一行是一个观测，每一列是一个特征。

          Step 2 · 中心化

          µ = (1/n) Σi=1n xi
          Xc = X − 1n µT （1n 是 n×1 的全 1 向量）

          中心化把数据中心搬到原点，于是方差描述的是围绕特征均值的散布，而不是到某个任意原点的距离。

          ⭐ 一个随手就能做的自检

          Xc 的每一列加起来必须等于 0（允许极小的舍入误差）。手算时先验这一步，能挡掉大半的错。

          Step 3 · 构造协方差矩阵

          Σ = (1/(n−1)) · XcT Xc

          Σ 是对称的 d×d 矩阵。对角元是某个特征自己的方差；非对角元表示两个特征怎样共同变化。

          Step 4 · 为什么会冒出特征向量（这一段要会推）

          取任意单位方向 v（即 vTv = 1），把每个中心化观测投上去：

          z = Xc v

          这些一维得分的样本方差是：

          Var(z) = (1/(n−1)) zTz = vT Σ v

          PCA 问的就是：哪个单位方向能让这个量最大？解这个带约束的最大化问题，得到特征值关系：

          Σ v = λ v
          ★★★ 这一步的结论要能背出来

          一个特征向量给出的方向，其投影方差就等于它的特征值。

          所以特征值最大的那个特征向量就是第一主方向，因为它产生最大的投影方差。

          ⭐ 几何读法（答简答题时很好用）

          想象一根一维的轴穿过中心化后的点云转动，把每个点投上去。PCA 挑的就是让这些投影坐标散得最开的那个角度。协方差的特征问题，只是「不用一个个角度去试」的矩阵算法。

          Step 5 · 分解并排序

          • 求 Σ 的特征值 λ1…λd 与对应的单位特征向量 v1…vd；
          • 按降序排 λ1 ≥ λ2 ≥ … ≥ λd；
          • 特征向量定义主方向，每个方向上挂着的特征值就是对应得分的方差。

          主方向两两正交。对拟合用的这批数据，成分得分是不相关的——但这不保证所有非线性依赖或任务相关的信息都消失了。

          Step 6 · 选成分、投影、重构

          取前 k 个特征向量放进 d×k 的矩阵 Wk。成分 j 的解释方差比是：

          rj = λj / Σl=1d λl
          k 个成分的累计保留方差 = Σj=1k rj
          Z = Xc Wk （n×k 得分矩阵）
          X̂ = Z WkT + 1n µT （回到原特征空间的重构）
          ⚠ 重构时必须把均值加回去

          Z WT 只回到中心化的空间。漏掉 + µ 是手算大题最常见的扣分点之一。

          ★ 开算之前必须核对的五条约定（讲义标为 exam-critical）

          约定内容
          ① 先中心化构造散布矩阵或协方差矩阵之前，先把每个特征的均值减掉
          ② 散布 vs 协方差S = XcTXc 和 S/(n−1) 的特征向量完全相同；特征值差一个 (n−1) 的因子，但解释方差比一模一样
          ③ 归一化投影之前要用单位特征向量
          ④ 投的是中心化数据Z = XcW；均值只在重构时加回去
          ⑤ 该缩放时才缩放特征单位或量程不可比时才标准化
          ⭐ 约定 ② 在考试里的用法

          题目给的是散布矩阵 S（不除 n−1）时，直接对 S 做特征分解即可——方向一样，比值一样，不用先除。这样能省掉分数运算，还不容易算错。

          Study check
          • 为什么 vTΣv 度量的是沿方向 v 的方差？
          • 如果协方差的一个特征对是 (λ, v)，λ 在 PCA 里是什么意思？
          • 为什么散布矩阵和样本协方差矩阵给出相同的主方向？

          T1-097. 手算例题 A：讲义的 PCA by hand

          这个例子刻意造得两个主方向都有变异，所以保留一个成分只能留住大部分、留不住全部方差 ——比「所有点正好共线」的例子更能说明成分选择。

          题：把下面四个二维观测投到一维
          观测xy
          1−30
          230
          30−1
          401
          第 1 步

          均值与中心化矩阵。

          µ = (0, 0) ⇒ Xc = X（本来就已经居中）

          自检：两列各自加起来都是 0。✓

          第 2 步

          散布矩阵与样本协方差。

          S = XcTXc = [[18, 0], [0, 2]]
          Cov = S/(n−1) = S/3 = [[6, 0], [0, 2/3]]

          因为是对角矩阵，特征值直接就在对角线上，不用解特征方程。

          第 3 步

          特征值与单位特征向量（按降序）。

          λ1 = 6, v1 = (1, 0)T
          λ2 = 2/3, v2 = (0, 1)T
          第 4 步

          解释方差比。

          r1 = 6 / (6 + 2/3) = 6 / (20/3) = 0.9
          r2 = (2/3) / (20/3) = 0.1

          一个成分就达到 90% 的保留方差目标。

          第 5 步

          投影到 PC1 并用一个成分重构。

          z = Xcv1 = (−3, 3, 0, 0)T
          X̂ = z v1T + µ = [[−3,0], [3,0], [0,0], [0,0]]
          第 6 步

          谁丢了信息？

          观测 3 和 4 在第二个特征上被重构到了均值（0），它们之间的差别彻底消失了。

          总平方重构误差 = (−1−0)² + (1−0)² = 2
          校验：被丢掉的特征值 × (n−1) = (2/3) × 3 = 2 ✓
          ★★ 这题真正要考的点

          保留 90% 的方差，不等于保留了每个特征的 90%，也不等于保留了每一个与应用相关的信号。

          这里第二个特征的变异在秩一重构里完全消失。如果应用恰好要区分观测 3 和 4，那么「90% 方差」这个目标就是不够的。

          ⭐ 一个能当校验用的恒等式（手算时很值钱）

          丢掉成分 j 造成的总平方重构误差 = λj × (n−1)（λ 取自样本协方差矩阵）。或者更直接：= 散布矩阵 S 的对应特征值。这里 S 的第二个特征值就是 2。

          Tutorial8. 手算例题 B：Tutorial 三问全解

          Tutorial · Q1 — 准备步骤

          数据集 X = [[2,3], [3,5], [0,−1], [−1,−3]]。两个特征尺度已经可比，所以只中心化、不标准化。

          ① 均值与中心化矩阵
          µ = (1, 1)
          Xc = [[1, 2], [2, 4], [−1, −2], [−2, −4]]
          ② 散布矩阵与样本协方差
          S = XcTXc = [[10, 20], [20, 40]]
          Cov(X) = S/3 = [[10/3, 20/3], [20/3, 40/3]]
          ③ 中心化的快速自检

          每一个中心化后的列加起来都等于 0。

          另外：把 S 乘以正常数 1/3 会改变它的特征值，但不改变它的特征向量。

          Tutorial · Q2 — 特征值与第一主成分

          特征方程化简为 λ(λ − 50) = 0。

          ① 两个特征值
          λ = 50 与 λ = 0
          ② 验证特征向量
          S (1, 2)T = (50, 100)T = 50 · (1, 2)T ✓
          S (−2, 1)T = (0, 0)T = 0 · (−2, 1)T ✓
          ③ 选出并归一化第一主成分
          v1 = (1/√5) (1, 2)T ≈ (0.4472, 0.8944)T

          选它是因为它对应最大的特征值，也就是方差最大的方向。

          Tutorial · Q3 — 投影与重构
          ① 四个一维得分
          z = Xcv1 = (√5, 2√5, −√5, −2√5)T ≈ (2.236, 4.472, −2.236, −4.472)T
          ② 重构第一个观测
          x̂c,1 = z1 v1T = √5 · (1/√5, 2/√5) = (1, 2)
          加回均值 (1,1) ⇒ (2, 3)，正好是原始点。
          ③ 为什么一个成分就留住了 100% 的方差

          每一个中心化后的行都是 (1,2) 的倍数，所以中心化矩阵的秩是 1。正交方向上没有任何变异，于是 PC1 保留 50/(50+0) = 100% 的方差。

          Tutorial · 扩展（两问）

          (a) 若第一个特征以美元计、数值大上几千倍

          因为 PCA 最大化方差，大尺度的那个特征会主导协方差矩阵，把 PC1 拽向它自己的坐标轴——哪怕这种主导只是单位造成的。

          什么时候该标准化：特征单位或量程不同、而你希望比较的是「相对变异」时。但它不是自动动作：到底该用绝对方差还是标准化后的方差，由领域含义决定。

          (b) PCA 放在有标签的预测任务之前

          PCA 只用输入特征、不用目标标签。所以高方差方向可能反映的是干扰变异，而较低方差的方向反而可能含有有用的预测信号。

          怎么检验：比较用 PCA 和不用 PCA 的下游验证表现；并且任何缩放器与 PCA 变换都只在训练数据上拟合，再应用到验证/测试数据。

          T1-089. Python 工作流：把数学符号对上 sklearn 属性

          属性 / 输出对应数学里的什么说明
          pca.mean_µ拟合时学到的特征均值，投影前会被减掉
          pca.components_WT（每一行一个 vj）用原始特征坐标表示的主方向
          pca.explained_variance_λj每个保留方向上的方差
          pca.explained_variance_ratio_rj该方向占总方差的比例
          fit_transform(X)Z = XcW一行一个观测，一列一个保留成分
          inverse_transform(Z)X̂ = ZWT + µ重构，均值已经帮你加回去了
          ⚠ components_ 是按行存的

          数学里 W 是 d×k（列是方向），而 sklearn 的 components_ 是 k×d（行是方向）。写代码或读答案时注意这个转置。

          讲义里那个可验证的例子

          用的正是第 7 节那四个点 X = [[−3,0], [3,0], [0,−1], [0,1]]：

          输出值
          mean_[0, 0]
          components_与两条特征轴对齐
          explained_variance_约 6 与 0.667
          explained_variance_ratio_0.9 与 0.1
          得分矩阵形状(4, 2)
          只留 1 个成分时的保留方差90%
          总平方重构误差2

          缩放为什么能改变 PCA

          把第二个特征乘以 100 之后：没有标准化时，被放大的那个特征会主导 PC1。标准化之后，两个特征方差相等、协方差为零，所以两个解释方差比都是 0.5。

          ⚠ 这是一个「特征值并列」的情形

          两个特征值相等时，第一主方向不唯一，返回哪个朝向可能取决于数值细节。

          这个例子说明的是「缩放改变了 PCA 认为什么方差重要」，不能被解读成「标准化会让 PC1 在两个特征上载荷相等」。

          ★ 不要无脑标准化

          特征单位或量程不可比时才缩放。如果原始的方差差异本身就有科学含义，标准化反而会抹掉你本来想让 PCA 保住的信息。

          避免数据泄漏

          train_scaler.fit_transform(X_train) → train_scaler.transform(X_test)
          train_pca.fit_transform(X_train_scaled) → train_pca.transform(X_test_scaled)
          ★ 泄漏规则（M2 三个主题通用）

          若 PCA 或聚类被用在后续的预测流程里，预处理与无监督变换都只用训练数据拟合，再把拟合好的变换应用到验证或测试数据。
