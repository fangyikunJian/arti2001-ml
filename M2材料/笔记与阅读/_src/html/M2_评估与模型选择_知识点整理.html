              T1-041. 为什么无监督结果不能用准确率来判

              ★ 官方对这一页的定位（原文）

              「核心且可考核的材料：你应当能够为一个无监督学习结果选择、解释并批判恰当的证据。」

              「你不需要推导 silhouette、AIC 或 BIC 的公式。」

              评估无监督模型和评估有监督预测器不同。没有提供目标标签时，通常没有一个单一的准确率能告诉我们发现的结构是否正确。取而代之的是：把几种形式的证据合起来，并结合问题、表示与建模假设去解释。

              五条学习成果

              1. 解释为什么无监督结果通常不能用准确率来判断；
              2. 为 PCA、聚类与 GMM 选择合适的评估证据；
              3. 解释 inertia、silhouette、解释方差、AIC 与 BIC，而不把任何单一数值当成自动的真理；
              4. 检查对初始化、缩放与超参数的稳定性与敏感性；
              5. 判断发现的结构对这个应用是否有意义。

              T1-042. ★★★ 四部分证据框架（整个 M2 的骨架）

              证据要问的问题例子
              拟合 / 内部结构拟合出来的模型，是否表示了它被设计去找的那种结构？解释方差、重构误差、inertia、silhouette、似然、AIC、BIC
              稳定性一个小的建模或抽样改动，会不会给出相似的结果？跨随机种子、初始化、样本或邻近超参数重复
              假设与表示距离、尺度、形状与分布假设是否合理？特征缩放、簇的几何、密度、协方差形式、噪声处理
              领域有用性这个结果是否回答了真实问题、是否支撑一个可辩护的解释？有意义的投影、可行动的分组、合理的成分、专家审阅
              ★★★ 这一页的关键原则（一句话，建议背下来）

              「一个有说服力的结果通常需要不止一个信号。一个高分本身不能证明某个嵌入、簇或成分对应真实世界的真相。」

              ⭐ 怎么把这个框架用在答题上

              任何「请评估/论证这个无监督结果」的大题，都可以照这四格展开：① 内部证据是多少 → ② 稳不稳 → ③ 假设合不合适 → ④ 对应用有没有用，最后写一句「这是有依据的判断，不是证明」。

              T1-043. 评估 PCA

              证据内容
              解释方差比每个保留成分所代表的总方差占比。累计解释方差帮助决定保留几个成分
              重构质量数据投影再重构之后丢了多少信息。对压缩或去噪尤其相关
              任务有用性降维后的表示是否支持了预期的可视化、解释或下游分析
              对缩放与离群点的敏感性必须检查 —— 高数值方差可能只反映测量单位或极端观测，而不是有用信号
              ★★ PCA 评估的那句总结（原文的意思）

              「高解释方差是有用的证据，但 PCA 保的是方差，不是意义。一个低方差方向仍可能对应用很重要；一个高方差方向可能代表的是干扰变异。」

              T1-044. 评估聚类（一）：inertia 与肘部法

              k-means 的 inertia 是簇内平方距离之和。inertia 越低意味着点离各自的质心越近。

              ★★★ 必须分清的两句话（讲义反复强调）
              • 全局最优的 inertia 不会随簇数增加而上升；
              • 但不同次拟合可能落到不同的局部极小，所以「实测到的」inertia 不一定单调下降。

              肘部法找的是「再加簇、收益明显变小」的那个点。有些数据集根本没有明显的肘部，所以这是一个诊断手段，不是自动规则。

              inertia 怎么算（等权重）

              I = Σr=1K Σi∈C_{r} ‖xi − µr‖₂² , µr = (1/|Cr|) Σi∈C_{r} xi
              ‖xi − µr‖₂² = Σq=1p (xiq − µrq)²

              K 是簇数，Cr 是第 r 个簇的观测下标集合，|Cr| 是它的大小，µr 是质心（均值），p 是特征数、用 q 索引。

              ⚠ 三条计算约定
              • 先算每个点到它所属质心的平方距离，再把所有点加起来；
              • 它是「和」，不是「平均」；
              • 比较时必须用同一批观测、同一组特征、同一种缩放。
              手算例题 1 · inertia（讲义的一维小例）

              一维两个簇 {1, 3} 与 {8, 10}。

              ① 质心
              µ1 = (1+3)/2 = 2 µ2 = (8+10)/2 = 9
              ② inertia
              I = (1−2)² + (3−2)² + (8−9)² + (10−9)² = 1 + 1 + 1 + 1 = 4

              T1-045. 评估聚类（二）：轮廓系数 silhouette

              轮廓系数比较「一个观测离自己簇有多近」与「它离最近的另一个簇有多近」。取值在 −1 到 1 之间：

              取值含义
              接近 1这个点与它被指派的簇匹配得好
              接近 0重叠或边界上的点
              负值这个点可能离另一个簇更近

              怎么算（三步）

              a(i) = (1/(|Cr|−1)) · Σj∈C_{r, j≠i} d(xi, xj)

              a(i) 是到同簇其它点的平均距离 —— 排除点自己。d 通常是欧氏距离，不平方。

              b(i) = mint≠r [ (1/|Ct|) · Σj∈C_{t} d(xi, xj) ]

              对每一个其它簇，算点 i 到该簇所有点的平均距离；这些平均值里最小的就是 b(i)。

              ⚠⚠ b(i) 的三个常见误解
              • 用的是「按点到点平均距离」最近的那个簇，
              • 不是最近的那个「单个点」，
              • 也不是最近的那个「质心」。
              s(i) = (b(i) − a(i)) / max{a(i), b(i)} , S = (1/n) Σi=1n s(i)

              s(i) 是该点的轮廓系数；S 是整体分数，对 n 个被评估的观测取平均。a(i) 远小于 b(i) 时分数为正且接近 1；两个平均值接近时接近 0；a(i) 更大时为负。

              手算例题 2 · silhouette（接上例）

              仍是 {1, 3} 与 {8, 10}，算点 1 的轮廓系数。

              ① a(1)

              同簇只剩点 3：

              a = |1 − 3| = 2
              ② b(1)

              到另一个簇所有点的平均距离：

              b = (|1 − 8| + |1 − 10|) / 2 = (7 + 9)/2 = 8
              ③ s(1)
              s = (8 − 2) / max{2, 8} = 6/8 = 0.75
              ④ 整体分数

              对其余各点同样算一遍，再取平均。

              ⚠⚠ 计算条件（容易被忽略，但很爱考）
              • 整体分数要求簇数在 2 到 n−1 之间；
              • 独自成簇的点按约定记为 0；两个距离平均值都为 0 时也记 0；
              • 对 DBSCAN，评估时要排除噪声点（label = −1），报告被排除的比例，并检查剩下的数据仍满足上述条件。
              ★★★ silhouette 的系统性偏向（高频简答题）

              「平均轮廓系数更高，往往意味着簇更紧致、更分离。但是 silhouette 倾向于偏好「凸」的簇，当有用的分组是弯曲的、基于密度的或极不均衡时，它可能给出有误导性的排名。」

              对 DBSCAN，还要同时看：簇的个数、被标为噪声的比例、以及对 eps 和 min_samples 的敏感性。

              稳定性与意义（四条检查）

              • 跨多个初始化或随机种子重复 k-means；
              • 检查邻近的 k、eps 或 min_samples 会不会引起突变；
              • 看图和簇的摘要，而不是只依赖一个分数；
              • 问这些分组在应用里是否有意义、有用。

              T1-046. 评估高斯混合模型

              证据内容
              对数似然度量拟合出的密度，但它一般会随模型复杂度上升而改善，所以不能单独用它来选成分数
              AIC 与 BIC在拟合与复杂度之间权衡。对同一批数据拟合的模型，AIC 或 BIC 更低者更优
              责任度显示软成员度里的不确定性。大量模糊的责任度可能意味着成分之间重叠严重
              初始化与收敛EM 可能收敛到局部解。要用多个初始化并比较拟合结果
              分布假设低 BIC 不证明总体里有那么多自然分组，也不证明高斯成分在科学上有意义

              AIC 与 BIC：平衡拟合与复杂度

              AIC = 2k − 2 log(L̂) BIC = k·log(n) − 2 log(L̂)

              k 是估计出的参数个数，n 是观测数，L̂ 是最大似然。一个更灵活的模型可能把训练数据拟合得更好，但也可能过拟合。复杂度罚项鼓励「解释得好、又不含多余参数」的模型。

              ★★ 三条使用规则
              • 对同一数据集拟合的模型，AIC 或 BIC 更低的那个更受偏好；
              • BIC 的复杂度罚项比 AIC 更强（尤其样本量增大时），所以它常常选出更简单的模型；
              • 这两个准则支持「模型比较」，但不保证选中的模型在科学上或实践上恰当。

              ⚠ 在 T3 的讲义里，同一组公式写成 AIC = −2 log L + 2p、BIC = −2 log L + p·log N —— 完全是同一个式子，只是把两项前后调换、并把参数个数记作 p。不要被符号差异迷惑。

              T1-047. ★★★ 示范决策：不要只看一个数

              讲义给了一张非常典型的三行表，几乎就是大题的标准答法模板：

              候选内部证据稳定性应用证据
              k-means, k = 2silhouette 0.58；inertia 相对较高稳定把领域专家会区分的两个组合并了
              k-means, k = 3silhouette 0.55；inertia 明显下降稳定三个组有合理的解释
              k-means, k = 4silhouette 0.59（最高）；inertia 略低不稳定有一个小组跨运行会变
              ★★★ 标准结论（照着这个结构写）

              最大的 silhouette 属于 k = 4，但那个结果不稳定。

              k = 2 的解稳定，但它合并了应用关心的分组。

              ⇒ 在这个例子里 k = 3 是最可辩护的选择，因为有好几种形式的证据支持它。

              ⚠ 收尾必须有这一句：这是一个有理据的判断，不是「恰好存在三个自然分组」的证明。

              T1-048. 可复用的评估检查清单（六步）

              1. 陈述实际问题，以及「什么样的结果才算有用」；
              2. 检查特征表示、缩放与相似性度量是否恰当；
              3. 使用一个方法专属的诊断量，但要说明它度量什么、以及它不能确立什么；
              4. 检查跨初始化、跨样本或跨邻近超参数的稳定性；
              5. 检视图形、摘要、不确定性与失败案例；
              6. 用领域证据解释结果，并报告局限。
              ★ 数据泄漏提醒（三个主题通用，必考）

              「如果 PCA 或聚类被用在后续的预测工作流里，预处理与无监督变换都只用「训练数据」拟合，然后把拟合好的变换应用到验证或测试数据。」

              T1-049. 四个 Study check（官方原题，附参考答案）

              Study check 与参考答法

              ① 为什么「k-means 的 inertia 更低」不足以支持更大的 k？

              因为全局最优的 inertia 不会随 k 增大而上升 —— 极端情况下每个点自成一簇时 inertia 为 0。所以「更低」几乎是必然的，它不构成选择依据。还必须看 silhouette、稳定性、以及分组在应用里是否可解释。

              ② 为什么即使 DBSCAN 还原了更有意义的弯曲分组，silhouette 仍可能偏向 k-means？

              silhouette 倾向偏好「凸」的簇。它比较的是簇内平均距离与到另一簇的平均距离；一条弯曲带上相距很远的两点会抬高簇内平均距离，哪怕它们属于同一个连通组。于是这个度量偏好的几何，与应用要求的几何不一致。

              ③ 更低的 BIC 支持什么、不证明什么？

              它支持：在这些候选模型里，这一个在「拟合 vs 复杂度」的权衡下更可取。它不证明：总体里存在那么多自然分组，也不证明高斯成分在科学上有意义。

              ④ 在接受一个无监督结果之前，能做哪两项稳定性或敏感性检查？

              (a) 跨多个随机种子/初始化重复拟合，用标签无关的方式比较哪些观测仍在一起；(b) 重采样观测（或改动邻近的超参数，如相邻的 k、eps、min_samples），看结构是否突变。前者查优化敏感性，后者查抽样稳定性。

              附录 B · 高频易错点清单

              #易错点正确做法
              1把 inertia 当平均是平方距离之和
              2以为实测 inertia 必须单调下降只有全局最优才单调不增；局部极小会让实测值波动
              3只靠肘部法定 k有些数据没有明显肘部；它是诊断不是规则
              4算 a(i) 时把点自己算进去要排除自己，分母是 |Cr| − 1
              5算 silhouette 时把距离平方了silhouette 用的是距离本身，不平方
              6b(i) 取「最近的点」或「最近的质心」取的是按平均点到点距离最近的那个簇
              7DBSCAN 算 silhouette 不排除噪声排除 label = −1，并报告排除比例
              8只剩一个簇时还去要 silhouette无法计算（NaN）；NaN ≠ 质量为 0
              9用对数似然选成分数它随复杂度上升而改善；要用 AIC/BIC
              10拿 AIC 和 BIC 互相比较同类相比，且须同数据同特征
              11由「分数最高」直接下结论要同时过稳定性与领域有用性两关
              12在全量数据上拟合预处理再划分训练/测试只在训练集上拟合，再 transform
